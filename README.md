## 当前书写约束

- 常规章：2800～3500字
- 硬上限：3800字
- 关键高潮章：偶尔可到4200字
- 超过上限时优先拆章
- 第二卷重点是连接七站并建立长期互助，不是重复救援或连续吞并
- 降低大型升级频率，持续兑现经营、岗位和已有设施
- 归途站最终建立开放的分布式轨道网络，不吞并所有小站、不建立个人帝国
- 白栎保持独立，生活站台、病历、药品和人员转移不能由归途站单方面决定
- 沈青禾保留白栎岗位、召回权和专业判断，不能后一章立刻完全忠诚
- 病患按紧急程度而不是站点身份排序
- 公开账不得记录可识别病人的姓名、病史和诊断
- 转运准备区只能转运、记录、清洁准备和短期观察，不能包装成万能医院
- 破冰模块当前限制使用，不能突然变成无限破冰能力
- 普通黑雾通行依赖三端校准、限速和能源消耗，不能写成无代价瞬移
- 增加总章数不等于拉长当前剧情；扩展主要放在移动核心、百站制度、轨道城市生活和跨域网络
