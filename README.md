## 当前方向

> **现代家庭小厂现实危机 × 验证式进化**

核心规则：

> **现实里犯过的错，复测改对以后，它就真的学会了。**

第一阶段围绕家庭电机厂的一批小型无刷电机质量危机展开：真实失败提供反馈，主角选择改进方案并重新部署，只有通过现实复验的改进才会被永久固化。
