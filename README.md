## 当前书写约束

- 常规章：2800～3500字；硬上限3800字；关键高潮章偶尔可到4200字。
- 第二卷重点是连接七站并建立长期互助，不是重复救援或连续吞并。
- 降低大型升级频率，优先兑现附车、流程、岗位和已有设施。
- 白栎保持独立，生活站台、病历、药品和人员转移不能由归途站单方面决定。
- 沈青禾保留白栎岗位、召回权和专业判断，不能迅速转为完全忠诚的正式成员。
- 病患按紧急程度而不是站点身份排序。
- 公开账不得记录可识别病人的姓名、病史和诊断。
- 基础医疗协作区只能转运、记录、清洁准备、样本封存和短期观察，不能包装成万能医院。
- 医疗废物和高风险废水必须交具备处理能力的节点。
- 破冰模块仍限制使用；普通黑雾通行仍依赖三端校准、限速和能源消耗。
