## 当前书写约束

- 常规章：2800～3500字
- 硬上限：3800字
- 关键高潮章：偶尔可到4200字
- 超过上限时优先拆章
- 降低大型升级频率，持续兑现经营、岗位和已有设施
- 归途站最终建立开放的分布式轨道网络，不吞并所有小站、不建立个人帝国
- 七座站状态不同；当前先完成白栎合作，不同时营救七站
- 白栎保留独立管理，病历、药品和人员转移不能由归途站单方面决定
- 宋雨眠和专业人物可以否决不符合医疗伦理的方案
- 破冰模块当前限制使用，不能突然变成无限破冰能力
- 普通黑雾通行依赖三端校准、限速和能源消耗，不能写成无代价瞬移
- 接驳附车只能转运，不能直接写成完整医疗车或万能医院
- 增加总章数不等于拉长当前剧情；扩展主要放在移动核心、百站制度、轨道城市生活和跨域网络
