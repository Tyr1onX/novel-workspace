# 有人让你打开“屏幕共享”，先挂电话：不管他说自己是谁

“客服”说要帮你取消扣费，“银行工作人员”说账户有风险，甚至有人自称“公检法”，让你下载一个软件，再打开“屏幕共享”。

碰到这种情况，先别跟着操作。

最安全的做法只有一句：先挂电话，再自己去官方渠道核实。

先记住这一句：陌生人通过电话或聊天让你开启“屏幕共享”，还要你打开银行、支付或验证码页面——立即停止操作。

## 一、“屏幕共享”到底共享了什么？

屏幕共享本身是一个正常功能。家人远程教你操作手机、同事开会演示，都可能会用到。

危险的是：你和一个陌生人通话时，对方一边让你共享屏幕，一边“指导”你打开手机银行、支付软件、短信验证码或者身份证信息。

这时候，你屏幕上出现的内容，对方也可能同步看到。部分远程控制软件甚至还能进一步操控手机。

国家金融监督管理总局近年的风险提示中，反复提到有人冒充客服、公检法等，以“取消扣费”“配合调查”等理由诱导用户开启屏幕共享或远程控制，再窃取账户信息、验证码并实施转账。

一个很好用的判断方法：正常客服可以让你自己去官方 App、官方网站或线下网点办理。只要对方坚持让你下载陌生软件、共享屏幕、远程控制，或者操作银行卡和验证码，就不要继续。

## 二、听到这几句话，就要提高警惕

- “你的会员 / 保险 / 贷款正在自动扣费，我帮你取消。”
- “你的账户有风险，按我说的操作才能解除。”
- “为了证明是本人，请下载这个会议软件。”
- “打开屏幕共享，我一步一步教你。”
- “不要告诉家里人，这件事需要保密处理。”

## 三、如果已经打开了屏幕共享怎么办？

1. 马上停止共享。退出屏幕共享或远程控制，结束通话，关闭可疑软件。
2. 不要再输入任何密码或验证码。尤其不要继续打开手机银行、支付软件，也不要做人脸识别。
3. 如果已经操作过银行卡或支付账户，尽快联系官方客服。说明情况并检查账户；必要时挂失、冻结或修改密码。
4. 怀疑被骗时及时报警。可以拨打 110；遇到疑似电信网络诈骗，也可拨打 96110 咨询、核实。

## 四、这件事也可以告诉家里人

这类骗局最麻烦的地方，是对方往往说得很着急：马上扣钱、影响征信、账户异常、涉嫌违法……

人一着急，就容易跟着对方一步一步点下去。

所以不需要把所有骗局都背下来。家里只要记住一个简单规则：

**陌生人让你共享屏幕 → 先挂电话 → 自己找官方客服核实。**

不要使用对方发来的电话号码、链接或二维码。官方渠道自己找，事情慢一点处理也没关系。

## 最后提醒

屏幕共享不是坏功能，但它不该成为陌生人远程“指导”你操作钱和账户的工具。

真正重要的不是记住骗子的每一种新话术，而是遇到涉及钱、密码、验证码和屏幕共享时，先停下来。

多停一分钟，往往就能避开一次骗局。
