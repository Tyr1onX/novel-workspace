# 微信字体太小怎么调大？这2个地方一起调

看聊天记录、朋友圈、公众号文章时，总觉得字太小，手机拿得越来越远？

先别急着换手机，也不用装什么“放大软件”。微信自己能调一次，手机系统还能再调一次。

建议先调微信，还是觉得小，再调手机系统。这样最容易找到适合自己的大小。

## 第一处：先把微信自己的字体调大

打开微信，依次进入：

**我 → 设置 → 通用 → 字体大小**

进入后，拖动下面的滑块，往右就是把字调大。调到自己看着舒服的位置即可。

微信里的聊天、联系人列表、朋友圈等页面都会跟着变化。不同版本的页面样式可能略有不同，但“字体大小”一般都在“通用”里。

如果调得太大后，有些页面出现一行放不下、按钮挤在一起，再往回调一档就行。

## 第二处：微信调到最大还是小，再调手机系统

如果不只是微信，连短信、设置、通讯录里的字也觉得小，那就直接调手机系统字体。

如果用的是 iPhone：

**设置 → 显示与亮度 → 文字大小**

拖动滑块即可放大文字。如果还是不够大，还可以进入：

**设置 → 辅助功能 → 显示与文字大小 → 更大字体**

iPhone 还可以在“显示与亮度”里使用更大的显示缩放，让文字、按钮和图标一起变大。

如果用的是安卓手机：

不同品牌名字略有不同，一般在：

**设置 → 显示和亮度 → 字体大小 / 字体与显示大小 / 界面缩放**

找不到时，最简单的方法是在手机“设置”顶部直接搜索“字体大小”。

以华为手机为例，新版 HarmonyOS 可以在“显示和亮度”中调整字体大小和界面缩放；部分版本还提供长辈关怀模式。

## 如果不仅字小，按钮也总是点错

这种情况可以再看看微信设置里的“关怀模式”。

关怀模式的重点不只是放大文字，还会把部分按钮做得更大、更清楚，色彩对比也更明显。

不同微信版本里的入口位置可能略有变化。如果设置页里能看到“关怀模式”，可以打开试一试；不合适随时可以关掉。

## 别一次拉到最大，先试一档

字体并不是越大越好。太大会让一行能显示的字变少，有些网页和小程序也可能显得拥挤。

最简单的方法是：

- 先把微信字体往右调一档；
- 回聊天页面看一会儿；
- 如果还是费眼，再继续调大；
- 微信已经够大，但其他软件仍然小，再调手机系统。

最后以“能轻松看清，又不会觉得界面太挤”为准。

## 给家里人设置时，多做一步

调完以后，别只看设置页面。最好再打开一次聊天、通讯录和公众号文章，让本人实际看一会儿。

每个人舒服的大小都不一样。让使用手机的人自己觉得清楚，才是最合适的设置。
