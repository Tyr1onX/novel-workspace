# 抖音自动化工作流

## 目标

减少手动发布操作，把 7BYTE 视频形成稳定闭环：

```text
视频素材 + 标题 + 文案 + 话题 + 发布时间
  ↓
写入排期表
  ↓
到点发布
  ↓
回收播放、点赞、评论、分享等数据
  ↓
反推下一期选题
```

## 实现路径

只保留一条主路径：官方开放平台授权 + 本地排期器。

不做：

- 绕过扫码登录。
- 绕过验证码。
- 爬创作者中心后台页面。
- 模拟人工点击批量发布。

## 当前阶段

先完成目录、排期表和数据字段。等开放平台权限确认后，再接入真实上传发布。
