# 微信公众号工作流

## 目标

把「闻舟会用」从临时生成内容，收敛成可复用内容资产。

## 当前主路径

```text
选题
  ↓
生成文章
  ↓
生成封面 / 配图建议
  ↓
归档 Markdown
  ↓
导出 docx
  ↓
手动导入公众号后台
  ↓
你确认标题、作者、原创声明、封面
  ↓
发布
  ↓
回填阅读、分享、收藏、留言等数据
```

## 发布版规则

- 正文末尾不再展示资料来源。
- 资料来源只保留在内部归档或研究记录中。
- 涉及争议、安全、诈骗、支付等内容时，优先写成“具体场景 + 稳妥处理”，避免夸张标题和对立表达。

## 后续可自动化部分

- 生成 docx。
- 生成封面图。
- 生成排期。
- 维护数据台账。
- 准备导入所需标题、作者、摘要、封面、原创声明勾选清单。

最终发布按钮仍由你在公众号后台确认。
