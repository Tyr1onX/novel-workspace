# 系列设定集

## 作品定位

- 书名：**《无尽轨道：我能融合整座车站》**
- 类型：男频、科幻末世、末日求生、升级流、囤物资、移动基地经营
- 主角：周野
- 核心能力：万物融合
- 核心资产：从一节破旧车厢成长为移动站点、轨道城市和人类交通枢纽

## 核心阅读承诺

这不是单纯的打怪升级文。主要爽点来自：

1. 别人在挨饿受冻，周野的列车逐步拥有热饭、热水、卧室、温室、冷库、维修与稳定能源。
2. 每次搜集的设备与人员都能产生长期价值，而不是用完即弃。
3. 家人与专业成员各司其职，列车越来越像真正的家和社会。
4. 主角从被迫沿轨道求生，逐步获得路线选择、铺轨、建站和修复区域网络的权力。
5. 生存危机服务于建设爽感，避免长期暗黑、血腥和无意义压抑。

## 世界底层设定

原世界成年人被投入名为“无尽轨道”的异常交通网络。每个人获得一节初始列车，在不同站点停靠、搜索资源并继续前进。

无尽轨道并非普通游戏地图，而是一套已经失控的空间交通网络。它连接许多被灾变切割的区域。黑雾是轨道网络崩坏后形成的空间异常，会造成方向混乱、感知失常、设备故障和区域吞没。

“系统”并非单纯发奖励的游戏界面，而是在筛选和扶持能够承担区域修复任务的移动节点。周野前期只想带家人活下去，后期逐渐意识到：想让自己的列车永远安全，就必须让沿途轨道和站点重新运转。

## 万物融合

### 基本能力

周野可以将符合条件的车辆、建筑、设备或功能区域与列车融合，使其重组为适配列车的车厢、模块或站点设施。

### 能力不能做的事

- 不能凭空创造物资。
- 不能无视目标所有权或控制权限。
- 不能无限压缩规模而没有承载代价。
- 不能无视能源、材料、施工时间和专业人员。
- 不能把所有危险目标一句“融合”直接解决。

### 大型融合条件

大型目标原则上必须同时满足：

1. 合法所有权、明确授权或区域控制权限；
2. 足够的基础材料、机械零件、电子元件与能源；
3. 实际改造时间；
4. 当前列车承载和编组能力；
5. 相应岗位人员或技术资料；
6. 特殊目标可能需要完成一次正常运行、权限验证或前置任务。

### 能力成长方向

- 单件回收与小型设备重组
- 车辆、商店和普通功能车厢融合
- 专业设施与生产车厢融合
- 区域型站点融合
- 临时铺轨与路线拓展
- 移动安全区和轨道网络修复
- 最终成为主干网络的移动核心

## 长期主线

周野的目标分阶段变化：

> 找到家人并活下去 → 建成可自给的移动家园 → 连接孤立站点 → 建立互助交通网络 → 修复无尽轨道主干线

终局不是单纯称王，也不是把所有幸存者收入自己的列车，而是重新建立普通求生者也能安全通行、交换资源和抵达新区域的轨道网络。

## 调性边界

- 主角理性、不圣母，但不以虐杀和羞辱为爽点。
- 队伍收人看能力、信用与制度，不随意后宫化。
- 冲突优先通过资源、权限、路线、技术和组织能力解决。
- 反派不能全是无脑抢劫者，应有利益逻辑和不同生存方案。
- 感情线暂缓，未来采用单女主、慢热路线时不得挤压建设主线。
