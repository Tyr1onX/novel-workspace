# 当前短期大纲：曙光枢纽篇

范围暂定第14～30章。

## 第14～20章——已完成

- 抵达曙光，拒绝强制接管，改停外环。
- 核验1874名义人口与1362正常配给账户差异，锁定403个E-4异常账户。
- 签订零号相位锚联合部署协议。
- 揭示E-4节点、相位砂、人员轮换与返回者更名体系。
- 外环首次停电，移动站点建立独立供电和公开交易点。
- 恢复五号避难点求救：73人存活，2人重伤。

## 第21～24章：黑雾救援第一阶段——已完成

- 验证73人求救和乔原身份。
- 建立坐标标定桩、低频中继和旧工程支线导航方法。
- 送入过滤芯、药品、食物、300升净水和工具。
- 发现16.8公里处54.7米断口并架设临时单跨轨道桥。
- 验证三处漂移区和五号避难点装卸线。
- 改造轻型医疗列车，首批撤离18人。
- 建立外环临时观察区，恢复返回者原始账户和公开状态。

## 第25～27章：枢纽危机与零号设备部署

### 第25章《旧相位锚撑不住了》——已完成

- 首批返回使E-4真相进入公开状态，家属与居民持续关注账户板。
- 旧主锚输出升至181%，过滤腔仅2/4有效，并主动放弃三号外围节点。
- 安全边界收缩导致临时桥远端偏移7.3厘米、右侧拉索张力达到安全值93%。
- 周野决定第二批18人撤离与零号设备部署并行。
- 团队拆分：孙海峰、陈启、乔汐执行第二批撤离；周建国监测桥梁；林秀兰与孙晓雨管理观察区；梁文山、许成、周野参与主锚部署。
- 修复主锚井备用转换柜，使8组变频单元可用。
- 外围节点分级接入：一、二、四接入，五号独立保留，六七隔离，三号中断。
- 冷启动最低条件已满足，初始建议覆盖8公里，坐标可靠度76%。
- 周野与顾宁已完成双重权限接入，准备进入双锚重叠阶段。

### 第26章《把零号相位锚点亮》

- 正式执行双锚重叠切换。
- 旧主锚目标降至约60%输出，零号设备先建立8公里初始稳定区。
- 处理公共电网波动、坐标可靠度不足、三号节点中断与五号独立目标。
- 双端镜像日志首次在实际运行中发挥作用，记录每次功率、权限和参数修改。
- 第二批撤离列车正在返程，临时桥偏移逼近8厘米停止线。
- 初始覆盖优先稳定曙光核心与临时桥方向，不可直接解决五号避难点全部问题。

### 第27章《最后一批人》

- 在新旧屏障切换与临时桥稳定限制下完成剩余撤离。
- 第二批安全返回后，五号避难点剩37人，仍需至少3批。
- 乔原作为最后或接近最后一批返回，兑现负责人职责。
- E-4完整人员记录、节点损耗和返回者数据进入公开系统。
- 管理委员会必须正式处理更名、死亡补偿、家属和岗位恢复问题。

## 第28～30章：收获与离开

### 收获

- 曙光永久通行与停靠权。
- 北部区域轨道图。
- 相位防护与维护技术。
- 医疗合作或基础医疗设施。
- 零号研究所后续权限。

### 舒缓剧情

- 温室第一批生菜收获。
- 团队吃到进入求生世界后的第一顿新鲜饭菜。
- 建立正式配给、岗位、考察乘员和外部合作制度。
- 给移动站点正式命名。

### 卷尾

- 发现北部多个孤立小站求援。
- 周野离开曙光，开始主动连接站点。

## 本篇禁区

- 不融合整个曙光枢纽。
- 不连续增加大型车厢。
- 不把所有管理者写成坏人。
- 不让乔汐或陈启天然绝对可信。
- 不用一次零号设备启动解决全部E-4问题。
- 救援受能源、材料、载具容量、黑雾暴露和隔离能力限制。
- 不再每章使用倒计时、红色警告和区域公告。
