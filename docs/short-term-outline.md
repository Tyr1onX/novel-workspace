# 当前短期大纲：曙光枢纽篇

范围暂定第14～30章。

## 第14～16章：抵达曙光——已完成

### 第14章《陌生人的警告》

- 完成主体车厢、外部编组、能源和主要资源清点。
- 发现对外登记1874人，但基础口粮实际领取仅1368份。
- 周野拒绝主站台整编组控制，改走外环四号检修线。

### 第15章《这不是求援，是征用》

- 乔汐确认自己与匿名消息有关。
- 高绍明、温启川和顾宁分别体现管理、调度与技术立场。
- 周野拒绝无条件移交零号设备与研究资料。
- 双方签署72小时外环停靠与联合验收备忘录。

### 第16章《一千八百人的枢纽站》

- 展示居民区、课堂、公共洗浴、市场和配给中心。
- 周建国换到破冰模块碳刷及常用接口。
- 唐岚与农业区建立数据合作意向。
- 发现大量E-4冻结账户，以团队围桌吃饭收束。

## 第17～20章：失踪人口

### 第17章《少掉的四百个人》——已完成

- 通过基础配给、家属补贴、货运签收和账户状态交叉核验。
- 1874人与1362个正常配给账户相差512人，其中109人有公开去向。
- 锁定403个E-4关联异常账户。
- 最近一次E-4物资仅按148人核算。
- 发现47名疑似返回后更换身份者；陈维/陈启得到独立验证。
- 剩余208人没有口粮、医疗、返回或死亡记录。

### 第18章《零号设备该归谁》——已完成

- 正式部署谈判完成。
- 零号相位锚登记为区域公共安全设施，不归任何单一组织私人处置。
- 曙光取得日常使用权；移动站点保留运输舱、运输控制核心、能源隔离器与过渡期维护权。
- 高密度能源核心与相位锚永久绑定。
- 建立日常运行、超限授权、紧急关闭与双端镜像日志规则。
- 稳定运行24小时后，移动站点获得永久停靠权、市场准入、公共接口与北部轨道图。
- 陈启承认自己是从E-4返回后更名的陈维。

### 第19章《雾区采集队》——已完成

- 揭示E-4由七个外环稳定节点、维护队、采集队和物资转运体系组成。
- 相位砂只能从黑雾凝结物中取得，用于维持节点过滤器。
- E-4早期以高回报吸引志愿者，后期通过岗位轮换、处罚抵消和居民资格形成事实上的高压招募。
- 返回者因原账户死亡补偿、相位异常隔离和秩序保密而更换身份。
- 乔汐个人动机明确：哥哥乔原在五号节点失联，旧测绘密钥六天前仍有使用记录。
- 两个临时避难点位于三号、五号节点后方，理论容量约120人。
- 陈启开始补全旧工程支线与潜在救援路线。
- 结尾旧相位锚抢占公共电力，外环开始成片停电。

### 第20章《第一次停电》

- 外环、公共洗浴、低优先级维修区和部分居民车厢先断电；医疗与核心区使用备用能源。
- 周野不无偿承担全站能源消耗。
- 梁文山计算移动站点可安全输出的能源与持续时间。
- 移动站点开放有限供电、充电、保温和维修服务，以换取医疗物资、相位锚维护资料、正式市场准入和路线情报。
- 林秀兰参与建立普通居民能理解的收费与优先级规则；周建国、许成处理接口安全。
- 经营型爽点，展示移动站点已经拥有对外提供公共服务的能力。
- 不能让一次供电直接解决旧相位锚根本问题，也不能耗空自身能源。

## 第21～24章：黑雾救援

- 停电和交易使移动站点与居民、维修人员建立公开联系。
- 确认E-4避难点仍有幸存者的直接信号。
- 使用路线扫描、临时铺轨、工程机器人、外勤车、保温与相位隔离完成救援。
- 六号节点附近旧工程支线可作为候选绕行路径，但必须先验证。
- 不新增大型车厢。
- 救援带回幸存者、节点记录和旧相位锚真实损耗数据。

## 第25～27章：枢纽危机与部署

- 原有相位锚进入快速失效期，黑雾逼近关键设施。
- 零号设备正式接入旧屏障网络并开始24小时稳定运行。
- 部署需要顾宁技术组、陈启等E-4旧节点人员与移动站点共同完成。
- 委员会内部可能围绕控制权、E-4真相公开和撤离顺序发生冲突。
- 通过协议、镜像日志、技术依赖、居民选择和内部立场分化解决，不写简单屠杀。

## 第28～30章：收获与离开

### 收获

- 曙光永久通行与停靠权。
- 北部区域轨道图。
- 相位防护与维护技术。
- 基础医疗设施或医生团队合作协议。
- 零号研究所后续权限。

### 舒缓剧情

- 温室收获第一批生菜。
- 团队吃进入求生世界后的第一顿新鲜饭菜。
- 建立正式配给、岗位、考察乘员和外部合作制度。
- 给移动站点正式命名。

### 卷尾

- 发现北部多个孤立小站的求援与断线信息。
- 周野离开曙光，开始主动连接站点。

## 本篇禁区

- 不融合整个曙光枢纽。
- 不连续增加大型车厢。
- 不把所有管理者写成坏人。
- 不让乔汐或陈启天然绝对可信。
- 不用一次零号设备启动直接解决全部E-4问题。
- 不再每章使用倒计时、红色警告和区域公告。
- 至少每四章安排一章生活、经营或人物互动。
