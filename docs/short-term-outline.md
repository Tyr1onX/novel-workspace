# 当前短期大纲：曙光枢纽篇

范围暂定第14～30章。

## 第14～20章——已完成

- 抵达曙光，拒绝强制接管，改停外环。
- 核验1874名义人口与1362正常配给账户差异，锁定403个E-4异常账户。
- 签订零号相位锚联合部署协议。
- 揭示E-4节点、相位砂、人员轮换与返回者更名体系。
- 外环首次停电，移动站点建立独立供电和公开交易点。
- 恢复五号避难点求救：73人存活，2人重伤。

## 第21～24章：黑雾救援第一阶段——已完成

- 验证73人求救与乔原身份。
- 建立坐标标定桩、低频中继和旧工程支线导航方法。
- 送入过滤芯、药品、食物、300升净水和工具。
- 在54.7米断口架设临时单跨轨道桥。
- 验证三处漂移区和五号避难点装卸线。
- 改造轻型医疗列车，首批撤离18人。
- 建立外环临时观察区，恢复返回者原始账户和公开状态。

## 第25～27章：枢纽危机与零号设备部署

### 第25章《旧相位锚撑不住了》——已完成

- 旧主锚输出升至181%，过滤腔仅2/4有效，并主动放弃三号节点。
- 临时桥偏移7.3厘米、拉索张力93%。
- 第二批撤离与零号设备部署并行。
- 完成主锚井转换柜修复与外围节点分级接入。
- 冷启动最低条件满足，坐标可靠度76%。

### 第26章《把零号相位锚点亮》——已完成

- 双锚重叠切换开始，旧主锚逐步从181%降至60%。
- 镜像日志发现旧主锚自治服务自动启用“核心人口保护模板”，并记录中心与外围权重修改。
- 高绍明确认该模板是旧危机时期批准的应急方案；现在改为只能监测，任何重新启用均需周野、顾宁双重授权。
- 零号设备完成冷启动，输出提高至52%，建立8.2公里核心稳定区。
- 初始覆盖因三号节点中断向东偏移，无法触及临时桥。
- 四号节点不可逆地改作零号设备坐标中继，形成宽160米、延伸至临时桥的北部走廊。
- 临时桥偏移从8.1厘米回落到约5.1厘米，第二批18人安全通过并返回观察区。
- 五号避难点剩余37人。
- 零号设备进入初始运行，24小时连续稳定记录开始。
- 乔原从三号节点方向捕捉到新的E-4通用求援信号。

### 第27章《最后一批人》

- 先完成五号避难点剩余37人的分批撤离，不能因三号求援信号立刻打乱已经建立的路线和名单。
- 至少还需3次轻型列车往返；每次检查临时桥、北部中继和相位隔离设备。
- 乔原作为负责人应在最后或接近最后一批返回。
- 可在其中一次返程安排小规模信号验证，确认三号方向是否存在幸存者，但不在本章开启完整第二救援线。
- 零号设备初始运行期间不能随意提高输出或改变中继方向。
- 旧主锚维持60%备用，任何异常都必须写入双端镜像日志。
- 本章结束时让五号避难点清空，E-4完整人员记录回到曙光，并把三号信号留作下一阶段线索。

## 第28～30章：收获与离开

### 收获

- 零号相位锚连续稳定运行满24小时。
- 曙光永久通行与停靠权。
- 北部区域轨道图。
- 相位防护与维护技术。
- 医疗合作或基础医疗设施。
- 零号研究所后续权限。

### 舒缓剧情

- 温室第一批生菜收获。
- 团队吃到进入求生世界后的第一顿新鲜饭菜。
- 建立正式配给、岗位、考察乘员和外部合作制度。
- 给移动站点正式命名。

### 卷尾

- 三号节点或北部孤立小站信号成为后续路线线索。
- 周野离开曙光，开始主动连接站点。

## 本篇禁区

- 不融合整个曙光枢纽。
- 不连续增加大型车厢。
- 不把所有管理者写成坏人。
- 不让乔汐或陈启天然绝对可信。
- 不用一次零号设备启动解决全部E-4问题。
- 救援受能源、材料、载具容量、黑雾暴露和隔离能力限制。
- 不再每章使用倒计时、红色警告和区域公告。
