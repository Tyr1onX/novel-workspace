# 当前短期大纲：曙光枢纽篇

范围暂定第14～30章。

## 第14～20章——已完成

- 抵达曙光，拒绝强制接管，改停外环。
- 核验1874名义人口与1362正常配给账户差异，锁定403个E-4异常账户。
- 认识乔汐、高绍明、温启川、顾宁和陈启。
- 签订零号相位锚联合部署协议。
- 揭示E-4节点、相位砂、人员轮换与返回者更名体系。
- 外环首次停电，移动站点建立独立供电和公开交易点。
- 恢复五号避难点求救：73人存活，2人重伤。

## 第21～24章：黑雾救援

### 第21章《黑雾里还有七十三个人》——已完成

- 验证求救信号与实时数据。
- 确认乔原存活。
- 制造6只坐标标定桩。
- 初步验证六号旧工程支线入口。

### 第22章《先送进去一车物资》——已完成

- 按1.2吨载重精确装载并送入第一轮补给。
- 外勤车推进到16.8公里处，发现54.7米真实断口。
- 修复旧物资转送平台，将过滤芯、药品、食物、300升净水和工具送入。
- 避难点物资可维持9～10天。
- 获得73人完整名单与断口后路线图。

### 第23章《六号节点的旧支线》——已完成

- 使用轻型初始列车、8台工程机器人和轨道拓展工程子单元施工。
- 消耗能源12、基础建材36、机械零件10、电子元件2、轨道材料折算0.18公里。
- 在54.7米断口架设临时单跨轨道桥。
- 桥梁参数：限载18吨、限速5公里/小时、单车通过、稳定约72小时。
- 使用机械基准索、机械计数和钢轨震动识别黑雾造成的错误坐标、循环岔口与虚假墙面。
- 验证五号避难点外620米装卸线具备停靠换向能力。
- 形成单批不超过18人、至少4次往返的撤离方案。
- 乔汐与乔原首次直接通话。

### 第24章《把他们接回来》

- 第一批优先撤离2名无法移动者、7名需搀扶者和严重相位暴露人员。
- 轻型列车需加装担架固定、保温与临时相位隔离区。
- 单批不超过18人，不能一次撤完73人。
- 乔汐可参与外环接应或同行，但驾驶与路线判断仍由孙海峰、陈启负责。
- 漂移区、临时桥多次往返和伤员状态共同制造成本。
- 第一批返回后进入北区或新设隔离区，推动E-4真相无法继续完全隐瞒。

## 第25～27章：枢纽危机与部署

- 旧相位锚进入快速失效期，黑雾逼近关键设施。
- 零号设备正式接入旧屏障并开始24小时稳定运行。
- 顾宁、陈启与移动站点共同完成部署。
- 管理委员会内部围绕控制权、E-4真相和撤离顺序发生分歧。
- 通过协议、镜像日志、技术依赖和居民选择解决，不写简单屠杀。

## 第28～30章：收获与离开

### 收获

- 曙光永久通行与停靠权。
- 北部区域轨道图。
- 相位防护与维护技术。
- 医疗合作或基础医疗设施。
- 零号研究所后续权限。

### 舒缓剧情

- 温室第一批生菜收获。
- 团队吃到进入求生世界后的第一顿新鲜饭菜。
- 建立正式配给、岗位、考察乘员和外部合作制度。
- 给移动站点正式命名。

### 卷尾

- 发现北部多个孤立小站求援。
- 周野离开曙光，开始主动连接站点。

## 本篇禁区

- 不融合整个曙光枢纽。
- 不连续增加大型车厢。
- 不把所有管理者写成坏人。
- 不让乔汐或陈启天然绝对可信。
- 不用一次零号设备启动解决全部E-4问题。
- 救援受能源、材料、载具容量、黑雾暴露和隔离能力限制。
- 不再每章使用倒计时、红色警告和区域公告。
