## 新建小说约定

新项目统一建立：

`novels/<project-slug>/`

建议至少包含：

- `README.md`：平台、状态、当前进度和入口
- `chapters/`：正文
- `docs/` 或 `design/`：本书专属设定、大纲、人物、章节卡和连续性
- 平台运营资料如需要，也只放在本项目内部

跨小说复用的方法统一放在仓库根目录的 `shared/`，不要复制进每一本书形成多套不同版本。
