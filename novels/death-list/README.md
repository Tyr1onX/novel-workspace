## 核心卖点

每天凌晨零点，林默手机会出现一份死亡名单：姓名、时间、地点、死因。他可以提前介入，但名单展示的是当前高确定性死亡链下的结果字段；只改表面安排时记录可能继续存在或刷新，真正切断现实致死链后名字才会消失。

长期只保留这一套核心机制。禁止追加积分、商城、抽奖、技能树、任务惩罚、随机奖励或第二套系统。
