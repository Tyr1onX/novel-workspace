## 一句话卖点

每天凌晨零点，林默手机会出现一份死亡名单：姓名、时间、地点、死因。

他可以提前介入，但只改变表面结果时死亡信息会刷新；只有真正切断致死因果，名字才会从名单上消失。

## 核心承诺

这本书长期只围绕一个核心发动机推进：

> **看见高确定性死亡 → 验证 → 介入 → 表面结果被改变 → 找到真实根因 → 名字消失或付出失败代价。**

禁止追加积分、商城、抽奖、技能树、任务惩罚、随机奖励等第二套系统。
