# Death List：STYLE DNA

本文件定义《每天零点我都会收到一份死亡名单》的单本声音。共享 Humanizer / Prose / Dialogue 规则继续生效。

## 1. 叙事基调

- 近距离第三人称，默认跟随林默。
- 现实校园 / 城市质感优先，诡异感来自“正常生活里多出一个无法解释、却精确兑现的东西”。
- 不主动营造玄学腔、神秘存在注视感、宏大命运感。
- 悬疑依靠时间、地点、人物行为、物件和因果缺口，不靠旁白反复说“诡异”“恐怖”“不对劲”。

## 2. 节奏

- 开篇和危险章节尽快给具体倒计时或现实后果。
- 紧张不等于短句轰炸；句长随现场动作自然变化。
- 一个场景只追一个主要QUD，允许次级问题暂时悬着。
- 不把每章都写成“发现 → 正确分析 → 执行 → 成功 → 总结”。允许误判、信息晚到和部分失败。

## 3. 名单UI

名单是事实工具，不是文风主角。

原则：

- 新字段 / 新时间 / 新死因真正变化时再展示；
- 同一条信息不在旁白、对白、UI里重复三遍；
- 倒计时只在它改变人物决定时出现；
- 不连续大段刷系统提示制造字数和紧张感。

## 4. 悬疑写法

优先：

- 具体时间差；
- 人物为什么出现在这里；
- 现场某个原本普通的东西突然与名单对上；
- 一个已经处理掉的危险并未让名字消失；
- 两个人掌握的信息不完整且不一致。

少用：

- “他不知道的是……”全知预告；
- “真正的恐怖才刚开始”式作者预告；
- 结尾揭晓一个前文没有证据的新设定；
- 每个细节最后都证明是伏笔。

## 5. 情绪

默认：行为 + 普通直接情绪词 + 少量身体反应 + 留白。

林默可以直接“烦、怕、犹豫、后悔”，不把普通紧张连续写成心跳、喉咙、手心、后背、呼吸一整套。

死亡真正发生、救援彻底失败、熟人进入名单等峰值场景才允许更强感官密度。

## 6. 人物对白声音

### 林默

- 不是社交高手。
- 想确认事实时会问具体问题，但知道继续问会暴露异常时会停。
- 不把自己的推理完整说给别人听。
- 压力下更偏行动和短确认，不突然说漂亮的人生句。

### 周屿

- 宿舍熟人关系，注意力经常在游戏、上课、吃饭、迟到等自己的事情上。
- 可以损林默，但梗来自当场旧账和现实，不成为常驻吐槽机。
- 没理由追问时不会替读者追问名单机制。

### 苏晚

- 观察与证据意识强，但不是百科全书。
- 她首先维护自己的判断权，不因为主角是主角就自动配合。
- 问问题有社会成本；如果林默闪躲，她会选择自己核查，而不是连续采访。
- 与林默形成搭档后仍保留自己的任务、判断和错误。

### 李建国

- 老师身份下说话服务课堂秩序和教学，不承担“慈祥导师”模板。
- 在不知道危险时不会配合林默完成悬疑说明。

## 7. 生活纹理

校园 / 城市场景里的普通人首先忙自己的事。

可出现：

- 赶课；
- 点名；
- 游戏；
- 食堂；
- 电梯；
- 校园群；
- 轨道交通延误；
- 医院挂号；
- 门禁；
- 校媒采访；

但细节首先属于现场，不要求全部服务伏笔。

## 8. 章节结尾

优先停在：

- 名单出现新的具体变化；
- 某个死亡时间被刷新；
- 名字消失 / 没有消失；
- 人物被迫做出的动作；
- 新证据改变当前问题；
- 一个角色看到不该看到的结果。

禁止用作者总结：成长、命运、责任、答案、真正的开始。
