# 第49章 你们扔掉的滤芯，我要了

第二天一早，唐岚先去后仓。

六十多支废滤芯还在原位。

她在最外面那排挂了一张纸。

【待分层复检】

何庆看见以后笑。

“昨晚还说先别动，今天就归你管了？”

“我没说归我。”

唐岚拍了拍那张纸。

“你们扔掉的滤芯，我要了。”

“先把能用的东西挑出来。”

旧热洗滚筒被拖到车间空地。

外壳还完整。

里面三根加热管已经断了，控制箱被潮气腐蚀得发绿，滚筒轴承转起来发涩。

何庆说：“以前颗粒碳和一部分树脂都在这里处理。”

孙海峰问：“坏两年都没修？”

“会修，不代表有件换。”

“沉泉不是说不缺维修？”

“我们不缺会修的人。”

何庆看向周野。

“缺的是把几样旧东西重新拼成能用设备的人。”

蒋岑也没绕。

“设备可以给你们改。”

“废滤芯按刚才谈的处理，能拆出什么，先登记再分。”

周野问：“机器归谁？”

“沉泉。”

“那就不动主水线。”

他把目标一件件放进融合识别。

旧热洗滚筒。

QX-07货物除湿系统能提供的一段废热软接。

一台小型机械离心装置。

沉泉原有的分层卡具。

几组可调流量泵。

系统很快给出三个方向。

【整支滤芯清洗机】

【分层滤材再生工作台】

【高温颗粒碳再活化装置】

周野选了第二个。

【预计功能：机械分层 / 低温与中温热洗 / 废热干燥 / 离心脱水 / 分批再装】

【不包含：微生物最终验证 / 未知污染物净化 / 严重破损材料修复】

蒋岑盯着最后一行。

“这个可以。”

“你不想做成更强的？”孙海峰问。

周野扫了一眼额外材料需求。

“更强要改沉泉主线。”

蒋岑直接说：“不改。”

“那就这样。”

融合开始。

旧控制箱先脱落。

还能使用的滚筒骨架缩短，外侧重新形成四只可拆处理筒。

QX-07的废热只通过软接进入顶部接口。

归途站开走以后，软接拆掉，沉泉仍能换回本地热源。

离心装置压进底座。

原来的单规格卡具改成三组可换夹具。

半分钟后，一台比旧滚筒矮了一截的新设备停在车间里。

【分层滤材再生工作台建立完成。】

【当前归属：沉泉净水站固定设施。】

【归途站获得结构经验：滤材再生Ⅰ。】

孙海峰第一句话还是：“真不带走？”

何庆在旁边听笑了。

周野说：“机器本来就是沉泉的。”

“结构经验已经拿到了。”

何庆走到工作台前，这回没再抱着胳膊看。

“那干活。”

昨天十只样本拆下来的材料重新过了一遍。

外层纤维只洗到压差恢复，降级做前置粗滤。

颗粒碳进热处理筒。

离子交换层由何庆配再生液。

唐岚刚伸手，就被他挡回去。

“这个你别碰。”

“我就看。”

“看可以，别闻。”

有裂纹的陶瓷直接进报废箱。

剩下的重新组合。

十只废芯的可用材料，最后配出六只待测试滤芯。

孙晓雨看着数量。

“别写六成。”何庆先说。

“我还没写。”

“怕你顺手。”

“我账没这么做。”

六只接上独立测试线。

第一小时，压差正常。

第二小时，浊度稳定。

第三小时，吸附指标比昨天那支直接清洗的试件高了一截。

蒋岑只说：“继续跑。”

唐岚问：“一句好话都没有？”

“滤芯听了能多跑一天？”

唐岚翻了个白眼，没再跟她争。

到第二天凌晨，六只都没有立刻失效。

最差一只保持在新滤芯六成以上。

最好的一只接近七成五。

蒋岑在记录上写：

【可继续测试】

孙晓雨立刻凑过去。

“水价？”

“等三天。”

“我就知道。”

话音刚落，主处理车间响起短促报警。

何庆脸上的笑瞬间没了。

“哪条？”

“二号原水线。”

值班员把曲线投到墙上。

原本稳定的进水浊度突然抬头。

水槽里浮起一层细密灰白悬浮物，像地下某一层沉积被翻了起来。

二号过滤线压差正在往上走。

何庆看完第一组数据。

“这种水质，新滤芯也耗得快。”

蒋岑已经让人切低流量。

“先保护居民主线。”

周野看向刚接在独立测试线上的六只再生滤芯。

蒋岑马上说：“不进居民饮用水。”

“我也没让它进。”

他指向车间角落一条停用旁路。

“原水分一小股。”

“过旁路，出水不进饮用水箱。”

“你要三天测试，现在正好有真的脏水。”

蒋岑看了两秒。

“走旁路。”

何庆已经转身去拿接头。
