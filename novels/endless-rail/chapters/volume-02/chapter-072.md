# 第72章 前六辆车从哪来

接驳车过桥用了两分多钟。

孙海峰全程没碰五公里以上。

车轮每压过一段接缝，桥底都会传来一声很闷的回响。

马立平坐在旁边，平时话不少，这会儿一句都没说。

直到最后一组轮轴完全离开桥面，他才往后看了一眼。

“还在。”

孙海峰说道：“你这话说得我更紧张了。”

桥头的灰帽男人已经把黄旗收起来。

他递来一块巴掌大的铁牌。

上面压着三个字。

【东桥07】

“挂车头。”

“今天有效。”

“只进东货场，不往生活区开。”

周野接过铁牌。

“登记在哪？”

“前面。”

男人指了指黑雾里那三盏货位灯。

“别跟着旧站牌走。”

“看白灯。”

接驳车继续往里。

旧港真正露出来以后，和周野想的完全不一样。

没有一百多人挤在站台等救援。

也没有人看见陌生列车就围上来。

东货场只有两条短轨。

一条进秤房。

一条靠着低矮货台。

三辆不到十吨的小轨道货车停在里面。

有人卸木箱。

有人往另一辆车上搬装着干菜的麻袋。

最里面还停着一只焊得很丑的水罐。

所有人都在干自己的活。

归途站这辆陌生接驳车进来，只换来几次抬头。

孙海峰慢慢把车停到白线后面。

“这叫失联？”

许成看着沿货台排开的机械路牌。

“对我们失联。”

“跟别人不一定。”

秤房就在旁边。

一间不到二十平方米的旧砖房。

墙上挂着当天入站表。

最上面已经有六行。

第七行刚写了一半。

【07 归途站】

灰帽男人坐到桌后。

“人。”

周野报了四个。

“周野，孙海峰，许成，马立平。”

“货。”

“桥夹板四块，维修工具，独立牵引电池一组。”

男人停笔。

“卖不卖？”

“不卖。”

“那写自用。”

他真只写了这辆车上的东西。

周野等了一会儿。

“不要全部库存？”

男人抬头看他。

“我登记你这辆车。”

“你整个站有多少东西，关东桥什么事？”

周野没说话。

最早收到旧港那条正式消息时，对方要求外来列车提交完整成员和库存。

后面还有人偷偷提醒他们别交。

现在桥头这套规矩显然不是一回事。

“中转委员会还在？”周野问。

灰帽男人笔没停。

“在里面。”

“你要找他们，进货场以后自己问。”

“东桥只管车能不能进、带什么进。”

他说完，把登记本往前推了一点。

“签。”

周野签完，没有马上走。

目光停在前六行。

灰帽男人顺着他看过去。

“想看？”

“想知道我们前面六辆从哪来。”

“看可以。”

“别拿走。”

孙海峰立刻凑过来。

前六行很简单。

【01 南堤菜棚 / 4.31t / 鲜菜、腌菜】

【02 北岬外仓 / 5.08t / 滤材、电池壳】

【03 灰坡拆解场 / 6.42t / 废铜、旧轴承】

【04 南堤菜棚 / 3.76t / 干菜、种薯】

【05 北岬外仓 / 4.89t / 密封件、照明件】

【06 灰坡拆解场 / 5.97t / 电机旧件、钢板】

孙海峰第一眼就盯上了第二行。

“北岬？”

“他们不是不让外来列车进吗？”

灰帽男人终于笑了一下。

“是不让进站。”

“没说不换货。”

“外仓在他们站外两公里。”

“车到第一道牌停。”

“他们把东西推出来，你把东西留下。”

“谁都别往第二道牌后面走。”

孙海峰沉默两秒。

“规矩还挺大。”

“那你别去。”

“我也没说一定去。”

马立平指着另外两个名字。

“南堤和灰坡是什么站？”

“不是站。”

灰帽男人把登记本翻到后面。

“南堤原来是防洪维护点，后来几座菜棚的人凑一起住。”

“灰坡是旧拆解场，三拨人轮着拆废车。”

“都没完整站台。”

“重车也进不去。”

许成问：“他们怎么到旧港？”

灰帽男人朝墙上一张发黄的线路图抬了抬下巴。

图上大部分线已经被红笔划掉。

剩下的只有三条细线。

一条向北。

一条沿南侧堤线。

一条绕向东南的旧维修区。

每条线旁边都挂着不同颜色的小铁片。

黄。

绿。

灰。

“黄牌去北岬外仓。”

“绿牌去南堤。”

“灰牌去灰坡。”

“东桥这边的白牌，只管你们刚走的炉坪维护廊。”

孙海峰看了看车头那块【东桥07】。

“所以给我们的是白牌？”

“临时白牌。”

“出了旧港东货场就没用。”

周野问：“其他三条路能走吗？”

灰帽男人回答得很快。

“有牌能走。”

“谁给牌？”

“谁的路谁给。”

“旧港不给？”

“旧港只认牌。”

“不给别人替北岬答应，也不给北岬替南堤答应。”

这套规矩不复杂。

甚至有点土。

可正因为简单，反而跑了很久。

许成把线路图上的三个方向记下来，又对照今天六辆车的轮轴、车重和进站时间。

路线扫描器很快多出三条浅灰线。

没有变成绿色可用路线。

只多了一行状态。

【实体往返痕迹：确认】

【当前通行授权：无】

许成把终端递给周野。

“路是真的。”

“我们现在不能跑。”

“这样就够了。”

周野没让他继续往外探。

他们今天要弄清的是前六辆车从哪来。

不是拿到旧港所有路线。

货场外忽然传来一声铃。

灰帽男人站起来。

“让一下。”

孙海峰往窗外看。

桥头翻牌器刚刚转过一格。

【今日第8车】

一辆只有一节的黄色平板车慢慢进来。

车头挂着黄牌。

车厢两侧没有窗。

后面码着四只密封箱和两捆灰色滤材。

车身上用白漆刷着一行很小的字。

【北岬外仓】

平板车停到秤房前。

驾驶员没下车。

只从窗口递出一张货单和一块黄色铁牌。

灰帽男人核了一眼。

“4.62。”

“二号货位。”

对方点头。

从头到尾一句话没说。

几分钟后，旧港的人开始卸滤材。

另一边则把两箱真空包装的干菜和一只装满旧密封圈的周转箱推上车。

没有讨价还价。

货单上显然早写好了。

孙海峰站在旁边看了一会儿。

“所以北岬那句‘不接受外部列车进入站台’……”

“是真的。”周野说。

“人家只是没说后半句。”

黄色平板车装完就走。

进旧港不到十五分钟。

没有进入生活区。

也没见什么负责人。

灰帽男人把它的黄牌挂回墙上，在当天入站表补了一行。

【08 北岬外仓 / 4.62t】

然后，他从抽屉里又拿出一块白色铁牌，丢给周野。

和桥头那块不一样。

上面压着：

【东货场·访客】

“你们车今天能停到下午六点。”

“想问中转委员会，往里走第三个门。”

“想问商路，等老钱睡醒。”

马立平立刻抬头。

“老钱还真在？”

“在。”

“昨晚守西门，刚睡。”

“你敢现在叫他，他先骂你。”

马立平把嘴闭上了。

秤房外，翻牌器还停在第8车。

远处南侧轨道上，一盏绿色小灯已经亮了起来。

灰帽男人看了一眼墙上的钟。

“第九车快到了。”

“南堤的。”

“你们要看，就别把车堵在二号货位。”
