# 第86章 下一批六只，先检再洗

“下一批如果还送，你们怎么收？”

三号收货那边的话落下来以后，孙晓雨没有马上回答。

她把昨天夹在一起的四张成本页重新摊开。

B17用了四十九升水，QX-07二十六分钟，干燥十四小时零九分。

B21用了二十九升水，处理到最后仍退出整筒复用。

C04从初检就停了，没进清洗线，只做了十八分钟拆检。

C09用水三十四升，干燥十二个半小时，最后落到前端粗滤位。

同样四只旧筒，成本差得太远。

孙晓雨问北岬：“你们下一批打算送多少？”

“仓里还有二十多只。”

“我问下一批。”

对面顿了一下。

“你们能一次接多少？”

许成先看向干燥箱。

“六只封顶。”

孙海峰问：“昨天不是说箱里能放四只？”

“同时干四只。”许成说，“另外两只可以错开处理。再往上堆，前一批没出箱，后一批就会堵在QX-07旁边。”

周野问：“测试架呢？”

“一只一只跑，六只还能排。”

“水呢？”

孙晓雨翻过B17和C09的页。

“按这四只的结果，不能算平均数往后乘。”

许成点了点C04那张纸。

“这种进门就能看出支撑网断了的，没必要给它准备四十升水。”

北岬女人在通信里问：“所以先挑？”

“先做入站初检。”周野说，“能不能进处理线，检查完再定。”

“你们怎么收这个检查？”

孙晓雨把一张空白货单拉过来。

她先写了四个字。

【入站筛选】

“所有送来的筒都要过这一项。”她说，“外观、支撑网、端盖、明显塌陷和可见污染先看。像C04这种，到这里就停。”

北岬问：“停了也算？”

“算初检。”

“洗都没洗。”

“占了人和拆装位。”

孙晓雨继续往下写。

【进入QX-07：清洗水 / 管路占用 / 人工 / 特殊检查按实际发生记录】

【中途停止：已经发生的处理成本照实结算】

【干燥 / 流阻复测：实际进入该阶段才追加】

许成说：“结构拆检单列。”

【结构件拆检：北岬确认后执行】

北岬水线的人问：“一只旧筒一直吃水怎么办？”

许成把B21的记录抽出来。

“分段。低压首段最多二十升，没到二十升看出结构问题也停。”

“要反向处理，先重新看滤褶、支撑网和湿态流阻。反向单段最多十二升。”

“还值得继续，追加处理每段最多十升，再检查。”

“总上限呢？”

“不给所有旧筒一个死数。出现支撑断裂、滤层分离、继续塌陷，直接停。明显没整筒复用价值，也不拿水洗颜色。”

“追加处理要我或蒋岑确认还有价值。水处理分级最后由蒋岑判断。”

孙晓雨在旁边补了一句。

【阶段水量是检查点，不是必须用完的额度】

北岬换了一个问题。

“怎么换物资？”

“上一批是试批价。”孙晓雨说，“下一批六只的入站筛选，换FQ-42密封圈六只。”

“处理呢？”

“进QX-07就开单只成本页。水、管路、人工、特殊检查记到哪儿，结到哪儿。”

她把粗滤材写进处理栏。

【单只受控处理 + 实际进入的干燥 / 流阻复测：累计结算上限为同规格粗滤材0.6m × 1.2m】

“没做的阶段不收。预计超过这个上限，先停，重新报成本，你们确认后再做。”

北岬水线的人问：“B21那种最后不能整筒用呢？”

“结果不抹掉已经发生的成本。”许成说，“能在初检停就不进QX。进了线，做到哪儿记到哪儿。”

“拆检？”

孙晓雨写：

【结构件拆检：每只换防水接线盒1只】

“只在你们确认要拆的时候做。初检退出，也可以原样拿回去。”

三号收货那边算了一会儿。

“六只筛选先锁六只密封圈，处理按实际成本页结，拆检另算？”

“对。”

“最后按实际记。”

北岬女人没立刻答应。

她问：“运输怎么算？”

周野抬眼看向孙海峰。

上一批这部分没有单独列出来。

北岬的黄牌车先把脏滤筒从外仓送到旧港。

白03从炉坪去旧港接货，再回炉坪。

处理结束以后，白03还得重新从炉坪去一次旧港，把处理件和退出件送回去。北岬的黄牌车也要再来旧港取。

这是两个不同时间的接驳任务。

孙海峰把最近几次白03记录调出来。

“接进来一次，回送一次。”

“每次都是炉坪出车、旧港交接、再回炉坪。炉坪放行本也得签两次。”

“六只一次能带完吗？”周野问。

“能。只要别混别的重货。”

旧港刚好回了货位登记。

【FQ-42旧筒 / 单次中转货位 / 不超过24h】

孙晓雨问：“这个只算脏筒交接？”

“对。”北岬女人说。

“处理完的回送呢？”

“到时候另约。”

处理会跨过清洗和干燥，明天这一个中转窗口不可能一直占到回送。

孙晓雨把运输栏拆成两行。

【入站中转：北岬黄牌车送旧港 / 白03接回炉坪】

【回送中转：白03送旧港 / 北岬黄牌车取回】

周野说：“黄牌车两次任务，你们自己出。”

“可以。”

“旧港两个中转时段，也按实际回单由你们结。”

“可以。”

“白03呢？”

“按实际发生的接驳任务算。”孙晓雨说。

许成从北岬的电气清单里挑出二十四伏灯条。

孙晓雨确认规格后写：

【白03炉坪—旧港—炉坪：每实际完成1次往返 / 24V同规格灯条4m】

孙海峰指了指两行运输记录。

“这批完整送进来再送回去，正常就是两次。”

北岬女人算了一下。

“八米灯条。”

“两个任务都实际发生，就是八米。”孙晓雨说，“回送没发生，不提前算。”

“超过六只不接。”周野说，“剩下的继续留在北岬，等这一批出结果再谈。”

“你还是不肯给个复用率？”

周野看了眼桌上那四张N-3-3成本页。

“没有那个数据。”

北岬女人笑了一声。

“行。”

她把话题转到时间。

“黄牌车最早明天下午能到旧港。”

“先让旧港确认货位。”周野说，“白03也要炉坪登记。”

“你们外仓线呢？”

“照旧。”

外仓线务的回复被转进来。

【下一批技术货运可继续按既有中转方式执行】

【通行状态：不变】

孙晓雨把记录放进N-3页，没有往路线账上加任何新牌。

北岬女人问：“编号还是N-3？”

“下一单N-3-4。”

孙晓雨新建货单。

这次她没把刚才谈过的每一项再抄一遍，只留下执行时必须先看见的几行。

【N-3-4 / 数量上限：6只】

【结算：先筛选；进入QX-07后按实际发生记账；中途停止照实结算；未进入的后续阶段不计】

【受控处理：20L首段 / 反向单段≤12L / 追加单段≤10L；每段复核，结构异常或已无复用价值立即停止】

【运输：入站接驳1次 + 回送接驳1次；白03每实际往返换4m灯条；旧港两次中转窗口按实际发生由北岬承担】

【北岬外仓线：通行状态不变】

【本批结果独立记录，不并入N-3-3】

三号收货确认以后，没有立刻报六只编号。

“我们先去仓里挑。”

通信断开前，北岬女人又问了一句。

“如果六只全过初检，你们多久能做完？”

许成看着干燥箱里空出来的四个位置。

“先把六只送到旧港再说。”

晚上九点四十，旧港回了货位确认。

白03登记窗口也给出了明日下午的空档。

孙晓雨刚把两条信息挂进N-3-4，北岬那边又发来一张外仓照片。

六只旧筒已经排在黄牌车旁。

最左边那只的标签上写着：

【A06】

第二只：

【A11】

剩下四只的编号还被绑带挡着。

照片下面只有一行字。

【外仓初筛完成，六只。】
