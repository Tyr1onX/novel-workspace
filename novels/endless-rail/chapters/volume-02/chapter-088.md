# 第88章 第二次白03回来以后，N-3-4结单

A06在低温通风箱里过了一夜。

第二天早上，许成没有把所有称重过程重新摊开。

重量稳定以后，他只把最后三次结果留进成本页。

【A06 / 稳定干重：4.52kg】

【低温通风干燥：11h18min】

测试架低流量点跑了两轮。

第二档再跑两轮。

曲线没有出现B21那种周期性跳动，平均阻力比新件参考高得更多，第二档接近三成。

蒋岑看完远程记录，只问了一句。

“结构有没有新的硬折？”

“没有。”

“滤层有没有继续起毛？”

“没有。”

“那就前端。”

A06的最终标签改成：

【降级复用 / 雨水与冷凝回收水前端粗滤】

【不回一级预滤】

许成把它从测试架上卸下来。

这一只已经没有继续处理的必要。

孙晓雨把它的二十六升清洗水、QX-07占用、干燥和复测时间补齐，翻到下一页。

E02、D03和E09的处理从前一天傍晚一直排到今天上午。

三只都按各自状态处理，没有照搬B17、B21、C09的全部步骤。

只有会改变处理决定的地方被留下。

E02低压首段十四升时，回水已经很浅。

湿态检查没有异常，反向六升以后停止。

干燥复测结果稳定，平均阻力高于新件参考约一成。

最终和A06一样，降到前端粗滤位。

D03在首段做到十七升时，上端盖锈蚀处开始渗出细小锈粉。

滤层本身没有断。

许成把端盖位置洗净后重新看了一遍。

锈蚀已经吃进卡口边缘。

继续冲洗能让滤材更干净，却改变不了端盖的机械状态。

北岬水线的人看完近照，问能不能直接换端盖。

“可以拆。”许成说，“但那就进入结构件处理，不属于整筒继续洗。”

“你们想要的是复用这个筒，还是回收里面还能用的件？”

三号收货那边讨论了几分钟。

“D03停整筒。”

“结构件拆检做。”

孙晓雨把确认时间写进去。

【D03 / 低压首段17L后停止整筒处理】

【停止原因：上端盖卡口锈蚀进入结构边缘】

【结构件拆检：北岬确认执行】

这一只已经发生的清洗水、QX-07和人工照常进入单页。

结构拆检另加一只防水接线盒。

拆开以后，中心支撑筒和下端盖都能留作待复检件，上端盖退出。

E09最省事。

它的表面污染不重，首段十二升以后，许成发现中段两排滤褶一压就粘在一起。

放手后只能缓慢张开。

蒋岑让他看褶底。

滤材没有撕裂，但整段弹性已经明显差。

“别洗颜色了。”

E09停在十二升。

北岬这次没有再问为什么不把二十升跑满。

孙晓雨只把已经发生的十二升和处理时间记进去。

没有干燥。

没有复测。

没有拆检。

六只的最终结果在上午十一点前全部落定。

孙晓雨把六张单页摊成两排。

她没有算百分比。

也没有拿N-3-3的四只和这六只拼成十只再算。

本批摘要只写结果。

【N-3-4 / 6只入站筛选完成】

【A06：降级前端粗滤】

【A11：8L处理中止 / 退出整筒处理】

【D03：17L处理中止 / 转结构件拆检】

【D14：初检退出 / 未进入QX-07】

【E02：降级前端粗滤】

【E09：12L处理中止 / 退出整筒处理】

【本批结果独立记录】

下面是结算。

六只入站筛选，对应六只FQ-42密封圈。

A06、A11、D03、E02、E09进入过QX-07，各自按实际发生的水、管路、人工和实际进入的后续阶段结算。

D14只有筛选。

D03多了一项已经确认的结构拆检。

没有任何一只被塞进统一固定价。

北岬把成本页看完以后，三号收货先问D03。

“拆下来的下端盖能不能直接当备用？”

许成回答：“复检以后再定。”

“现在只写待复检。”

“行。”

对面又问：“这批做完，剩下那些旧筒还能继续送吗？”

周野看着货单。

“能按同一套流程再申请。”

“但不是现在自动续单。”

“归途站的处理位要回正常任务。”

北岬女人没再追数量。

“那把六只送回来。”

旧港回送窗口约在下午两点半。

炉坪那边也给白03排出同一时段的放行。

孙海峰把六只重新装进周转架。

两只能降级复用的贴黄色标签。

三只退出整筒处理的贴红色标签。

D03的可复检结构件单独装袋，原筒壳也跟着回去。

D14保持原样。

“少没少？”孙晓雨问。

孙海峰沿着架子数了一遍。

“六只都在。”

“结构件袋一只。”

“成本页副本一套。”

下午一点五十五，白03第二次从炉坪出发。

这次带出去的是处理后的六只。

旧港没有给它沿用上一次入站的货位。

回送重新开了一张中转单。

【N-3-4回送中转 / 一号货位 / 40min】

白03两点二十七到达。

北岬黄牌车两点三十五进入旧港外侧交接区。

黄牌车司机先核编号。

A06、A11、D03、D14、E02、E09。

六个封签完整。

北岬女人通过通信看着D03的结构件袋。

“这个防水接线盒算拆检？”

孙晓雨说：“算一只。”

“其他没有拆检。”

“知道了。”

旧港工作人员在货位单上签了交接完成。

黄牌车没有多停，六只旧筒重新装车以后直接离开。

白03也没有继续向北。

孙海峰在旧港掉头，按原路返回炉坪。

归途站主体从头到尾没有进入维护廊，更没有接近北岬外仓线。

北岬没有把交换物留到下一次再说。

黄牌车这趟来取回六只旧筒时，后厢还带着已经按成本页核过的结算物。

六只FQ-42密封圈装在一个小盒里。

五只实际进入QX-07的处理件，按各自发生的水、设备和后续阶段折算成同规格粗滤材，合计零点六米宽、四点四米长。

D03的结构拆检另有一只防水接线盒。

白03两次往返对应的八米二十四伏灯条也卷成两盘，分别贴着“入站”和“回送”。

孙晓雨在旧港现场只核数量和规格，没有把几项交换混成一个总价。

“密封圈六只。”

“粗滤材零点六乘四点四。”

“接线盒一只。”

“灯条八米。”

北岬女人逐项确认。

“和成本页一致。”

这些东西装上白03，结算也在这一趟完成交付。

孙海峰回炉坪时，车上没有六只旧筒了，只剩四类结算物和一套签过字的回单。

下午三点十九，白03回到炉坪。

赵琴翻开放行本，先看里程，再看回程时间。

“第二次往返完成。”

孙晓雨就在旁边补上最后一行。

【白03实际往返：第2次】

【对应交换：24V同规格灯条4m】

【N-3-4白03运输结算：共8m灯条】

这次八米全部有对应的真实往返。

旧港的两次中转也各有自己的回单。

北岬黄牌车的入站送货和回程取货由北岬自己承担。

N-3-4货单上已经没有待发生的运输项目。

【N-3-4：结算完成】

QX-07旁边的临时周转区开始清空。

A11留下的表面黑点样本只保留一个小袋，和N-3-4成本页一起归档。

蒋岑的远程通信也退回普通水处理联络。

这条滤筒服务从今天开始已经有了可重复使用的流程，但不再占着整个归途站的工作台。

赵琴没有直接转成任务。

她先把原始记录发给周野。

【K-17道岔 / 本周第三次重载通过后锁闭时间延长】

十二只低温柴油桶。

“这个比上一次高了快四成。”

“空桶回去还要收一趟？”

“要。”

“而且K-17这次得先拆开看。”
