# 第99章 八百一十七毫米，差三毫米就卡住

麦丘新一批热粮包装车前，韩序把最宽那块托盘单独推出来。

卷尺压在边缘。

八百一十七毫米。

归途站导轨净宽八百二十。

理论上能进。

孙海峰蹲下来，看了看托盘左前角。

那里的木板已经起毛。

如果推车稍微偏一点，三毫米根本不够。

韩序问：“换托盘？”

孙晓雨没有立刻回答。

这一批一共六块托盘。

两块八百毫米。

两块八百零四。

一块八百零九。

最后一块八百一十七。

托盘上的热粮包都已经封装完成。

把所有箱子拆散重装，要多用近一个小时。

只处理最后一块，会快很多。

周建国看过以后给出建议。

“八百一十七这块别进导轨。”

“八百零九的也先看四角。”

第二块问题托盘四角完整。

实际推入时还有余量。

八百一十七那块则换成归途站自己的七百六十毫米金属周转托盘。

二十四箱热粮包重新码一次。

用了十一分钟。

比全批重装快得多。

旧木托盘留在麦丘。

韩序当场给木板做了记号。

【不再用于归途站导轨装载】

这次没有卡死。接口表里“可直接使用 / 余量小”的黄色提醒提前拦住了一次可能的堵车。

孙晓雨没有满足于继续量宽。

问题已经从“站台怎么靠”进到“货本身怎么装”。

同一座站提供的货，包装状态也会变。

她把最近三班的货单摊开。

热粮包用木托盘。

北岬密封圈常用小周转箱。

废灯具用绑带架。

白栎检验耗材有恒温箱。

沉泉生活水是二百升周转水箱。

暖桥水泵带金属运输架。

这些东西不能只写“多少箱”。

至少要让装车的人提前知道它占多少空间、能不能叠、需要什么环境。

孙晓雨先做了一个很小的分级，只按运输处理方式，不按货物价值。

【A类：普通可直接装载】

【B类：需要指定托盘 / 桥板 / 固定方式】

【C类：温控、洁净、液体或其他特殊条件】

热粮包正常托盘是A。

八百一十七毫米变形托盘上的那批在换托盘前是B。

白栎恒温箱是C。

沉泉生活水也是C，但特殊条件写“洁净水路 / 立放 / 固定”。

暖桥水泵是B。

北岬旧灯具如果只用普通周转架，就是A。

韩序看完问：“A是不是就随便装？”

“不是。”

孙晓雨说。

“A只表示不需要额外接口和特殊环境。”

“重量、尺寸还要写。”

她把每一类都压到最少字段。

货物名称。

总重。

外廓尺寸。

能否叠放。

装卸方式。

特殊条件。

没有再加十几项检查。

第一张按新分级填写的是麦丘这批热粮包。

【热粮包 / A】

【托盘：760mm金属周转盘×1；合格木托盘×5】

【总重：按交接称重】

【可叠放：2层】

【特殊条件：防潮】

这张单一到归途站货运区，孙海峰不用再去问哪块托盘最宽。

第二张是沉泉S-25。

【生活水200L / C】

【立放 / 不叠放】

【50mm快接】

【生活水专用洁净件】

【到暖桥需50→40转换】

段守成收到以后回了一句。

“这次转换头已经挂墙上。”

第三张是北岬准备送来的六箱电气小件。

三号收货照着模板填。

【电气小件 / A】

【单箱≤18kg】

【可叠2层】

【无温控】

孙晓雨看完，发现缺外廓尺寸。

北岬回：“箱子都差不多。”

“差不多是多少？”

十分钟后，对面补了长宽高。

这一步看起来麻烦。

第二天旧港排货位时却直接用上了。

一号货位同时有两批货。

北岬六箱电气件。

另一辆外来轻车四箱维修材料。

旧港根据尺寸先把北岬六箱排到内侧。

白03到以后，整批可以一次装完。

没有再现场挪箱。

原本三十分钟的货位只用了十八分钟。

旧港工作人员看着单子说：“尺寸这项保留。”

他们没有接受孙晓雨整张分类表。

只把自己有用的尺寸和叠放信息抄进旧港货位预约。

这很符合周野的边界。

各站可以拿自己需要的字段。

归途站不要求所有人使用同一张表。

第四张新分级单来自白栎。

一只移动冷藏箱要跟下一班去暖桥。

以前货单只写“检验试剂一箱”。

这次白栎补了：

【C类 / 需要连续供电】

【不可叠放】

【运输温度：按白栎随箱记录执行】

【到暖桥使用AC-01专用接口线】

孙海峰装车时，这几行直接改变了货位。

原本他准备把冷藏箱放在普通小件架下层，上面还能再压两箱密封圈。

看到“不可叠放”以后，他把北岬小件移到另一侧。

冷藏箱单独占一个低位。

电源线也提前从车内恒温电源口引好。

出发前，许成只做供电确认。

没有重新拆开包装检查医疗内容。

宋雨眠负责医疗条件。

归途站只保证运输环境。

到暖桥以后，AC-01已经和冷藏箱放在同一货位。

车门打开就能一起取下。

上一次六分钟接电，这次压到四分钟以内。

段守成看着C类标签，问：“以后C都优先？”

孙晓雨摇头。

“C只说明运输条件特殊。”

“是不是优先，看任务。”

“这箱如果没有时间要求，就不会因为贴C把别人的急件挤掉。”

装载条件和任务优先级被明确分开。

这一点也写进v0.1的说明栏。

旧港很快又给了这个分级一个边界例子。

一只四百八十公斤的维修件准备从一号货位转给炉坪。

尺寸能进。

没有温控。

按处理方式却不能写A。

因为归途站P-01当前正式使用上限只有四百公斤。

旧港自己的桥板现场限值是五百公斤。

孙晓雨把它标成B。

【B类 / 指定旧港1号自有桥板】

这件货通过旧港桥板完成转运，没有调用P-01。

同一处货位上，“有桥板”也不等于哪块桥板都能用。

装载等级开始同时引用接口卡里的真实上限。

下午，暖桥那台第二只水泵修好。

周建国准备回送时发现运输架底部有一只脚向外偏了近两厘米。

泵本身没有问题。

偏出来的脚会让运输架宽度超过P-01桥板舒适范围。

过去这类问题可能到站才发现。

现在B类货上车前要报外廓。

孙海峰量完就把它拦在维修区。

“先修架子。”

周建国把脚重新校正。

焊点检查通过后，宽度回到原值。

第二天到暖桥，P-01按接口卡展开。

水泵顺利下车。

B类并没有让运输更复杂。

它只是把“到现场才发现”的问题挪到出发前。

孙晓雨把两班实际记录放在一起。

麦丘托盘提前换。

旧港货位少挪一次箱。

暖桥水泵运输架提前修。

三件事都来自同一个变化：货单开始写“怎么装”。

周野看完，问：“名字要不要正式一点？”

“叫什么？”

“货物分级。”

孙晓雨想了想。

“先叫装载等级。”

“别把它说得太大。”

于是当前页标题改成：

【装载等级 v0.1】

只有A、B、C三类。

没有价格等级。

没有信用等级。

也没有谁的货天然更重要。

医疗优先仍由医疗任务判断。

紧急线路仍由班次现场重排。

装载等级只负责一件事：让货物到车门前，大家已经知道怎么把它安全装进去。

晚上，韩序又发来一张照片。

麦丘那块八百一十七毫米的旧木托盘已经拆开。

其中两条还能用的木板被留下。

边缘受潮最重的三条被挑出来晾着。

他问孙晓雨：

“以后八百一十以下都算A？”

孙晓雨没有直接给一个永久数字。

她把归途站导轨的八百二十写回去。

【A类直接装载还要满足当前承载设备余量】

【托盘变形时重新测】

韩序回了一个“行”。

第二天的麦丘出货区多了一把固定卷尺。

旁边钉着一块小牌。

【进归途站前，先量最宽处】
