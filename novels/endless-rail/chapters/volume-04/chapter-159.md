# 第159章 事故广播不是求救单

归途站掉头以后，速度没有立刻提上去。

孙海峰把车压在低速段。

轨旁标记一节一节从窗外退回去。

远距离通信台上的事故广播还在重复。

【东南旧线 / 车体失压 / 多人受伤 / 黑雾冲击仍在。】

同一句话每隔四十秒出现一次。

没有点名归途站。

也没有给任何移动核心下命令。

这更像事故站点把自己还能发出的信息，尽量推给所有能收到的人。

周野站在通信台旁，看着第二张接口照片被传过来。

照片很糊。

灯光偏红。

半扇应急隔离门卡在轨侧检修廊和车厢连接段之间，门框上有旧制式铆钉，也有后来补上的焊点。

另一端则是新一些的气密门。

门侧牌只剩半块。

许成把照片放大到最大，盯了几秒。

“不是同一年代的东西。”

周建国也凑过来看。

“左边像旧线临时改造门，右边是后来补的车体隔离门。中间这段如果失压，不能只看哪扇门能关。”

“我们能处理哪一段？”周野问。

许成没有马上答。

他把前一次刚归档的工具清单调出来。

P-01。

低温工具位。

普通机械卡滞处理件。

旧接口转换夹。

以及铸衡站留下的几组图纸版本号。

这些东西听起来不少。

但照片里的问题，不是缺一只标准件。

它是两代隔离结构卡在同一段事故里。

“我们能看接口。”许成说，“能做临时转接，能帮他们确认哪边能固定，哪边不能承压。车体失压和伤员通道，不归我们判断。”

这句话比“可以救援”更短。

也更重。

孙晓雨在回复框里把能力范围删掉一半。

她原本写了“协助事故处理”。

后来改成：

【归途站可按许可路线接近；能力范围：旧接口兼容检查、现场转接、一般机械协助。】

宋雨眠看到后，没有加“医疗协助”。

她在白栎远程频道里接着核对东南旧线的伤员分类。

沈青禾站在一旁，手里拿着她自己的小本。

她现在还是白栎轮班医疗技术员，不是归途站可以随便挂出去的医疗车厢。

“对方有MED。”宋雨眠说，“我们过去以后，医疗口只听他们现场分诊，不抢。”

周野点头。

“写进内部任务页。”

孙晓雨把第二行补上：

【医疗相关：等待MED现场分诊，不主动承诺治疗能力。】

第三行留给DEF。

但现在没人知道DEF具体能做什么。

屏幕上那个识别点移动得很快。

它没有说“我来防御”。

只在事故广播间隙发出一串距离、雾压和驻留时间估算。

【DEF / 接近外缘 / 预计三分十二秒进入冲击层 / 屏障余量未公开。】

梁文山看完这一行，先去看归途站自己的能源余量。

“我们过去能撑多久？”周野问。

“按许可路线低速进，停留一小时以内，不压72小时安全线。”梁文山说，“超过一小时，必须看事故区有没有外部供能或返程保障。”

“写上。”

孙晓雨又补一行。

【现场停留：初始一小时内；超时需重新核能耗。】

没有人觉得这几行好看。

它们甚至有些冷。

事故广播里明明有“多人受伤”。

归途站回复的却是接口、机械、停留时间和不承诺医疗。

但周野看着那几行，反而觉得这样能去。

说不清的热心最容易变成现场负担。

能做什么，不能做什么，写清楚，才不会让事故站点把错误希望压到他们身上。

十分钟后，事故站点回了许可路线。

【西北侧旧线 / 允许中轻型移动单元接近 / 速度≤25 / 不得进入一号失压区 / 等待DEF建立外层屏障。】

孙海峰看了一眼线路图。

“我们从西北过去，绕十七公里。”

“F-02呢？”孙晓雨问。

许成看向另一个信号点。

铸衡站已经离开南侧编组场，速度稳定，车组很长。

让它掉头进入受损旧线，不一定比归途站更快。

更重要的是，事故站点只允许中轻型单元接近。

F-02的十二节主车不满足。

几分钟后，铸衡站也公开回复：

【F-02不进入西北侧旧线；可在外线待命，提供已确认图纸制造支持。】

程砺没有争。

制造核心没有把“我能做很多零件”当成进入事故区的理由。

这让周野少了一点不必要的担心。

真正先进入黑雾边缘的是DEF。

屏幕上，那个识别点越过事故区外圈以后，所有广播都短暂停了一秒。

随后一条新的状态弹出来。

【防御维护单元D-11已建立外层驻留点。】

没有图像。

只有一串不太稳定的雾压值。

正常值后面跟着三个波峰。

第二个波峰比第一个低。

第三个仍在警戒线附近。

梁文山看着那串值，说：“它能撑住一层冲击，但不代表里面安全。”

周建国收起工具包。

“那我们就别往里走。”

孙海峰把速度提到二十。

归途站进入西北侧旧线时，窗外的轨旁灯少了大半。

黑雾不再像北境那种远远铺在边界外的墙。

它贴在检修廊外侧，像一层不断被风顶起又压回去的灰布。

远处有两节车厢斜停在侧线。

连接处被临时红灯圈住。

红灯外，一个银白色的小型车组停在更靠近站台的位置。

它比归途站短。

车身侧面看不到货窗和工务门，只有一排窄窄的隔离舱门。

门上亮着浅色编号。

【MED-07】

宋雨眠看见这个编号时，语气明显放轻了一点。

“医疗维护单元到了。”

MED-07没有向归途站发欢迎信息。

它先发的是现场区分：

【伤员通道：二号站台南侧。】

【消毒预处理：临时棚A。】

【非医疗车辆不得靠近棚A十五米内。】

孙晓雨立刻把归途站停靠点从原来的二号站台边缘往后拖了十五米。

周野没有问为什么离这么远。

伤员通道已经有人管。

归途站靠太近，只会挡路。

另一侧，DEF的识别点停在失压区外缘。

这一次，归途站收到了短促的画面。

画面里有一辆深灰色车头，停在黑雾最浓的位置。

车身外侧展开了三片像折叠墙一样的东西。

雾撞上去，边缘不断起伏。

没有火光。

没有炮口。

也没有任何“攻击”动作。

它只是停在那里。

把雾压最乱的一段拦在外面。

许成盯着事故站点新传来的接口照片。

“DEF挡的是外面。”

他把两张门照片并排放好。

“我们要看的，是里面这两道门为什么互相卡住。”

事故站点终于给出更具体的任务请求：

【请求归途站确认：旧隔离门A-4是否可作为临时机械固定点；新气密门C-2是否允许接临时转接梁。】

这次是点名了。

但不是求救单。

是一个具体接口问题。

周野看向周建国和许成。

周建国背起工具包。

“先看，不承诺拆。”

许成拿起便携测距仪。

“我需要现场拍孔距、门框厚度和锁销位置。”

孙晓雨把回复发出去：

【归途站接受现场查看；不进入失压区；不改动MED伤员通道；等待DEF外层稳定确认。】

三十秒后，DEF发来一行允许接近。

【外层驻留点稳定六分钟；西北检修廊可短时进入。】

归途站侧门打开时，外面的冷风和消毒棚的味道一起涌进来。

周野没有第一个下车。

先下去的是周建国。

然后是许成。

孙海峰留在驾驶位。

宋雨眠继续在医疗频道听MED的分诊口令。

沈青禾把车内备用医疗包从门边挪开，避免被误拿到现场。

周野最后才跨下踏板。

他抬头看见失压区尽头那两扇门。

一旧一新。

两边都关不上。

中间那段红灯还在闪。

许成蹲到旧门轨侧，拿测距仪照向第一个孔位。

仪器发出很轻的一声。

屏幕上跳出数字。

【孔距：817mm】

周野记得这个数字。

之前那次停靠卡判断，他们曾经因为差三毫米重新做过判断。

许成看了一眼数字，又去量旁边新门的转接孔。

第二个数字出来时，他没有立刻说话。

【孔距：820mm】

三毫米。

同样的三毫米。

只不过这一次，卡住的不是一块桥板。

是事故区两端都不肯完全闭合的隔离门。

周建国把旧接口夹具从包里取出来，先没往门上靠。

他只把夹具放在地上，和两张照片里的孔位并排。

夹具上的滑槽能吃掉三毫米偏差。

但滑槽能对孔，不代表门框能受力。

许成把这一句也写进现场记录。
