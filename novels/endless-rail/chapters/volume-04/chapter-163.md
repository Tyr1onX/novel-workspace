# 第163章 三套核心不能共用一张权限卡

偏孔试贴板送到以前，事故站点先发来一份临时权限卡。

文件名很长。

【东南旧线一号失压区临时联合处置授权】

孙晓雨打开后，第一页就卡住了。

授权对象一栏写着：

【归途站 / MED-07 / D-11 / F-02】

四个名字挤在同一个框里。

下面的权限范围更麻烦。

现场接近、伤员通道、雾压驻留、接口转接、结构件制造，被放在同一组勾选项下面。

看起来很方便。

谁都能看。

谁都能签。

谁都能照着执行。

但MED-07第一个退回。

【医疗权限不可与非医疗维修授权共卡。】

紧接着，D-11也退回。

【防御驻留边界不得由非防御单元共享签署。】

F-02的回复更短。

【制造图纸确认不等于现场安装授权。】

一张看起来能提高效率的联合权限卡，三分钟内被三个核心同时打回。

事故站点值班员站在通信台前，脸上有些难看。

“这样要签到什么时候？”

周野没有立刻回答。

他也不喜欢多张表。

但现在不是嫌麻烦的时候。

如果这张共用卡签下去，后面出了事，很可能没人说得清谁批准了什么。

MED只应该对伤员通道、隔离舱和医疗转运负责。

D-11只应该对屏障范围、雾压窗口和防御驻留负责。

F-02能确认制造件，但不能替现场人员签安装。

归途站能签接口测量和临时兼容，不该碰医疗和防御结论。

事故站点自己还握着线路和车体产权。

少了它，谁都不该改动失压区结构。

孙晓雨把原权限卡复制一份，在旁边新建了一个空页。

她没有做漂亮模板。

只分出五段。

【事故站点：区域开放 / 原设备许可 / 最终接管】

【MED-07：伤员流线 / 消毒隔离 / 医疗转运】

【D-11：屏障范围 / 雾压窗口 / 驻留时限】

【F-02：制造图纸 / 材料边界 / 出厂确认】

【归途站：接口测量 / 临时兼容 / 现场试贴】

五段之间没有总负责人栏。

只有一个共同任务编号。

周野看完，问：“能用吗？”

孙晓雨说：“丑，但不串。”

她把新页发给四方。

这一次，MED-07没有退回。

岑嘉只在医疗段后面加了一行：

【医疗线变更需MED确认；非医疗车辆不得自行扩线。】

D-11加的是：

【屏障窗口只代表可进入时间，不代表维修动作安全。】

F-02加了两行：

【制造件按收到图纸加工；现场安装仍由事故站点与安装方确认。】

【未收到承力计算前，不提供拖拽梁。】

事故站点设备负责人终于上线。

他叫郑岳。

声音比值班员稳一些。

“东南旧线同意按分段授权处理。但你们归途站为什么只签试贴，不签安装？”

周建国接过话。

“因为还没试。”

郑岳停了一下。

周建国继续说：“C-2压力没有完全稳，A-4轨槽里有异物，旧门还承担一点阻挡。现在连试贴板能不能贴平都不知道。”

“如果贴平呢？”

“贴平以后也只是下一步。不是直接安装梁。”

郑岳没有再追。

他把事故站点段落签了。

第一张被签完的不是维修许可。

是区域开放许可。

【西北检修廊蓝线范围 / 六分钟观察窗口 / 可接收非承力试贴板。】

归途站这边签的是：

【只进行C-2外侧非承力试贴；不拆A-4；不改变门体承力状态。】

MED-07签的是医疗线不变。

D-11签的是下一次六分钟窗口。

F-02签的是试贴板出厂确认。

郑岳把旧卡退回以后，事故站点内部还短暂争了一轮。

他们习惯一张事故处置单走到底。

过去只有本站维修队和本站值班室时，这样确实最快。

现在不是。

黄线里的人不归维修队调。

雾压窗口不归医疗车签。

外线制造件也不能因为箱子到了就算现场可装。

值班员想把“现场总协调”写成事故站点。

郑岳看了D-11的屏障余量，又把那几个字删掉。

他可以开放区域。

但他不能替DEF承诺下一次波峰不会来。

他可以允许归途站靠近C-2。

但他不能替MED同意维修人员穿过棚A。

删掉“总协调”以后，页面反而短了。

只剩共同任务编号和五段签字。

孙晓雨看见这个变化，才把J-01的锁定按钮按下去。

五段签完后，孙晓雨把页面锁定。

她在文件名后面加了一个很小的编号。

【J-01】

不是制度名。

只是本次事故联合处置的第一张临时卡。

权限页分开以后，第二个问题很快出现。

同一个动作会碰到两段权限。

C-2外侧试贴是归途站的活。

但试贴时人要进入D-11给出的屏障窗口。

试贴板来自F-02。

原门框属于事故站点。

如果蓝线挪动半米，又会靠近MED的黄线。

孙晓雨没有把这些交叉关系写成一张复杂流程图。

她只在每段后面加了一个“触发重签”。

越红灯线，重签。

改黄线，重签。

试贴改承力，重签。

制造件改用途，重签。

屏障窗口超时，重签。

五条够用。

多了现场也没人看。

偏孔试贴板就在这时候送到交接点。

不是F-02主车亲自来。

是一辆小型外线送料车。

箱子很窄。

上面贴着F-02的制造标签和三行限制。

【偏孔试贴板 / 非承力 / 不得作为牵引件。】

周建国看到“不作为牵引件”时，反而放心了。

程砺没有因为铸衡站的名义，把一件临时板吹成可直接上车的大梁。

箱子交接也按权限走。

事故站点签收外来制造件。

归途站签收试贴使用。

F-02远程保留制造记录。

没有人让MED签。

也没有人让D-11签。

现场因此又慢了几分钟。

但每个人手上的责任小了一圈，也准了一圈。

下一次屏障窗口开启前，岑嘉亲自过来确认蓝线没有压到棚A。

她看见孙晓雨新做的J-01权限页，只扫了一眼。

“以后最好把医疗线颜色固定。”

孙晓雨问：“黄色？”

“黄色。不要拿来标工具。”

“好。”

这不是大规则。

只是现场用过一次以后，留下的一个可复用习惯。

D-11那边第一次发来操作员声音。

男声很低。

“D-11将在四分钟后打开观察窗口。窗口六分钟，外层波峰不稳定，维修人员不得越红灯内线。”

孙晓雨抬头看了一眼。

“请报现场负责人。”

那边停了半秒。

“佟锐。D-11驻留操作员。”

她把名字补进J-01。

不是为了人物卡。

只是以后出事要知道这条窗口是谁签的。

郑岳也在事故站点段落后补上自己的名字。

五段授权卡终于不再像临时拼起来的空表。

它开始能追到人。

四分钟后，D-11屏障重新前推。

蓝线外侧亮起。

周建国拿起试贴板。

许成带着测距仪和两只磁吸定位块。

周野仍然没走最前面。

他站在红灯线外，看着三个人按各自签过的范围移动。

MED的人在黄色线那边继续清点隔离毯。

DEF的屏障声压在黑雾边缘。

F-02不在现场，却有一块它做的板被拿在周建国手里。

归途站负责把这块板放到C-2外侧。

事故站点的人握着原设备钥匙。

没有哪张卡能把这五件事合成一个人的命令。

周建国把试贴板抵上C-2门框。

第一下没贴平。

门框右上角有一处旧焊瘤，正好顶住板边。

许成把磁吸定位块取下，换了一个角度。

第二下，板贴住了。

三毫米偏孔正好对上。

但板下缘和门框之间仍有半毫米缝。

许成把照片发回F-02。

程砺很快回复：

【需要避让右上焊瘤；下缘缝隙不可作为承力安装状态。】

周建国没有失望。

他把板取下，在现场记录里写：

【可定位，不可安装。】

事故值班员看见后，问：“那这次窗口就白用了？”

“不白。”许成说。

他把C-2外侧贴合照片和下缘缝隙数据一起上传。

“现在知道下一块要改哪里了。”

窗口还剩四十秒。

周建国没有补试第三次。

他们退回蓝线外。

D-11关闭观察窗口。

J-01权限页的最后一栏自动生成结果：

【C-2非承力试贴完成；需F-02修改避让位；A-4未扰动。】

这一次，五方都不用重新解释自己没做什么。

每个人签过的那一小段，都留在页面里。
