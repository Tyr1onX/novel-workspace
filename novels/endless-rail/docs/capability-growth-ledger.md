# 归途站能力成长账本

> 目的：单独跟踪“归途站现在到底能做什么、下一阶段要新增什么、哪些能力已经验证过必须继续复用”。
>
> 这不是装备清单，而是全书核心成长计分板之一。

# 一、成长原则

1. 大升级必须视觉化，读者不看系统提示也能感觉列车变了。
2. 每次新能力至少在后续3次真实任务中复用，否则视为一次性道具。
3. 已验证能力后续直接使用，不重复教学。
4. 新能力优先来自现有材料、专业人员、授权和前期积累，不凭空白送。
5. 归途站的核心强项始终是：**兼容、重构、移动、连接不同系统**，不是把所有能力吞成万能。

- 北岬经旧港中转的技术货运。

### 标准停靠第一阶段

- 50mm快接→40mm螺纹洁净水路转换件；

- AC-01：特定220V同电压接口线；
- 停靠卡；

- 毛重/皮重/净重、实称/参考来源记录；

### 当前硬边界

- 北岬仍无归途站直接通行；
- 白03属于炉坪维护廊，不属于归途站；
- P-01不是人员通道；
- LV-01不是万能电源；
- 各站保留站台、库存、专业判断和拒绝权；
- 当前未来72h最低能源余量不可被外部任务挪用。

# 三、当前强化：寒季运输（107～117，已到116）

## 已验证/已进入试用

### 网络侧

- 72h最低能源余量已经真实否决外部完整路线；
- 固定站可用自己的车辆、库存、生产节拍和货位分担，不再默认由归途站包办；
- 西侧绕行线完成一次4.82t白03真实货运，仍维持≤6t、5km/h排水桥、炉坪登记等旧边界；
- K-17低温加热回路故障被发现、暂停、修复、复检，主路恢复后备用线退回后台。

### 归途站实体低温准备

- **货运侧门挡水片（试用）**：减少融水进入锁舌；连续低温夜晚后第一拉可开，仍需更多天气复用。
- **P-01收纳防水罩（试用）**：4只，仅收纳状态覆盖锁销槽上半面，底部排水开放；红色提醒带提示展开前取下。
- **低温工具位（已使用1次）**：塑料刮片、窄刷、吸水布、当前确认可用于P-01规定位置的小罐低温润滑脂；湿布外晾后再收。

### 尚未完成

- 牵引电池低温维持启动越来越早；外侧检修门/金属骨架附近降温最快。
- 已布置外壁、门框、舱内、铰链附近临时温度点；纸带提示下方铰链附近可能有轻微空气流动。
- 当前还不能确认主要损失来自门封渗风还是材料冷桥，因此没有直接加保温棉、封死通风或增加加热功率。

## 第117章完成条件

第117章只从以上已经发生的故障和测试形成有限【寒季运输组件】。至少做到：

1. 读取夜间电池温度数据并做有证据的有限处理；
2. 让货运门/P-01/低温工具位至少再有一次真实低温复用；
3. 保留所有原有安全与能源边界；
4. 读者不看系统框也能从列车操作上感到寒季准备已经成形。

寒季组件仍需后续真实任务累计第二、第三次复用，才能进入长期稳定能力。

# 四、区域服务枢纽（118～145）

## 计划能力

- 第三方验货；
- 有限货运保障与延误补偿；
- 更成熟公开交易/运输台；
- 多商队选择与路线比较；
- 大宗与小批运输分工；
- 路线/货位/保障结算。

## 可见形态

归途站出现真正的调度与交易区域：货单、看板、交接窗口、待运货位、公开班次，不再只是某个人桌上的表。

## 卷末状态

【区域服务枢纽】

能够让不同站点和不同运输方在不被归途站控制的情况下使用同一套开放商路。

# 五、区域移动服务核心（146～195）

## 计划能力

- 多移动核心授权接口；
- 与制造核心进行批量标准件协作；
- 与医疗核心进行大规模转运/设备协作；
- 与防御核心进行危险区工程协作；
- 多系统临时兼容；
- 大型联合工程。

## 归途站核心优势

不是制造最快、医疗最强或防御最硬，而是：

> **能把不同核心、旧设备、不同标准临时接成一套可工作的系统。**

## 可见升级

- 多核心接口舱或授权节点；
- 联合工程挂点；
- 更强通信中继；
- 可临时接入其他核心模块。
