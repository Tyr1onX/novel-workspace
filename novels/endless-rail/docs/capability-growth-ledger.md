# 归途站能力成长账本

> 目的：单独跟踪“归途站现在到底能做什么、下一阶段要新增什么、哪些能力已经验证过必须继续复用”。
>
> 这不是装备清单，而是全书核心成长计分板之一。

# 一、成长原则

1. 大升级必须视觉化，读者不看系统提示也能感觉列车变了。
2. 每次新能力至少在后续3次真实任务中复用，否则视为一次性道具。
3. 已验证能力后续直接使用，不重复教学。
4. 新能力优先来自现有材料、专业人员、授权和前期积累，不凭空白送。
5. 归途站的核心强项始终是：**兼容、重构、移动、连接不同系统**，不是把所有能力吞成万能。

# 二、已完成阶段

## 1. 初始列车（1～8）

### 核心能力

- 基础移动；
- 家庭汇合；
- 初始物资管理；
- 万物融合的最小对象级应用。

### 读者视觉

从一节破旧、寒冷、资源不足的车开始。

## 2. 初级移动站（9～35）

### 已形成

- 多节主体与附车；
- 基础农业/温室；
- 能源与备用供电；
- 维修区；
- 仓储/冷藏；
- 普通市场与库存账；
- 基础相位防护；
- 初步医疗入口；
- 轻型接驳/轨道工程能力；
- 正式站名“归途站”。

### 关键变化

列车从“逃命工具”变成“可以持续生活的移动家”。

## 3. 自给型移动服务站（36～116，当前）

### 生活能力

- 稳定净水与补水；
- 食品加工/热粮包；
- 正式住宿区；
- 灰水/卫生污水分流；
- 基础医疗咨询、转运与检验协作；
- 能源安全余量管理。

### 服务能力

- 七站固定但有限的互助班次；
- 维修、运输、跨站协调；
- 公开服务账；
- 炉坪—旧港白03接驳；
- K-17工务协作；
- ≤6t西侧受控轻型备用路线；
- 北岬经旧港中转的技术货运。

### 标准停靠第一阶段

- P-01模块化可调装卸桥：日常轻货≤400kg；
- 50mm快接→40mm螺纹洁净水路转换件；
- LV-01：48V→24V有限低功率直流转换；
- AC-01：特定220V同电压接口线；
- 停靠卡；
- A/B/C装载等级；
- 维修交接摘要；
- 跨站对象索引；
- 毛重/皮重/净重、实称/参考来源记录；
- 公开货单/库存页接入运输状态。

### 当前硬边界

- 北岬仍无归途站直接通行；
- 白03属于炉坪维护廊，不属于归途站；
- P-01不是人员通道；
- LV-01不是万能电源；
- 各站保留站台、库存、专业判断和拒绝权；
- 当前未来72h最低能源余量不可被外部任务挪用。

# 三、当前强化：寒季运输（107～117，已到116）

## 已验证/已进入试用

### 网络侧

- 72h最低能源余量已经真实否决外部完整路线；
- 固定站可用自己的车辆、库存、生产节拍和货位分担，不再默认由归途站包办；
- 西侧绕行线完成一次4.82t白03真实货运，仍维持≤6t、5km/h排水桥、炉坪登记等旧边界；
- K-17低温加热回路故障被发现、暂停、修复、复检，主路恢复后备用线退回后台。

### 归途站实体低温准备

- **货运侧门挡水片（试用）**：减少融水进入锁舌；连续低温夜晚后第一拉可开，仍需更多天气复用。
- **P-01收纳防水罩（试用）**：4只，仅收纳状态覆盖锁销槽上半面，底部排水开放；红色提醒带提示展开前取下。
- **低温工具位（已使用1次）**：塑料刮片、窄刷、吸水布、当前确认可用于P-01规定位置的小罐低温润滑脂；湿布外晾后再收。

### 尚未完成

- 牵引电池低温维持启动越来越早；外侧检修门/金属骨架附近降温最快。
- 已布置外壁、门框、舱内、铰链附近临时温度点；纸带提示下方铰链附近可能有轻微空气流动。
- 当前还不能确认主要损失来自门封渗风还是材料冷桥，因此没有直接加保温棉、封死通风或增加加热功率。

## 第117章完成条件

第117章只从以上已经发生的故障和测试形成有限【寒季运输组件】。至少做到：

1. 读取夜间电池温度数据并做有证据的有限处理；
2. 让货运门/P-01/低温工具位至少再有一次真实低温复用；
3. 保留所有原有安全与能源边界；
4. 读者不看系统框也能从列车操作上感到寒季准备已经成形。

寒季组件仍需后续真实任务累计第二、第三次复用，才能进入长期稳定能力。

# 四、区域服务枢纽（118～145）

## 计划能力

- 第三方验货；
- 有限货运保障与延误补偿；
- 更成熟公开交易/运输台；
- 多商队选择与路线比较；
- 大宗与小批运输分工；
- 路线/货位/保障结算。

## 可见形态

归途站出现真正的调度与交易区域：货单、看板、交接窗口、待运货位、公开班次，不再只是某个人桌上的表。

## 卷末状态

【区域服务枢纽】

能够让不同站点和不同运输方在不被归途站控制的情况下使用同一套开放商路。

# 五、区域移动服务核心（146～195）

## 计划能力

- 多移动核心授权接口；
- 与制造核心进行批量标准件协作；
- 与医疗核心进行大规模转运/设备协作；
- 与防御核心进行危险区工程协作；
- 多系统临时兼容；
- 大型联合工程。

## 归途站核心优势

不是制造最快、医疗最强或防御最硬，而是：

> **能把不同核心、旧设备、不同标准临时接成一套可工作的系统。**

## 可见升级

- 多核心接口舱或授权节点；
- 联合工程挂点；
- 更强通信中继；
- 可临时接入其他核心模块。

# 六、移动城镇核心（196～250）

## 目标人口

80～150常住人口。

## 必须形成的生活模块

- 正式住宿与私人空间；
- 公共浴室/热水；
- 公共食堂；
- 正式医疗区；
- 教育/学徒空间；
- 小型制造；
- 公共休息区；
- 市场/生活服务位；
- 居民身份与基本议事机制。

## 能力变化

归途站不再是“专业成员一起住的工作车”，而是普通居民可以长期生活的移动社区。

## 读者必须看到

早餐、洗澡、上课、市场、夜灯、温室、孩子/学徒、居民回房间等真实日常。

# 七、高级相位移动核心（251～305）

## 计划能力

- 高级相位导航；
- 黑雾断层长期作业；
- 节点修复；
- 坐标验证；
- 主干权限碎片；
- 更严格撤退/隔离能力。

## 形态变化

不是火力升级，而是归途站第一次能进入过去完全不可长期进入的空间异常区，并带着工程团队活着回来。

# 八、移动轨道城（306～360）

## 目标人口

200～400人。

## 计划能力

- 多列接驳；
- 工程附车；
- 跨域补给；
- 中途维护站协作；
- 区域级通信；
- 四域资源互补；
- 大规模联合维修。

## 读者视觉

归途站不再像“一列很长的车”，而像一座沿轨道展开、拥有附属列车和不同功能区的移动城市。

# 九、成熟轨道城市（361～410）

## 新能力重点

- 卫星列车独立执行；
- 分级授权；
- 教育与专业培训；
- 批量制造；
- 城市级医疗/生活管理；
- 居民自治；
- 多专业团队脱离周野独立运转。

## 判断标准

如果周野离开归途站几天，城市仍能正常吃饭、供水、维修、治病、运输、处理普通纠纷。

# 十、主干线移动修复核心（411～465）

## 计划能力

- 主干权限；
- 多核心兼容；
- 全网节点数据；
- 分布式调度；
- 主干工程载体；
- 跨域资源统筹。

## 核心限制

归途站仍不能单独重启世界。

这一阶段的“强”来自：它终于能承载全网授权、材料、专业能力和节点信息，而不是拥有无限资源。

# 十一、永久公共交通与修复核心（466～510）

## 最终能力

- 不同移动核心与区域节点兼容；
- 公共班次长期运行；
- 普通人跨站旅行；
- 黑雾异常可监测/隔离/逐步修复；
- 不需要个人系统也能参与维护网络；
- 归途站继续作为移动城市和修复节点，而非世界政府。

# 十二、能力复用检查

以后新增任何模块/设施/权限时，必须登记：

- 首次出现；
- 首次实际使用；
- 第二次复用；
- 第三次复用；
- 是否改变长期能力；
- 是否还有边界；
- 如果长期不用，是否应降为后台能力而不是继续占正文。

# 十三、当前最近的升级路径

从第107章开始最重要的能力路径是：

> 现有标准停靠工具直接工作
> → 寒潮迫使归途站低温强化
> → 真实货损与赔付让运输服务成熟
> → 大型商队竞争证明归途站的“兼容 + 小批 + 改线”优势
> → 区域服务枢纽
> → 发现其他移动核心

近期禁止再连续十章只添加表格字段或小型接口工具。
