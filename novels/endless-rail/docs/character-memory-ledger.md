# 人物读者记忆账本

> 建立日期：2026-08-26
>
> 用途：解决“作者/连续性账本知道这个人是谁，但读者已经不记得”的问题。
>
> 本账本不替代 `continuity-ledger.md`。连续性账本回答“事实有没有冲突”，本账本回答“角色再次出现时，读者是否还能自然认出他”。

## 0. 权威与审计边界

- 番茄 `author-editor` 导出仍是第1～70章的平台历史权威源。
- 当前仓库已恢复第1～44章、67～70章的可读正文，第45～66章仍有部分平台稿尚未逐章恢复。
- 因此本轮对第1～44章、67～71章可做正文级复核；第45～66章暂按平台导出后形成的 handoff / continuity 摘要做角色连续性复核。
- 等第45～66章逐章正文恢复后，必须补一次句子级人物重登场审计。

## 1. 读者记忆硬规则

### 1.1 角色重新出现时，不只检查“设定上是否存在”

写到一个已有名字前，必须同时回答：

1. 他第一次在哪一章进入读者视野？
2. 当时读者是靠什么记住他的：关系、职业、动作、冲突，还是只有一个名字？
3. 最近一次真正参与场景是哪一章？
4. 中间是否连续多个章节只在账本里存在、正文没有有效动作？
5. 本次重登场如果只写名字，新读者/追更读者能否在一句内恢复身份？

如果第5项不能确定，正文第一次重新出现时必须加入一个**自然身份锚点**。

身份锚点应嵌在动作里，例如：

- `负责外勤的孙海峰已经把接驳车停到侧线。`
- `当初留在零号研究所的冯立又发来一条加密消息。`
- `白栎医疗负责人宋雨眠在固定通信窗口接了进来。`

禁止写成作者式人物卡：`孙海峰，外勤驾驶员，曾于第9章加入。`

### 1.2 触发重锚的默认条件

满足任一项，新场景优先补身份：

- 连续 **8章以上** 没有有效出场；
- 虽然提过名字，但连续 **5章以上** 没有动作、对话或关键决定；
- 首次登场只发生在高压大章、群体救援、多人同时入场或系统提示密集段；
- 角色从“临时乘员/路人”升级为长期核心成员，但中间缺少独立人物场景；
- 同一阶段存在姓名相近、职业相近或功能相近的人物；
- 角色跨卷、跨站点、跨长篇章重新出现。

数字是警戒线，不是机械模板。即使只隔三章，只要角色记忆弱，也可以重锚。

### 1.3 不要反复介绍熟人

周野、周建国等高频核心角色不应每次都重新解释身份。

重锚只在读者确实可能遗忘时使用，而且一处足够。后续同章继续直接叫名字。

## 3. 已发现的高风险点

### A. 孙海峰：本轮读者质疑的直接来源

事实链没有断：

- 第9章：在白桦农业实验站寒潮撤离时，以故障列车求援者身份首次具名；
- 第10章：确认孙海峰、孙晓雨为兄妹；
- 后续：说明灾变前做过货运司机，承担外勤车、探路和运输；
- 第13章：完成连续外勤任务并正式成为外勤驾驶员；
- 第30章：岗位制度明确他负责外勤车辆、接驳列车与路线执行。

问题不是“没有来源”，而是：

1. 第9章本身是高信息密度高潮章，名字只占很小位置；
2. 同阶段多人同时加入，孙海峰没有独立、醒目的第一次人物场景；
3. 后续作者侧一直把他当核心成员，正文却容易直接裸用名字；
4. 连续性账本此前只记录岗位，不记录读者第一次如何认识他。

结论：**人物事实连续，读者记忆连续性不足。**

### B. 孙晓雨：从“某人的妹妹”到“账目负责人”的跃迁容易被忽略

第10章她只是与哥哥一起被点名；早期存在感弱。第29章虽然用市场登记、公开库存和转正场景真正建立了人物功能，但如果读者已经忘记第10章，开头直接看到“孙晓雨负责贴标签”仍可能先产生一次身份断裂。

以后不要再主要依赖“孙海峰妹妹”记她。她正式转正后的核心记忆点应是：

> **普通物资 / 市场 / 公开库存 / 非隐私账目。**

兄妹关系只在生活场景里偶尔强化。

### C. 许成 / 郭成：姓名相似 + 技术身份相近

平台真实暖桥线存在“郭成”这一暖桥维修员，同时归途站长期成员已有“许成”。

风险组合：

- 都是男性技术人员；
- 名字都以“成”结尾；
- 暖桥阶段两人处在同一技术异常剧情；
- 暖桥本身又出现过“重复/假未来/两个郭成”类认知干扰。

这会放大正常的人名混淆。

当前不直接改已发布姓名，但后续凡在同一章出现二人：

- `许成` 优先绑定归途站电气/通信/实体参考；
- `郭成` 优先绑定暖桥维修员/那辆自行返回的旧检修车；
- 不允许连续几段只写“许成说 / 郭成说”而没有场景职责差异。

若未来准备做一次已发布正文统一修订，可以评估是否把暖桥维修员改成更不相似的名字；修改前必须全平台、全仓库统一替换并保护第41章异常逻辑。

### D. 冯立：典型“旧路人被重新调用”风险

第13章时，冯立是最后一名临时乘员，列车几乎报废、没有明确专业技能，最后选择留在零号研究所。

第30章再次出现时，正文直接写“发送者是冯立”，并由他提供零号研究所二级权限/北部隐藏生活保障线的重要信息。

这条因果可以成立：他一直留在研究所，后来成为归途站与研究所之间的联系人之一。

但读者很容易已经忘记第13章那个临时乘员。

**这是当前第二个最值得回修的裸重登场点。**

最自然的重锚方向不是解释一大段，而是类似：

> `当初选择留在零号研究所的冯立，又发来一条加密消息。`

一句即可恢复整条旧关系。

## 4. 中风险但暂不建议改正文的人物

### 宋雨眠 / 沈青禾

两人都属于白栎医疗线，容易被统称成“医疗女角色”，但现有首次建立总体合格：

- 宋雨眠：白栎医疗负责人，负责分级、接收、药品和专业边界；
- 沈青禾：医疗技术员，进入归途站30天轮班考察，不能独立诊断/处方。

第35～36章对沈青禾的身份强化足够，因此目前不属于断层。

未来跨出白栎篇后，宋雨眠每次长空窗重回正文都要带“白栎负责人”锚点；沈青禾则优先强化“仍属于白栎轮班框架”，防止身份悄悄漂移。

### 梁文山 / 许成 / 周建国

三人都会参与技术判断，但专业边界不同：

- 周建国：机械、维修、结构安全；
- 梁文山：能源、安全余量、运行边界；
- 许成：电气、通信、相位/实体参考、接口。

风险不在人名来源，而在技术场景中三个人如果连续都只负责“看数据、说不行、提出方案”，会逐渐声音同质化。

后续人物记忆应通过**不同的第一关注点**维持，而不是增加介绍文字。

## 5. 局部站点人物规则

暖桥、白栎、沉泉、麦丘、炉坪、旧港会不断出现本地人物。对只服务一个小篇章的NPC，不需要强行写进核心成员表，但必须遵守：

- 本篇第一次出现：名字 + 一个清晰职责/关系/动作；
- 连续篇章内高频出现：后续可直接用名字；
- 离开该站点 **10章以上** 再回来：重新用站点身份锚一次；
- 不要把多个同姓、同尾字、同职业名字同时放进一个短篇章，除非这种混淆本身就是剧情机制；
- 如果混淆本身是剧情机制，正常角色之间反而要加强区分。

当前特别需要记住：

- 郭成：暖桥维修员；若暖桥篇结束后再回来，必须重新锚定；
- 冯立：零号研究所留守联系人；任何再次出现都优先说明“零号研究所”；
- 马立平：炉坪旧巡线人员；第71章参与旧港前探，当前记忆仍新鲜；

## 6. 发布前人物记忆检查

每章交付/发布前新增以下检查：

- 本章出现的所有具名人物，是否都确实在正文中建立过？
- 有没有角色只存在于大纲/连续性账本，却从未在平台正文建立？
- 有没有超过8章未有效出场的旧人物直接裸名字回归？
- 有没有像孙海峰这样，首次出场发生在多人同时加入、高压高潮或系统信息密集段的人？
- 有没有像许成/郭成这样，姓名和功能都容易混淆的人同时出现？
- 角色身份变化（临时→考察→正式、外站→随车）是否在正文中真正发生，而不只是账本更新？
- 新角色的第一次记忆点是否至少有一个：**关系、职业、强动作、独特判断、具体冲突**？
- 如果删除名字，只看动作和说话方式，核心成员之间是否仍能大致区分？

如果任意一项回答不稳，先修人物锚点，再发布。
