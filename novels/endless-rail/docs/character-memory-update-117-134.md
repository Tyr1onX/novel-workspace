## 本轮人物关系与权限结论

- 周野的“开放商路”从原则变成真实损失：第134章大宗单确实给了长轮，归途站没有垄断保护。
- 孙晓雨的成长是把复杂现实记录清楚，而不是获得更高控制权；她的表格不能替别人做专业或商业选择。
- 马立平/赵琴的工务权限在赔付和竞争压力下仍有效，安全判断不能被“赶时间/怕赔钱”侵蚀。
- 韩序、旧港、罗庆、贺临都按自己的利益与责任行动，不是围着归途站配合剧情。
- 罗庆的错误是信息不完整，不等于永久不可信；贺临的竞争是专业能力，不等于敌对。
- 第135～138章人物冲突重点应落在订单、成本、装卸条件和实际任务适配上，避免写成周野与贺临口头争胜。
