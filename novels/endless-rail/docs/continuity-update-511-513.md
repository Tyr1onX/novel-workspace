# 第十一卷《地图之外的站》连续性：第510～513章

第510章：元旦清晨，公共联程客运已正常开通，普通家庭林成夫妻、女儿朵朵前往湖原南岸外婆家；一位老人展示旧月票【桦背湾】，朵朵将河道上游一个尚未开通的站台画成空白方框。该章是第一大阶段收束，不是全书终章；36锚点、多主体分布式运营、周野与宋雨眠已建立的关系等事实不回退。

第511章：南岸码头陆师傅、站务员卢敏、桦背湾姜伯、山货互助组邵姨出现。普通山货靠人力手车从山里运到南岸；一车缺轮，另一车轮毂磨偏。卢敏从旧地图查到【桦背湾林运侧台】，但现行公开客货线路未到该处，实际还有人在此生活。朵朵正常回外婆家，不成为探险核心。

第512章：旧林场窄轨762mm，已通公共主干轨距1435mm，相差673mm，旧线无法直接驶入主干车辆。当地代表何槐不允许主体车辆自行进入桦背湾。湖原本地仅准在靠河的旧公共卸货平台做目视、量轨检查，村内山路与灌溉渠木桥仍未开放。老手车曾在坡口出轨，周建国仅从安全边界将轮挡交给何槐。互助组允许拆下旧车架送往南岸检货台，实物检查后再决定维修。

第513章：桦背湾互助组所有的两辆旧窄轨手车提供两副检查合格的762mm轮对、旧刹车棘爪与角钢横撑；南岸以有偿方式供应四只新轴承；木工阿礼切掉烂木板部分。周野以原有万物融合能力完成**低底盘人力短货托**的钢架组合与机械刹车。仅在南岸已许可的平轨试验：空车、90kg与150kg均通过，短程人力推运与刹车可用。**坡道、弯轨、灌溉桥未验证，禁止直接宣布桦背湾货运恢复。** 成品仍归桦背湾互助组，成本真实存在。

第514章写作入口：次日上午由何槐带队查看河堤坡口与旧灌溉桥。继续突出现场动作、实体修复与居民得失，不重复制度条款。下一阶段的固定设施/轨道改造须获取当事方许可，且不能以整车直接切换轨距解决。
