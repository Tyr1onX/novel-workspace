# 《末世列车求生：我能融合整座车站》107～510章发展蓝图

> 当前正文：第106章完成。
>
> 本文件是 `master-outline.md` / `long-term-outline.md` 的中层细化，不推翻既有卷号、世界观与终局；它负责回答“每10～25章具体推进什么、读者看到什么、归途站得到什么、下一阶段为什么自然发生”。

# 一、全书核心幻想

这本书最重要的长期幻想不是战力升级，而是：

> **从一节又冷又破的列车开始，把自己的家越建越大、越住越舒服；再带着这个家穿过黑雾、连接越来越大的世界，最后发现自己一路学习的‘连接不同东西’正是修复整个无尽轨道的方法。**

以后任何制度、技术和政治冲突都必须服务这个幻想。

# 二、五条长期主线

1. **归途站成长线**：破车 → 移动站 → 自给服务站 → 区域服务核心 → 移动城镇 → 移动轨道城 → 主干线移动修复核心。
2. **地图扩张线**：曙光 → 北境七站 → 区域商路 → 其他移动核心 → 百站联盟 → 黑雾断层 → 四域 → 主干控制区。
3. **生活经营线**：吃饱 → 稳定供水/食品/医疗/住宿 → 居民社区 → 教育/制造 → 数百人城市生活。
4. **世界谜底线**：黑雾异常 → 系统维护痕迹 → 多移动核心 → 空间碎片 → 中央保护程序 → 主干网络真相。
5. **路线选择线**：自己活 → 帮一站 → 连接七站 → 开放商路 → 小站自治 vs 集中效率 → 分布式重启 vs 中央牺牲外围。

每个中型篇章至少推动两条，重要篇章推动三条。

# 三、读者兑现节奏

- 每5～8章：至少一个小兑现（新设备、新路线、新生活体验、新资源、新人物、新能力实际使用）。
- 每15～25章：至少一个明显变化（新地图、新势力、新模块、新权限、人口/形态变化）。
- 每卷：一次真正改变格局的阶段升级。
- 连续超过6章只写流程/制度/接口/账目而没有新场景、新能力或大事件，必须调整。

# 第三卷《联轨商路》95～145

## 卷核心

七站已经能长期互相活下去。现在的问题变成：**怎样让资源稳定、公开、可选择地流动。**

95～105“标准停靠”已完成第一阶段。106起进入寒季供应。

## 106～117：寒季供应

### 107～109：第一次真正取舍

**核心问题**：需求同时发生，但归途站不可能全接。

- 延续106候选页：麦丘64箱热粮包、沉泉3只空水箱、白栎防冻伤敷料、北岬无时限接触器。
- 第107章必须至少兑现一项延期任务，同时明确一项继续延期或拒绝。
- 排序只看：明确时限、不执行后果、本站替代方案、是否能并线、归途站最低余量。
- 第108章出现一个反直觉任务：带“医疗”标签的物资实际还能等待，而一个普通供暖/水路件如果不送会导致生活系统停摆。专业人员先给后果，周野再定路线。
- 第109章梁文山第一次明确否决会压穿72h最低能源余量的方案；内部产生“先保本车还是多跑公共任务”的真实分歧。

**读者新东西**：寒季后的归途站真实运行状态，不只是表格；低温对门、管路、电池、道岔的影响。

**小兑现**：至少一项此前延期货物真正送到，另一个站靠自己的办法撑过窗口。

**强场面**：车内所有人都知道外面有急需，但梁文山把能源安全线摆在桌上，明确说“这条线以下不动”。

### 110～113：网络开始反向工作

**核心问题**：七站不能永远等归途站救。

- 麦丘主动调整生产节拍，把货从包装线转入成品库，降低即时运输压力。
- 沉泉延长空箱回收窗口，避免无意义专车。
- 炉坪提供已有同向工务车，替代一部分归途站接驳。
- 旧港重新排货位，让两个普通任务合并。
- 暖桥自己完成一段临时保温或备用泵切换。
- 至少一次任务由“两个固定站直接协作 + 归途站只提供一段服务”完成。

**读者兑现**：此前七站建设产生复利；归途站不是七个附庸的保姆，而是网络里的移动节点。

**能力变化**：归途站获得“多站协同调度”雏形，但不是系统新技能，而是既有班次、停靠卡、公开货单开始产生组合价值。

### 114～117：寒潮运输事件

**核心问题**：已经承诺的任务因为线路/低温变化无法按原计划执行。

建议事件：

- K-17因结冰临时暂停重载；
- 西侧绕行线仍只有≤6t轻型货运能力；
- 一个已承诺物资必须在当天到；
- 归途站把大车任务拆小批，利用西侧绕行 + 炉坪同向车 + 旧港临时窗口完成。

过程中必须让95～105已有建设同时发挥作用：P-01、停靠卡、装载等级、对象号、重量来源、LV/AC接口至少自然调用其中3项，但禁止重新教学。

**篇末新能力：寒季运输组件（小型可见升级）**

可包含：

- 货运侧门/锁销除冰加热；
- 关键水路防冻循环；
- 电池低温保温；
- 一块有限恒温货位；
- 低温巡检工具位。

不能凭空出现，使用现有材料、能源和专业人员完成。

**最强场面**：主路封住，六吨限制的备用线第一次真正承担急货；归途站不“硬闯”，而是把一整趟任务拆成小车、接力和不同站点的动作。

**篇末状态**：寒季优先页试行，但不是永久区域制度。

## 118～130：货物与信用

### 118～121：第一起真实货损

- 麦丘食品或其他普通货在“包装受潮 + 旧港等待 + 路线延迟”的组合下出现部分损坏。
- 数量没有丢，责任却不能简单归一个人。
- 通过现场货物而非会议拆分：出站状态、旧港储存、运输环境、到站状态。
- 第一次形成“责任区间”而不是“一口价赔偿”。

**读者兑现**：一批真实损坏的货、谁承担什么、最后剩余可用货怎么处理；不只生成新字段。

### 122～125：第一次信息隐瞒

- 引入一个外围小站或商户，为了让自己的任务获得更高优先级，故意把库存写得比实际少，或隐瞒已有替代品。
- 对方不是纯坏人：真实理由是如果如实申报，长期处在排序末尾。
- 隐瞒导致另一个更需要的任务被推迟，产生具体代价。
- 孙晓雨现有公开账与旧港/炉坪第三方记录拼出矛盾。

**冲突重点**：以后别人还信不信他的“紧急”。

**禁止**：做成信用分面板 + 自动扣分。

### 126～130：第一笔保障赔付

- 从货损和信息隐瞒自然长出第三方验货、有限封签、延误责任和一笔真实补偿。
- 保障只覆盖明确条件，不写万能保险。
- 至少完成一笔实际补偿/替代运输，让制度有现实用途。

**篇末可见升级：公开交易与运输台**

把现有散落的货单/库存/停靠信息形成一个真正可使用的调度区域：屏幕/看板/货物窗口/交接台，读者能在场景里看见，而不是只听系统说“市场升级”。

**能力收益**：归途站能够承担第三方交接和有限保障，不只是自己运货。

## 131～141：商路争夺

工作名引入大型商队：**长轮商队**（正式写作可改名）。

### 131～134：更便宜的竞争者

- 长轮有更多车辆、更大载重、固定仓储和成熟大宗运输。
- 提出对大宗货更低的价格，甚至试探关键货位/线路的独家合作。
- 麦丘、炉坪或其他站点合理考虑试用。
- 周野不能要求七站只用归途站，否则违背自己的开放原则。

**读者体验**：第一次看到规模明显更大的专业商队，归途站不再是北境唯一能跑商路的存在。

### 135～138：归途站真的打不过大宗运输

- 长轮在大宗粮食、标准箱、固定路线上的效率明显高于归途站。
- 归途站丢掉一部分普通订单，服务账短期下降。
- 但归途站优势逐渐显露：小批混装、临时维修、医疗转运、复杂接口、非标准货、应急改线。

**禁止**：让长轮突然犯低级错误来衬托主角。

### 139～141：大车过不去，小网接过去

- 一处桥/道岔/黑雾变化让长轮的大车无法按原路线通过。
- 货物时限真实存在。
- 归途站用“拆货 → 小车 → 多站接力 → 旧港/炉坪/备用线”完成一段长轮做不到的任务。
- 长轮自身也保护住另一批大宗货，证明两套模式各有优势。

**最强场面**：不是打架，而是同一批货在地图上被拆成数条路线，最后在另一端重新合并。

**篇末关系**：竞争者转为“既竞争又合作”的长期角色。

## 142～145：第三卷卷尾

- 北境形成第一套开放商路协议：不永久买断生命线；站点可自由选择服务商；公开路线成本；明确有限公共任务边界；货损可追溯。
- 归途站不是区域统治者，而是服务枢纽之一。
- 可完成阶段升级：【区域服务枢纽】。

### 卷尾钩子

多批货物上出现高度一致、工业化程度明显超过北境的标准模块。

许成确认：

- 尺寸一致；
- 接口一致；
- 制造标记来自同一套体系；
- 北境没有任何站拥有这种连续制造能力。

远距离通信随后捕获一段系统级识别信号。

**另一移动核心正式进入第四卷。**

### 第三卷读者总兑现

- 标准停靠从工具变成成熟服务能力；
- 寒季运输能力可见提升；
- 有第一笔真实货损和赔付；
- 有大型商队竞争；
- 北境商路真正开放；
- 世界第一次明确证明周野不是唯一特殊者。

# 第四卷《移动核心》146～195

## 卷核心

世界扩大：不同移动核心代表不同旧网络维护职责，没有任何一个人能独立解决全部问题。

## 146～158：标准制造者

- 引入制造/复制型移动核心。
- 其核心优势：对已经有标准的设备进行高效率批量制造/模块复制。
- 缺点：严重依赖稳定原料、统一尺寸和中央仓储；面对杂乱旧设备与非标准站点时适应性差。
- 初期先合作：解决一批北境长期缺件，让读者真正看到“批量生产”的爽感。
- 周野负责兼容和改造；对方负责规模制造。

**强场面**：归途站过去需要几天手工适配的零件，对方的制造车厢连续吐出几十套完全一致的成品。

**冲突伏笔**：对方认为“既然统一标准效率这么高，就应该让所有站逐步改成同一种系统”。

## 159～170：医疗核心与防御核心

- 引入至少两种不同权限方向。
- 医疗核心：强在消毒、医疗设备维护、生物稳定、大量伤员处理，不是万能治愈。
- 防御核心：强在屏障、车体隔离、黑雾冲击防护、危险区域驻留。
- 用一次区域事故让三种核心分别承担不可替代任务。

**读者新东西**：真正成熟的医疗列车/防御列车，视觉上与归途站完全不同。

**动作场面来源**：黑雾冲击、设备失压、轨道错位、屏障崩溃，不转成杀怪升级。

## 171～183：路线定价与两种模式

- 制造核心倾向中央合同、统一规格、大批量低成本。
- 归途站坚持开放接入、小站选择和兼容旧设备。
- 一部分站点更喜欢中央标准，一部分更适合归途站服务。
- 双方争订单、路线、材料，不互相摧毁。
- 周野必须承认对方在大规模标准件上更强。

**读者收益**：主角首次面对“对手的方法确实更有效”的长期竞争。

## 184～195：多核心联合工程

- 一条区域级线路发生大型故障，单一核心均无法完成。
- 制造核心提供批量结构件；医疗核心承担人员保障；防御核心撑住危险区；归途站用万物融合解决不同系统接口。
- 首次执行“多系统兼容”，必须有各方授权，不能吞并别人能力。

**卷级升级：【区域移动服务核心】**

可见变化：

- 新的多核心接口舱/授权节点；
- 更强通信中继；
- 联合工程挂点；
- 可临时接入其他核心模块。

**卷尾问题**：合作站点快速扩大，归途站开始面对“自己会不会成为新的中心”。

# 第五卷《百站共约》196～250

## 196～208：大型枢纽邀请

- 北部大型枢纽提供更完整医疗、制造、人口和仓储。
- 条件是公共任务优先服从中心调度。
- 周野接受部分资源交换，不交出路线与融合控制权。
- 让大型枢纽先真正救人、解决问题，证明中心化不是天然邪恶。

## 209～220：公共任务边界

- 核心成员第一次因公共任务占比持续争执。
- 梁文山：能源安全；唐岚：农业不能透支；林秀兰：居民生活不能永远为外部让位。
- 建立本车公共任务预算：能源、时间、材料都有硬上限。
- 超出部分必须由合作站点共同承担。

**强场面**：外部大量请求等待时，归途站内部仍按时开饭、供暖、给孩子/普通居民保留生活空间——说明“保护自己的家”也是责任。

## 221～235：移动城镇

这是全书一个重要生活爽点阶段。

必须真正建设并使用：

- 正式住宿区与更稳定私人空间；
- 公共食堂；
- 医疗区；
- 公共浴室/热水；
- 教育和培训空间；
- 小型制造区；
- 公共休息区；
- 市场/生活服务位。

人口提升到80～150人。

**卷级大升级：【移动城镇核心】**

不能只弹系统提示，至少连续数章让读者“住进去”：早餐、洗澡、学习、工作、夜间灯光、市场、居民分工。

## 236～246：集中保全事件

- 大型枢纽遇到区域危机，决定放弃几个低收益小站以保护中心供应。
- 其计算真实合理，不能写成恶人。
- 归途站利用已经形成的多站分担找到第三种方案，但成本更高、更复杂。
- 有小站仍选择撤入大型枢纽，尊重其选择。

## 247～250：百站共约

形成【百站协作约章】：自治、公开服务费、紧急互助、生命线不得永久买断、公共任务共同出资。

**卷末兑现**：归途站是一座真正会移动的小镇；北部形成联盟，但周野没有成为“百站之王”。

# 第六卷《黑雾断层》251～305

## 251～263：消失的线路

- 一条已经稳定运行很久的线路开始“变长”。
- 车走相同时间却无法到原站；两个站点坐标短暂重叠；轨道在视觉和机械测量中不一致。
- 过去建设的普通维修手段第一次明显失效。

**读者新景象**：列车窗外同时出现两个互相重叠的城市/站台；前进20公里却回到自己线路后方。

## 264～277：断层远征

- 组织小规模专业队深入黑雾断层。
- 必须体现长距离危险作业：补给、轮班、通信、撤退路线。
- 发现不同区域建筑/铁路重叠，确认世界不是完整连续大陆。

**动作感**：坐标错位、车厢受力、线路消失、人员撤离，而不是怪物围攻。

## 278～290：系统维护层

- 读取旧主干维护日志。
- 系统并非神秘游戏外挂，而是灾后应急维护层。
- 初始列车是移动维修单元。
- 不同移动核心对应不同维护职责。
- 万物融合的本质是高兼容结构重构工具。

**读者认知升级**：前两百章建设突然获得新的解释。

## 291～305：主干权限碎片

- 断层深处找到旧主干控制站。
- 中央保护程序提出：删除一批外围坐标，可快速开放主干入口。
- 周野暂时拒绝，只取权限碎片和历史日志。
- 明确当年中央系统曾主动切断支线。

**卷级能力升级**：高级相位导航 + 节点修复权限 + 主干权限碎片。

**卷尾钩子**：北境之外的多个大区域开始在新导航中出现。

# 第七卷《四域并轨》306～360

## 306～318：第一次跨域班次

- 真正写长距离旅行，不一章瞬移。
- 数天在途：补给、住宿、驾驶轮班、维修、车内生活。
- 读者重新得到“带着家旅行”的核心幻想。
- 建立卫星接驳列车与中途维护站概念。

## 319～332：四域资源互补

四域功能保留既定设定：工业、农业、能源、医疗。

- 每域有明显视觉与生活差异。
- 唐岚、梁文山、许成等长期专业线得到跨区域兑现。
- 不让每个区域都“求归途站救”，它们拥有归途站需要的东西。

## 333～346：穹顶城

- 引入大型移动城市【穹顶城】（工作名）。
- 它明显比归途站更大、更整洁、更安全，医疗、人口、制造都强。
- 它主张逐步把资源集中到少数移动城市，固定小站可在条件成熟时迁移放弃。
- 领导者有真实救人记录与治理能力。

**强场面**：归途站第一次停靠在一座比自己大数倍、灯火通明的移动城市旁。

## 347～360：四域并轨

- 四域节点同时发生连锁失效。
- 穹顶城单体能力强，却无法同时覆盖所有外围方向。
- 归途站用百站约章、多核心接口和各域资源组织分布式修复。

**卷级升级：【移动轨道城】**

可见变化：多列接驳、工程附车、跨域通信、区域级补给和更大的居住结构。

人口可到200～400。

# 第八卷《轨道城市》361～410

## 361～373：城市日常

这是重要的“种田兑现篇”。

必须写真实城市生活：

- 早餐高峰；
- 学校和学徒；
- 公共浴室；
- 医疗排班；
- 市场夜晚；
- 温室收获；
- 噪声、隐私、房间分配；
- 卫星列车回站；
- 普通居民的工作与休息。

周野不再处理所有小事。

## 374～386：制造与教育

- 周建国从“亲自修”转为培养工程队。
- 许成建立维护档案和接口教学。
- 唐岚带农业学徒。
- 医疗建立辅助培训。
- 小制造能力开始稳定供应外部站点。

**读者收益**：早期核心成员真正成为一代“老师傅/负责人”。

## 387～398：卫星列车与自治

- 多列接驳/工程附车拥有独立负责人。
- 归途站建立分级授权。
- 有居民提出“既然归途站更安全，为什么不直接接管小站”。
- 周野明确服务与自治边界。

## 399～410：城市级考验

- 跨域供应中断。
- 归途站必须在本城数百人的库存与外部生命线之间取舍。
- 过去合作站点开始反向支援。
- 证明网络强于单纯囤货。

**阶段成果：【成熟轨道城市】**

- 卫星列车；
- 教育体系；
- 居民自治；
- 批量制造；
- 专业团队可脱离周野独立工作。

# 第九卷《主干线之争》411～465

## 411～423：旧网络同时失效

- 多区域同时衰退。
- 早期七站、曙光、百站联盟、四域开始反向支援归途站。
- 大量回收前文建设，让读者看到几百章投入没有白费。

## 424～437：中央重启提案

中央层给出真正诱人的方案：

- 快；
- 成功率高；
- 优先保住人口密集核心区；
- 代价是大量低稳定外围坐标永久删除。

穹顶城支持。

一部分归途站盟友也支持。

周野提出分布式方案，但成本更高、需要更多节点与时间。

**禁止**：把中央方案写成明显邪恶按钮。

## 438～451：联盟分裂

- 不同站点、居民、移动核心做出不同选择。
- 冲突表现为权限、材料、迁移、线路开放和信息公开。
- 有人离开归途站体系去穹顶城，允许合理分歧。
- 另一移动核心不必全部站周野。

**强场面**：不是战场，而是一条条站点在地图上选择“中央”或“分布式”，网络结构真的改变。

## 452～465：主干入口

- 归途站承担主干维修载体。
- 农业、能源、制造、医疗、坐标数据从各地集中到工程上。
- 获得最后主干权限。
- 完整揭示：中央保护程序被设计为在极端情况下允许删除外围。

**卷级升级：【主干线移动修复核心】**

此升级不是“可以单人救世界”，而是终于具备承载全网协作的接口与权限。

# 第十卷《重启无尽轨道》466～510

## 466～478：全面断线

- 黑雾扩张，多条跨域线中断。
- 归途站不可能亲自到所有地方。
- 地方负责人、卫星列车、旧规则和公开班次开始独立运行。
- 核心成员各负责工程、能源、农业、医疗、物流、生活和通信。

**读者感受**：前九卷培养出来的人和组织全部“自己动起来”。

## 479～491：分布式启动

- 各域选择本地重启锚点。
- 普通小站通过真实人口、物资、交通流维持坐标稳定。
- 七站、曙光、百站联盟、四域、其他移动核心全部回归主线。
- 穹顶城负责大型核心区稳定，但承认单一集中方案覆盖不了所有外围。

## 492～501：中央主干远征

- 归途站进入最深层主干控制区。
- 障碍是错误坐标、权限冲突、能源分配、结构崩坏。
- 万物融合的终极用途揭晓：**兼容不同系统、不同年代、不同标准的节点，让它们在不被吞并的情况下连接。**
- 每次关键融合都需要对应节点/核心授权。

### 终极尺度回收

早期：50mm水口接不上40mm。

中期：不同站点、不同核心、不同制度接不上。

终局：不同空间碎片与主干网络接不上。

主角几百章做的是同一件事，只是尺度越来越大。

## 502～506：重启与代价

- 分布式方案比中央方案慢。
- 有部分线路必须暂时隔离；有现实损失和无法全部救回的节点。
- 但绝大多数重要小站和核心人口线路被保留。
- 黑雾没有彻底消失，变成可监测、可隔离、可逐步修复的异常区域。

## 507～510：尾声

- 周野和父母仍生活在归途站。
- 核心成员进入各自长期岗位。
- 普通居民可以凭公开班次跨站旅行。
- 不把周野写成世界统治者。

**最后一幕建议保留既定方向**：

一个普通家庭拿着公开车票登上接驳列车，去往曾经隔绝的另一座站。

归途站窗外仍有黑雾，但轨道信号已经是绿的。

# 五、战斗与危险的长期定位

本书不建立传统“等级—技能—怪物—Boss”战斗系统。

危险与动作场面主要来自：

- 黑雾空间错位；
- 线路坍塌；
- 车体/桥梁/屏障失效；
- 极端气候；
- 人员撤离；
- 路线封锁；
- 资源竞争；
- 大型工程失败风险；
- 不同组织之间的现实冲突。

可出现必要的人类暴力、防卫和护送，但不能让它取代建设、路线和连接成为核心成长计分板。

# 六、以后续写时的强制检查

每写一批新章前，至少回答：

1. 当前处于哪个10～25章中型篇章？
2. 这个篇章推动哪2～3条长期主线？
3. 最近一次读者小兑现在哪一章？
4. 下一个明显的新场景/新能力是什么？
5. 本篇最强场面还在不在？
6. 是否连续过多章节只写流程、维修、账目、接口或制度？
7. 本篇结束后归途站到底多会做什么？
8. 下一篇为什么自然发生？

如果回答不了，先改大纲，不继续机械续写。
