# 长期总纲

> 全书详细终极规划见：`docs/master-outline.md`。
>
> 本文件保留十卷快速结构，供日常续写确认方向。涉及世界谜底、人物长线、升级阶梯和终局设计时，以 `master-outline.md` 为准。

## 阶段规模

- **第1～510章：已设计完整的第一大阶段，十卷**，维持分布式重启与普通人跨站旅行的完整兑现。
- **第511章以后：同一作品的滚动续写储备**。先构思511～690的三个独立篇章，再凭真实读者数据决定是否继续，不能为延长而推迟第510章高潮。
- 新阶段以新区域探索、实际融合建设、可见生活空间和人物变化为中心，不重复上一个阶段已经结算的制度冲突。
- 具体接续见 `docs/ongoing-serial-plan-393-onward.md`；尚未授权平台续排。

## 全书主线

> 找到家人并活下去 → 建成移动家园 → 连接七座小站 → 建立开放商路 → 接触其他移动核心 → 形成百站协作网络 → 查明黑雾与系统真相 → 完成四域并轨 → 建成成熟轨道城市 → 拒绝牺牲外围的中央重启方案 → 重启分布式无尽轨道。

## 第一卷：初生移动站（1～35章）

从一节破旧车厢起步，找到父母，建立补给、冷藏、仓储、维修、农业与能源体系。

第30章时移动站点已经正式命名为【归途站】，完成曙光零号相位锚任务、E-4救援、市场和岗位制度。

31～35章处理七座失联小站入口、离开曙光、第一次正式发车，并补上基础医疗与临时住宿能力。

卷末成果：归途站约9～10名核心成员，具备普通黑雾短程通行、基础诊疗、临时住宿和北部路线入口。

## 第二卷：北境七站（36～94章）

连接生活保障线上的七座孤立小站：白栎、暖桥、沉泉、麦丘、炉坪、旧港、北岬。归途站是移动运输/维修/协调节点，不算第八座被归途站拥有的固定站。

重点建设：基础医疗、稳定净水、食品加工、正式住宿、卫生制度、公开服务费、运输成本与固定互助班次。

当前实际基线：

- 36～46：白栎—暖桥；
- 47～56：沉泉；
- 57～66：麦丘 + 正式住宿/卫生兑现；
- 67～77：炉坪—旧港；
- 78～88：北岬技术合作 / N-3，其中87～88只快速兑现N-3-4并收束；
- 89～92：燃料运输与关键道岔维护成本；
- 93～94：真实任务跑通第一条稳定互助线路。

七站不全部求救，也可以拒绝合作、只接受单项合同或保留独立路线。

卷末成果：归途站升级为自给型移动服务站，建立第一条稳定互助线路；七站能够长期互相活下去，但尚未形成第三卷级别的统一商路制度。

## 第三卷：联轨商路（95～145章）

资源稳定流动后，冲突转向价格、接口、信用、保险和路线权。

归途站推动标准停靠、货物分级、公开结算和区域商路协议。第二卷已有的具体服务价格、固定互助班次继续作为基础，不在卷首重新发明。

卷末出现另一移动核心活动的明确证据，归途站成为区域服务枢纽。

## 第四卷：移动核心（146～195章）

正式引入其他系统扶持的移动核心：标准制造、医疗维护、防御屏障或通信调度等。

各核心能力互补，也在路线定价和中央合同上竞争。

卷末完成多核心联合工程，归途站升级为区域移动服务核心。

## 第五卷：百站共约（196～250章）

多个大型枢纽与小站围绕集中管理、公共责任和站点自治产生冲突。

归途站建立公共任务预算、居民制度、教育培训和小型制造能力，升级为移动城镇。

卷末形成百站协作约章：站点自治、公开服务费、紧急互助、公共任务共同出资、不得永久买断生命线。

## 第六卷：黑雾断层（251～305章）

稳定线路出现空间断层，归途站深入黑雾并确认：

- 无尽轨道连接多个被灾变切割的空间区域；
- 系统是崩溃后的应急维护层；
- 初始列车是移动维修单元；
- 黑雾是坐标失配和空间重叠形成的异常；
- 中央程序曾主动切断支线以保住核心区。

卷末取得主干线修复权限碎片与高级相位导航能力。

## 第七卷：四域并轨（306～360章）

连接工业、农业、能源与医疗四个功能互补区域。

出现主张集中人口、逐步放弃固定小站的大型移动城市“穹顶城”（工作名）。

卷末四域初步并轨，归途站升级为移动轨道城。

## 第八卷：轨道城市（361～410章）

专门兑现归途站成为城市后的生活和经营：数百人的住宿、医疗、食堂、教育、卫生、制造、卫星接驳与自治。

归途站必须证明自己不会因规模扩大而成为新的中心霸权。

卷末形成成熟城市制度和能够独立执行任务的专业团队。

## 第九卷：主干线之争（411～465章）

无尽轨道进入全面失效前夕。

中央系统提出快速重启方案：保留大型核心区，永久删除大量外围坐标。

归途站提出更困难的分布式方案，需要过去建立的站点、标准、物资和移动核心共同参与。

卷末取得中央主干入口，归途站成为主干线移动修复核心。

## 第十卷：重启无尽轨道（466～510章）

前九卷建立的人、站、设施、制度和信任全部进入最终重启。

周野的万物融合终极用途不是吞并其他站点，而是兼容不同移动核心和区域节点。

最终完成分布式重启：黑雾不再无序吞没线路，普通人可以凭公开班次在站点间安全通行。

结局中，归途站不成为统治中心，仍保持移动能力，继续修复尚未恢复的支线。

## 第511章起的同书续写储备

- 511～570《地图之外的站》：沿已恢复主干寻找仍未开放的民用旧线，发现新的真实生活区，建设远端临时补给节点。
- 571～630《山谷与海风》：进入新地理环境，利用合规回收资源融合防潮、冷链、居住与生产模块，继续“带着家旅行”的核心幻想。
- 631～690《远域慢车》：与有独立技术优势的当地群体合作，开出真正改变普通人生活的远域公共班次。
- 后续按每50～60章的完整阶段动态规划，不能只靠同类任务换地点凑章节。

## 全书节奏原则

- 每卷最多一次真正改变格局的区域级升级。
- 新完整车厢至少间隔6～10章，优先采用模块、附车和改造。
- 每个设施都必须在后续反复兑现用途。
- 每卷至少兑现一个长期生产或生活成果。
- 大型冲突必须结合人员、制度、情报和已建能力解决。
- 归途站连接小站，不吞并所有小站。
- 主角最终修复网络，不称帝、不建立个人帝国。
- 标准版必须保留“移动核心”和“轨道城市”两个独立阶段，不能刚引入就匆忙进入终局。
