## 第71章《想进旧港，先上秤》

- 归途站主体无法通过炉坪—旧港维护廊，只派两节轻型接驳编组前探。
- 桥面有6处近期人工加固钢板。
- 当日临时通行条件：**18吨以下、低速、单编组、桥上不停车**；不是永久额定值。
- 前探人员：周野、孙海峰、许成、马立平。
- 接驳编组实测14.72吨，以5km/h通过。
- 旧港东桥有人值守，有机械称重板、红/黄手旗、旧登记本和货物登记。
- 翻牌器显示归途站为**今日第7车**。

## 第72章《前六辆车从哪来》

- 旧港东货场确认当天前6辆车来自三条既有轻型商路：
  - **北岬外仓**：滤材、电池壳、密封件、照明件；北岬仍“不接受外来列车进站”，但站外2公里设外仓交易。
  - **南堤菜棚**：鲜菜、腌菜、干菜、种薯；南堤不是完整车站，而是防洪维护点附近聚居形成的小节点。
  - **灰坡拆解场**：废铜、旧轴承、电机旧件、钢板；同样不是完整车站。
- 三条路线均有真实往返痕迹，但归途站**没有通行授权**。
- 旧港采用颜色路牌：黄牌北岬、绿牌南堤、灰牌灰坡；谁的路谁发牌，旧港只认牌、不替别人授权。
- 第8辆车来自北岬外仓，第9辆车即将来自南堤，证明这套商路是日常运行，不是一次性事件。

## 第73章《旧港不替别人发路牌》

- 第9辆南堤轨道车实际到站，携带叶菜、腌菜、种薯，换走轴承、密封条、旧水泵；货单三天前已开，证明旧港已有预先约定的稳定换货节奏。
- 南堤驾驶员也从北部公共频道听说过“归途站”，解释旧港此前为什么知道这个名字：不是神秘监控，而是运行中的车辆和公共频道传播。
- **老钱**正式进入正文：旧港旧线路员，和炉坪巡线员马立平是旧识；现在负责残存轻型线路相关事务。
- 半年前旧港曾要求外来列车提交完整成员、食物、饮水、药品、能源等库存，这一历史矛盾已解释：那是灾变初期水位下降、客运线断裂时照旧避难预案制作的“外来列车接收评估”表，使用不到10天即因过度暴露隐私和没人愿填而废止。
- 当时有人私下提醒归途站“别交库存”，身份仍未知；不强行揭晓。
- 当前旧港东桥只登记**本车人员、本车货物和车重**；不索取整座移动站库存。
- 旧港的权力边界明确：只管东桥、称重、货场和旧港自己的接入；北岬/南堤/灰坡的路牌必须由各自节点授权。
- 炉坪—旧港维护廊历史上由双方共同维护。炉坪此前长期无人能对外表态，所以旧港只管理桥西一端。
- 老钱交给马立平一块尚未完成的白牌：
  - `旧港—炉坪`
  - `临时往返`
  - 右下角留空，需要炉坪方面确认并打上本地记号后，旧港才会换成正式白牌。
- 许成当前路线扫描状态：
  - 北岬外仓线：实体往返确认 / 无通行授权
  - 南堤线：实体往返确认 / 无通行授权
  - 灰坡线：实体往返确认 / 无通行授权
  - 炉坪—旧港维护廊：临时通行 / 待双方确认

## 当前创作硬规则

- 常规单章约2800～3500字，硬上限3800；一章一个主目标。
- 每章至少出现一个可见变化：资源、路线、设施、人员关系、权限、交易、真实使用结果之一。
- 系统提示只在信息真正变化时出现。
- 周野负责路线、融合、协议、资源优先级与是否承担风险；专业岗位做专业判断。
- 不写连续会议和制度说明，规则必须通过实际使用呈现。
- 章末落在动作、物件、数据、对话或未解决的小问题，不写“总结+升华”。
- 归途站连接小站，不吞并小站；旧港也不替其他节点授权。
