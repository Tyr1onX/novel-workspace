## 写作流程

每个新章固定执行：

`Architecture Lite / QUD → First Draft → Narrative Pass → Dialogue → Humanizer → Prose → Meta → Continuity / Numbers → Final Read`

章末继续停在具体动作、设备、货物、数字、路线条件或未决问题，不写“本章意味着什么”。
