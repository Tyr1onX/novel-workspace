## 297～305：第六卷《黑雾断层》收束

- N07-A碎片不再只是历史档案，开始支持邻接节点诊断。
- 湖原方向H12被验证为今天仍存在回应的维护中继；H03远端只读摘要可被唤醒。
- 归途站先修复无人维护平台R-4，再验证T1/M1转接层，不直接跳去外域。
- 获得有限、可审计的局部节点修复能力；活跃居民节点只能生成修复建议，不可强制改坐标。
- 白栎通过固定节点相位参照降低渐进修复成本，但没有获得永久豁免。
- 高级相位导航定位为“层级识别 / 邻接预测 / 回撤校验”，明确不能替驾驶员自动开车。
- 第305章形成四域方向：北境工业区、湖原农业区、熔谷能源区、旧城医疗区。
- 第六卷结束时，主干删除方案仍未执行；归途站拿到的是继续渐进修复和跨域验证的钥匙。

## 306～318：第一次跨域班次

- 第一趟不是瞬移：主体列车经N07、R-4、T1/T2和维护层分多日抵达湖原。
- 车内生活被完整保留：三天九顿饭、热水、灰水、住宿噪声、学校、市场和夜班都参与跨域运行。
- 湖原不是等待救援区域；有自己的粮、水、维护队、订单和线路优先级。
- 接驳-01开始脱离主体执行独立任务；程扬成为负责人，任务可自己判断但受货权/能源/返回时间边界约束。
- H12恢复北境与湖原双向联系，但维护权仍分属两侧。
- 北境制造与湖原粮水形成第一条稳定互补链；F-02批量制造，归途站不吞并制造核心能力。
- 建立北境—湖原01线，试运行固定六日一班，并允许其他承运方未来接入。
- 长途能力真正体现为：主体城市能在陌生线路上继续吃饭、洗澡、上课、检修和换班。

## 319～332：四域资源互补

- 工业区不缺钢却受工艺水约束；湖原工业水、北境本地备份共同形成多来源保障。
- 湖原种质跨域采用小批、冷柜、对照、失败记录和原始保有方机制，不把“共享”写成一次交空家底。
- 熔谷能源丰富但守住本地最低线；可售模块、可售功率和本地安全余量分开。
- 旧城医疗区主要输出医疗能力和时间窗，不让归途站变成医疗车。
- F-02、湖原、熔谷、旧城都出现“自己做不了/买不到”的东西，四域互补从标签变成真实供应链。
- 普通货运队开始通过限定认证直接跑跨域线，货单可绕开归途站。
- 公共资源目录按资源类型采用不同公开颗粒度，不强制公开原种库、患者信息或全部能源底线。
- 四域联运和调度逐步脱离单一中心/归途站，运行图从残图变成可用网络。
- 第332章结束时，穹顶城进入四域运行图，准备正式接触。

## 333～346：穹顶城

- 穹顶城规模、床位、食堂、维修坞、人口与制造能力都明显强于归途站。
- 它的集中路线有真实优势：维修便宜、医疗覆盖大、迁入后部分小站生活质量提高。
- 同时保留边界：不接所有小支线、不免费维修、不自动获得全部站点数据。
- 有小站选择迁入，也有小站明确留下；两条路都写出真实成本。
- 归途站从穹顶城学习食堂交接、坞修基准和培训，但不照搬全部制度。
- 穹顶城拿到分层数据授权而非全量客户路线；双方保持理念差异和长期合作可能。
- 第346章穹顶城离开，没有“谁赢谁输”。

## 347～360：四域并轨

- 四域同时出现版本/同步偏差，先缩小到具体差异，不把事件写成全网神秘崩坏。
- 湖原先保本地粮，熔谷可把外售功率降为0，旧城会停普通采购；各域先守本地底线。
- 穹顶城可以保主干，但覆盖不了全部外围；百站共约开始扩展到四域之外。
- N07只提供有限权限窗口；四域各修自己的一段，不由归途站接管全网。
- 普通货车成为第一辆全程通过的日常车辆，跨域线路开始脱离“英雄首航”。
- 接驳编组增加，主体不必跟着所有小任务走。
- 第360章四域并轨收束，归途站进入【移动轨道城】状态。

- 沈青禾仍是白栎医疗技术员，不被写成归途站医生；新增正式基础医生与辅助岗位。

- 第373章以城市完整换班收束“城市日常”：岗位开始独立于个人运行。

## 继续有效的硬边界

- 归途站核心优势仍是兼容、重构、移动、连接不同系统；不得吞并F-02、MED、D-11和各区域专业能力。
- 高级相位导航是辅助工具，不替代机械承载、驾驶判断与环境窗口。
- 局部节点修复不等于主干控制；居民节点不得被归途站单方面改坐标。
- 湖原、熔谷、旧城、北境都保留自己的关键资源与最低安全线。
- 穹顶城是有能力、有成绩的长期理念对手/合作方，不得反派化。
- 沈青禾仍属于白栎医疗技术员轮班体系；宋雨眠仍是白栎医疗负责人。
- F-02负责稳定批量制造；归途站小制造保持小批、非标准与兼容定位。
- 接驳编组可以独立执行，但不能把任务边界、货权、能源和人员责任写成“负责人自行决定一切”。
- 城市岗位可以独立运行，但高风险/跨域/关键结构仍需对应专业层级复核。

## 写作流程

每个新章继续执行：

`Architecture Lite / QUD → First Draft → Narrative Pass → Dialogue → Humanizer → Prose → Meta → Continuity / Numbers → Final Read`

章末优先落在具体动作、设备、班次、货物、人物选择或未决条件上，不用作者式总结替读者概括意义。
