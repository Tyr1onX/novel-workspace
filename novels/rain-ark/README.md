## 开书用文案

**推荐书名**：《末日暴雨：我能把整栋楼升级成方舟》

**简介（暂定）：**

暴雨下到第七天，水已经淹到二楼。

陆沉被困在十八层居民楼里。电梯停了，楼梯间开始进水，整栋楼的饮用水只够再撑一天。

就在所有人准备继续往高层搬时，他看见了别人看不到的建筑改造图。

一台报废水泵，变成了挡住洪水的止水节点；屋顶裂开的旧水箱，接出了第一桶干净水；居民舍不得交出的几块电池，让十八层楼的应急灯重新亮起。

可升级需要真材料，也需要有人肯把自己的东西拿出来。楼里的水和电刚稳住，隔着两个路口的公寓又发出求救信号。

洪水还在上涨。陆沉开始想，既然整栋楼都能改造，那能不能让它离开这里？
