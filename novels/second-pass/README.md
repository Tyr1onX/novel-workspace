# 《开局小厂要倒闭，我让失败变成黑科技》

> 内部项目代号：Second Pass
> 首发平台：七猫中文网
> 状态：**V2 RESTRUCTURED / WRITING**

该目录只保存本书自己的设定、机制、人物、章节卡和正文，不继承其他小说的世界观与连续性。

## 当前核心方向

> **现代小厂起步 × 失败回收系统 × 黑科技制造 × 自用装备 × 主角自身进化 × 科幻成长**

一句话幻想：

> **别人失败一次，损失一次；周屿失败一次，就能把失败变成经验、材料和下一代黑科技。**

小厂、订单、赚钱只负责第一张地图，不再作为全书最终主线。

长期成长：

> 废品 → 黑科技产品 → 失败项目 → 自用装备 → 人体适配 → 个人进化 → 更高层级技术失败资源。

## V2 系统

系统可以从真实失败中提取价值：

- 学习失败经验；
- 回收失败品材料；
- 直接修复；
- 直接强化；
- 消耗失败样本和材料完成实物重构；
- 跨失败库融合新技术；
- 中后期把主角本人纳入可进化对象。

系统不是“诊断助手”。获得经验后也不要求主角再按传统研发制造流程从头做一遍。

## 第一产品

> **工业无人机动力模组。**

开局18件客户退货是第一批失败资源。

第一章必须直接完成：

> 退货废品 → 失败经验/材料 → 首次重构 → 超规格动力模组 → 现实性能兑现。

## 写作硬规则

- 前300字出现核心幻想，不先讲履历和工业背景；
- 第一章必须有实物黑科技和直观性能差距；
- 技术线索不是爽点，必须兑换成成品、装备、钱、资源、地位或个人能力；
- 读者已看到的废品/资源尽量交代主要去向，不浪费；
- 大逻辑稳定，小逻辑优先服务爽感；
- 系统允许跨过正常制造成本，不能再次削成普通工程工具；
- 商业服务升级，不把后半本写成商战权谋循环；
- 最强一代技术逐步转向主角自用；
- 中期开始装备成长，随后自然进入主角身体进化。
