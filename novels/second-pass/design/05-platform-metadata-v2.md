# 七猫平台定位 V2

> 日期：2026-08-25
> 目标：与重构后的“失败回收 → 黑科技 → 装备 → 自身进化”方向对齐。

## 一、作品名称

平台当前使用：

> **《开局小厂要倒闭，我让失败变成黑科技》**

继续保留。

理由：

- “小厂要倒闭”给现实危机；
- “失败”给反常识资源；
- “变成黑科技”给明确上限幻想；
- 新 V2 机制比原 V1 更真正兑现这个标题。

仓库旧长名《开局小厂要倒闭，我让每次失败都变成黑科技》不再作为正式平台书名。

---

## 二、分类建议

### 旧分类

> 男生 → 都市 → 都市生活

### V2 推荐

> **男生 → 都市 → 都市高武**

理由：

- 开局仍是现代城市、小厂和黑科技，不适合一开始放进纯未来世界；
- 中期明确进入外骨骼、自用装备、个人强化和现实冲突；
- 后期主角自身进化，已经明显超出普通“都市生活”；
- 七猫公开书库中，《全车黑科技，保时捷拿什么跟我比》和《落榜后接手民用模具厂，鹰酱吓哭了！》这类现代黑科技/工厂强幻想作品均被归在“都市高武”，说明这个二级分类对现代强能力黑科技题材具有实际容纳空间。

不推荐当前直接改成：

> 科幻 → 未来幻想

因为故事前几十章仍发生在当代现实壳里，未来幻想读者预期可能与“小厂开局”错位。

等作品真正写到中后期也不需要为了后期地图再换分类，分类首先服务开局获客。

- 逆袭

- **爽文**
- **快节奏**
- **系统**
- **逆袭**
- **科技**
- **都市**
- **天才**（如果标签位充足）

### 优先替换

`励志`、`人间清醒`不再是核心卖点。

如果后台实际标签库存在以下标签，优先替换进去：

1. **黑科技**
2. **升级流 / 进化**
3. **都市异能 / 超能**
4. **无敌 / 杀伐果断**（只有正文真正往这个方向发展后再用）

不要为了凑数量选择与正文无关的热门标签。

## 四、简介 V2

建议替换当前旧简介：

> 小厂濒临倒闭，客户一次退回十八件动力模组，尾款被冻结，仓库里只剩一地没人要的废品。
>
> 可周屿看到的却完全不同。
>
> 【检测到真实失败样本。】
> 【可学习、可回收、可修复、可重构。】
>
> 别人失败一次，烧钱、报废、重来；周屿失败一次，却能把失败变成经验，把废品变成材料，再直接重构成更强的黑科技。
>
> 废电机变成超规格动力模组，坠毁无人机变成下一代飞行平台，报废机器人、失败外骨骼、搁置实验项目……别人避之不及的技术垃圾，全成了他的矿。
>
> 直到有一天，最先进的装备已经强到连他的身体都跟不上。
>
> 系统弹出了新的提示：
>
> 【检测到使用者适配失败。】
> 【失败对象：宿主。】
>
> 周屿这才发现——
> 原来能被失败推着进化的，从来不只是机器。

简介重点：

- 前三行就解释卖点；
- 不再强调“系统也会判断错误”“复验通过才固化”等慢机制；
- 明确给出废品、黑科技、失败项目和个人进化四层幻想。

---

## 五、封面方向

现有封面“小厂危机 + 男主 + 电机 + 科技界面”仍可用，但 V2 方向下建议后续重做一版更强幻想：

- 男主前景；
- 左侧/下方是报废电机、无人机残骸、机械臂等“废品”；
- 废品向上重构成发光的无人机动力核心/外骨骼轮廓；
- 不要只画一个普通工厂老板；
- 让封面本身表达“垃圾 → 黑科技”。

---

## 六、后台需要人工修改的项目

七猫作者后台需手动处理：

1. 二级分类：`都市生活` → **`都市高武`**；
2. 简介替换为 V2；
3. 标签删除/弱化 `励志`、`人间清醒`；
4. 如果后台有 `黑科技 / 升级流 / 进化 / 都市异能`，优先补入；
5. 封面后续重做时同步新方向。

作品名称暂时不改。
