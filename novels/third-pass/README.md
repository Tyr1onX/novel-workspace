# 《你最好第一次就杀死我》

> 首发平台：待新建作品时确认，优先七猫男频

V3 是在《开局小厂要倒闭，我让失败变成黑科技》签约驳回后的独立新书，不继承其人物、工厂、订单、废品仓库和系统界面。

## 工作书名

> **《你最好第一次就杀死我》**

标题先作为V3工作标题使用。最终新建平台作品前仍允许只改标题，不改核心能力。

## 核心幻想

> **林序和他亲手使用的装备，会记住每一次真正差点毁掉他的失败。**
>
> **同一种失败，第一次能伤他；只要他活下来，第二次就未必还有用。**

这次不把“个人进化”放到中后期，而是第一页就让主角本人进入能力中心。

## 核心机制：失败记忆

它不是传统系统：

- 没有任务；
- 没有积分；
- 没有商城；
- 没有每日签到；
- 没有复杂科技树；
- 不用大量【检测/进度/融合】日志占正文。

只有一条稳定规则：

> **一次真实失败如果没能彻底毁掉林序，他本人以及当时与他深度绑定的装备，就会留下针对这次失败的“适应”。**

适应必须通过真实代价获得，不能靠看别人失败、捡垃圾或无风险刷次数。

同类失败重复收益快速衰减，逼迫主角主动面对新的、更高层级的失败。

## 题材方向

> **近未来都市 × 黑科技装备 × 个人进化 × 高危任务 × 适应型成长**

开局不是经营公司，也不是慢慢研发产品。

第一张地图直接放在城市高危救援和动力外骨骼事故中，让读者先看到：

> **第一次故障差点压死他；第二次同样的故障再来，已经压不住他。**

后续统一成长：

> 机械过载 → 冲击/高温/电击 → 动力装备 → 神经控制 → 自用装甲 → 人体与装备融合 → 更极端环境与更高级失败。

商业、订单、研究机构只负责提供资源和场景，不再承担主线。

## 主角

**林序，24岁。**

近未来城市应急装备维护/救援人员，懂动力设备和现场处置，但不是全知工程师。

人格核心：

- 不迷恋危险本身，迷恋“危险暴露出的答案”；
- 第一次吃亏会记得非常清楚；
- 真正让他兴奋的不是无伤碾压，而是发现“这一次失败以后，下一次已经不同”；
- 主动决定下一次要挑战什么失败，因此外挂不能替代他。

## V3 写作硬规则

1. 前300字必须出现一次真实危险和核心能力价值，不先讲世界史。
2. 第一章必须完成“第一次被同类失败重伤 → 适应形成 → 第二次同类失败明显失效 → 现实收益”。
3. 前三章至少有一个普通读者无需技术知识就能复述的视觉画面。
4. 爽点优先用身体、装备、生存、冲突结果表达，不主要靠性能数字。
5. 每一次新进化必须来自不同或更高层级失败，禁止同一种资源无限刷。
6. 每2章左右必须出现外部事件、对手、任务或人的选择，不能连续写测试日志。
7. 主角必须主动决定冒什么险、保留什么适应、用什么装备，能力不能替他做全部决策。
8. 第一阶段不能只解决一个经济问题，必须建立长期敌人与更大危险入口。
9. 最强装备默认优先主角自用，不重复“做出来就卖给客户”的旧循环。
10. 系统提示如必须出现，一次只允许一句短信息，正文主要靠事件表现规则。
