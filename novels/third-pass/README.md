## 原核心幻想

林序和他亲手使用的装备，会记住每一次真正差点毁掉他的失败；同一种失败第一次能伤他，只要活下来，第二次效果就会降低。

## 原题材方向

近未来都市 × 黑科技装备 × 个人进化 × 智能对手 × 高危冲突 × 适应型成长。

第一张地图为城市仓储坍塌救援和动力外骨骼事故。第一章曾尝试用“第一次远程锁死重伤 → 有人看见主角重新进入 → 第二次锁死失效”的结构完成标题兑现。

## 放弃时已经验证出的经验

这些经验可以继续进入其他项目，但不能用于复活本设定：

1. 核心幻想先过“作者自己是否想点”的门槛，不能只看结构评分。
2. 人为冲突应尽早进入，避免连续事故复盘/功能验证。
3. 强设定也不能替代人物欲望。
4. 删除能力解释以后，场景仍应有人物目标、阻力和选择。
5. 研究足够以后必须进入真实正文测试，不无限扩样本。
6. `shared/PROSE_RULES.md` 的语言闸门继续有效。
