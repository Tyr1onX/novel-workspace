# 项目简报 V3

工作书名：《你最好第一次就杀死我》

内部代号：Third Pass

## 立项原因

V2 已经证明：仅把“系统奖励”改成“失败回收”还不够。即使首章快速出黑科技，如果长期循环仍是收失败品、重构、测试、客户震惊，编辑仍会判断“普通、缺乏吸引力”。

V3 必须把核心幻想从“东西变强”改成“主角本人越来越难被同一种东西打败”。

## 一句话高概念

> 林序和他亲手使用的装备，会记住每一次真正差点毁掉他的失败；只要第一次没能彻底杀死他，同一种方法第二次就很难再奏效。

## 读者第一层幻想

普通人面对危险：

> 犯一次错，付一次代价；再犯还会再付一次。

林序面对危险：

> 第一次真的会痛、会伤、会差点死；但这次失败会永久改变他和装备。

所以读者天然会追问：

- 火烧过一次以后呢？
- 高压电击过一次以后呢？
- 外骨骼失控一次以后呢？
- 枪弹/冲击/爆炸呢？
- 如果对手不知道规则，用同一种杀法第二次呢？
- 如果失败大到连城市级装备都扛不住呢？

这就是V3的长期追读引擎。

## 第一张地图

近未来都市，动力外骨骼、工业无人机和智能救援设备已较普及，但仍存在大量高危失效。

林序是城市应急装备维护/现场救援人员。

第一章直接进入一次仓储区坍塌救援：

- 动力外骨骼在承重时发生关节锁死/输出反冲；
- 林序第一次被自己的装备压伤，差点被二次坍塌埋住；
- 他从真实失败中形成第一次“机械过载适应”；
- 为救仍困在里面的人，他必须再次进入相同工况；
- 同样的外骨骼过载第二次发生时，装备和身体已经会自动卸载、重分配；
- 第一章直接完成“第一次差点死，第二次同类失败压不住他”。

第一笔现实收益不是钱，而是：

> 他用一套刚刚差点杀死自己的失控装备，把别人从废墟里拖了出来。

## 与V2的根本区别

V2：

> 失败在外部 → 系统吃掉 → 产品升级 → 外部验证。

V3：

> 林序亲身失败 → 身体/装备留下适应 → 立即再次面对同类危险 → 生存和冲突结果改变。

失败不再是仓库资源，而是人物命运。

## 题材承诺

这不是纯商业文，也不是普通高武打怪升级。

长期体验必须保持：

> **技术灾难感 + 个人进化感 + 黑科技装备感 + 对手第二次出手无效的反杀感。**

## 第一阶段目标

前10章完成：

1. 核心能力首证；
2. 主角确认“失败必须亲身承担”；
3. 获得至少三种质感完全不同的适应；
4. 第一件专属自用装备成型；
5. 出现第一个主动利用主角弱点的人；
6. 让对手用同一种方式第二次出手并失败；
7. 建立更大入口：一批被封存的高危失败装备/项目正在等待测试。

前10章结束时，读者关注点应从“他能不能活”升级为：

> **下一种能逼他真正失败的东西，会是什么？**
