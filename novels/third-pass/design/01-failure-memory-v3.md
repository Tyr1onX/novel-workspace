# 核心能力 V3：失败记忆

## 核心规则

> **林序只要亲身经历一次真正的失败，并且没有被这次失败彻底毁掉，他的身体以及当时与他深度绑定的装备，就会记住这次失败。**

所谓“记住”不是获得一个抽象数值，而是产生针对性适应。

例如：

- 外骨骼关节过载反冲 → 身体学会更合理地卸力，装备学会提前释放过载；
- 高温灼伤 → 体表循环和装备热管理出现针对性适应；
- 电击导致神经失控 → 神经耐受和绝缘/泄放结构得到适应；
- 高速冲击 → 肌骨受力方式与护甲结构改变；
- 控制延迟差点致命 → 人机控制链缩短，反应与补偿方式改变。

## 什么算“真实失败”

必须同时满足：

1. 林序本人处于失败链中，而不是站在旁边观看；
2. 失败产生真实代价：受伤、任务失败、装备损毁、失控、失去重要机会等；
3. 结果在正常情况下足够严重，不是故意摔杯子之类的低成本刷取；
4. 林序最终活着并保留行动能力，失败才会沉淀为适应。

## 不允许被刷烂

同类失败的收益快速衰减。

第一次：完整适应。

第二次：主要验证适应是否有效，新增收益很少。

第三次以后：除非规模、机制或环境发生质变，否则几乎不再产生新成长。

因此林序不能靠反复触电、反复摔倒这种行为无限成长。

长期成长必须来自：

> **新的失败类型 / 更高层级失败 / 多种失败同时发生 / 原有适应互相冲突。**

## 适应对象

### 1. 身体适应

身体会把失败中真正限制生存的环节优化掉。

表现优先写成可见结果：

- 同样冲击不再骨折；
- 同样高温下还能行动；
- 电流通过时不再瞬间失去肌肉控制；
- 高G动作不再黑视；
- 神经延迟逐渐压缩。

不要频繁写“力量+3”“耐力+5”。

### 2. 装备适应

只有林序亲手使用、穿戴、操控并真正参与失败链的装备才会留下记忆。

它们可以出现：

- 结构重排；
- 失效保护；
- 动力重新分配；
- 材料局部变化；
- 控制策略改变；
- 与林序身体更深的人机适配。

装备不是商城奖励，而是在一次次实际事故里被“打出来”的。

### 3. 人机共同适应

V3最重要的长期升级。

当失败同时来自“人的极限”和“装备的极限”时，两者会开始共同改变。

例如：

> 装甲的动力足够，但林序神经反应跟不上。

下一轮真正失败后，成长不再只是升级装甲，而可能直接改变他的神经控制方式。

这就是从黑科技装备自然进入个人高武/进化的桥。

## 能力前台表达

禁止长期使用V2式系统面板。

正文优先表现：

- 痛觉；
- 身体产生的新本能；
- 装备结构发出的细微变化；
- 第二次同类失败到来时的强烈对比。

如果需要提示，只允许极简：

> **这次失败，被记住了。**

或：

> **同类失效，已适应。**

一句足够。

## 能力的真正限制

不是冷却时间，也不是积分。

而是：

> **想获得从未拥有的适应，就必须先真的暴露一个从未经历过的弱点。**

这意味着林序越强，下一次能真正让他失败的东西就越危险。

成长本身会主动制造更高的风险。

## 最核心的反杀规则

正文需要反复兑现、但每次换不同场景：

> **同一种方法，最好第一次就解决他。**
>
> **因为只要那一次没能彻底毁掉他，第二次就会变成他的优势。**
