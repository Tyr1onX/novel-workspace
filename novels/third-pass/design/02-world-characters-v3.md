# 世界与人物 V3.1

## 世界底色

时间：近未来，不写具体年份也可以。

技术已经比现实前进一截，但仍是普通人能快速理解的城市：

- 动力外骨骼进入消防、物流、抢险和工业现场；
- 无人机承担高空巡检、吊运和危险区作业；
- 神经控制、柔性护甲、轻量材料仍处于快速迭代期；
- 高危技术试验很多，事故也真实存在；
- 大量智能装备依赖厂商远程维护、云端安全策略和第三方控制协议；
- 城市里有大型装备企业、第三方事故调查 / 测试机构、应急机构和被封存的失败项目。

不要一开篇解释技术革命史。

读者只需要先接受：

> 这个世界已经有能替人扛几百公斤的外骨骼，它联网，它会坏，也可能被人从远处动手脚。

## 世界升级原则

前期不出现灵气复苏、怪物潮和突然的玄幻体系。

成长优先来自技术和人体极限逐渐逼近：

> 工业装备 → 高危装备 → 人机接口 → 专属装甲 → 人体适应 → 超常个体 → 极端环境技术。

世界扩大优先通过“更大的事故链 / 更强的技术参与者 / 更危险的人”完成，不靠突然换一套力量体系。

# 主角：林序

24岁。

城市应急装备维护兼现场救援人员。

不是科研天才，也不是顶级格斗家。

他的优势在于：

- 对设备失效非常敏感；
- 真出事时仍然能继续做判断；
- 吃过一次亏以后，会记住失败发生的具体路径；
- 一旦发现别人把他的弱点当成确定答案，他会想办法反过来利用这个判断；
- 他不喜欢把自己的命交给别人写好的“事故结论”。

## 人格核心

林序怕痛，也知道新的危险第一次真能杀人。

他不会为了升级主动拿自己刷伤害。

真正能把他重新推回危险里的东西通常是：

- 里面还有人；
- 证据马上会消失；
- 对手已经开始下一步；
- 退一步会让别人替他承担结果。

失败记忆改变的是他的风险计算方式。

已经吃过一次的亏，会让他更敢利用同一种局面；没有经历过的新方法，他仍然必须谨慎。

## 开局个人目标

第一章没有抽象目标。

他只想把程野和被困工人带出来。

第一章结束后，目标立刻变成：

> **保住事故机和原始日志，查清是谁在看见自己重新进入以后，又下发了第二次锁死指令。**

这一目标同时关系到：

- 程野受伤到底是谁的责任；
- 救援队会不会被写成违规操作；
- 第一条指令是不是事故；
- 第二条指令背后的人为什么想让现场按某种结果结束。

林序前期不是为了“确认自己的超能力”行动。能力只能在他追这件事的过程中被一点点认识。

# 程野

32岁，现场救援队长。

第一章和林序一起进入坍塌区，并在第一次锁死后被留在里面。

作用：

- 林序重新进入的直接人物理由；
- 普通人的风险尺度参照；
- 救援系统内部的人脉与旧事故信息入口；
- 会阻止林序把一次异常生还误解成“自己死不了”。

他不是捧哏。

林序第二次冲进去把他救出来以后，程野醒来的第一反应也应该先骂他，而不是负责宣布“你变强了”。

两个人的关系建立在长期一起进现场的信任上：

> 能互相把命交出去，也因此更有资格骂对方乱来。

# 苏岚

26岁，应急装备工程师。

她不是站在旁边解释技术的工具人。

第一阶段主动任务：

- 在第一章抓到第二次维护接管的本地记录；
- 保护事故数据不被云端覆盖；
- 追维护账号、项目编号和控制链；
- 判断 R7 后续出现的变化究竟是硬件、软件还是无法解释的第三种东西；
- 在林序开始靠直觉赌命时，用工程证据和现实风险和他发生冲突。

人物冲突：

> 她习惯在事故发生前消灭不确定性；林序的能力却让“已经真实发生过一次的失败”成为可以利用的信息。

两个人应该经常在同一个目标上意见不同，而不是一个负责冒险、一个负责夸他。

# 白启川

38岁，第三方重大装备事故调查 / 高危失效测试机构负责人。

前10章后半段正式进入。

旧版“带林序去封存库刷危险装备”的功能删除。

他首先带来的东西是一份事故名单：

> 不同厂商、不同设备、不同场景，却接入过同一套远程安全维护协议。

白启川的价值：

- 给更大的证据和事故视野；
- 提供合法接触危险现场与事故设备的权限；
- 有自己的机构责任和风险判断，不会无条件配合林序；
- 可以提供场景，不能提供能力答案。

# 第一阶段对手：梁骁

29岁，R7 供应商现场负责人。

第二章开始正式进入。

他不是“等主角打脸的产品经理”。

他的现实任务非常明确：

- 尽快把事故设备收回供应商控制范围；
- 把事故定性限制在操作超载 / 单机故障；
- 阻止本地日志进入不可控的第三方调查；
- 找出林序和苏岚到底保存了多少东西；
- 必要时让林序失去现场和设备权限。

梁骁知道的事情比他说出来的多，但前期不急着确认他是不是第一章亲自下指令的人。

这样可以让他同时承担：

- 眼前可见的对手；
- 更大幕后链条的入口；
- 一个也会观察林序、根据结果改变策略的人。

他不能一直重复“否认设备问题”。

一旦发现旧解释压不住，必须马上换动作：删日志、抢设备、推动停职、找执行者、改变杀法。

---

# 第一阶段真正的敌意

第一章以后，故事必须保留一个比梁骁更大的未知主体：

> **有人能使用远程维护通道，并且在观察现场结果。**

第一次锁死可能还有其他解释。

第二次锁死发生在林序重新进入并恢复联网之后，这使“人为选择”进入故事。

这个未知主体的可怕之处不在权限有多高，而在于它会学习：

> 锁死没杀掉林序 → 换电；
> 旧锁死已经失效 → 换热；
> 林序开始追日志 → 改证据链和执行方式。

林序也会学习。

前期真正的长线发动机是双方互相修正答案。
