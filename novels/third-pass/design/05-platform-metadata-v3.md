# 平台包装 V3

> 这里只锁“卖点表达”，不提前假定七猫后台一定有哪些分类/标签。新建作品时以实际可选项为准。

## 工作标题

首选：

> **《你最好第一次就杀死我》**

优点：

- 十个字左右，手机端识别快；
- 直接制造危险与反杀预期；
- 不需要先理解“失败回收”“黑科技制造”等抽象词；
- 天然让人追问：为什么必须第一次？

备选：

1. 《第一次杀不死我，就别想有第二次》
2. 《每失败一次，我就进化一次》
3. 《同一种死法，对我无效》
4. 《高武：你最好第一次就杀死我》

不再使用“小厂要倒闭”“失败变黑科技”式标题继续换皮。

## 一句话简介

> **第一次，失控的动力外骨骼差点把林序压死；第二次同样的故障再来，他却穿着那套装备从钢梁下站了起来。**

## 推荐简介 V1

动力外骨骼失控的那一刻，林序第一次知道，救人的装备也能把人活活压死。

他断了肋骨，救援失败，差点被二次坍塌埋在现场。

然后，那次失败被他的身体和装备一起记住了。

第二次，同一处关节再次锁死。

同样的重量再次压下来。

林序却没有跪下。

从那天开始，他发现一条越来越危险的规则：

**只要一次真正的失败没能彻底毁掉他，他和亲手使用的装备，就会对它产生适应。**

机械过载、高温、电击、高速冲击、人机失控……

每一种新的失败，第一次依然可能要他的命。

可一旦让他活下来——

**最好别再用第二次。**

## 推荐简介 V2（更短）

第一次外骨骼失控，林序被钢梁压断肋骨。

第二次同样的故障发生，他穿着那套装备重新站了起来。

他这才发现：

**每一次没能彻底毁掉他的失败，都会被身体和装备记住。**

第一次能伤他。

第二次，就未必了。

而随着机械过载、高温、电击、爆炸与人机失控一个个成为过去式，所有人终于意识到——

真正危险的从来不是林序第一次失败。

是他失败以后，还活着。

## 暂定分类

如果七猫后台仍有与上次相同的大类，优先考虑：

> 男生 → 都市 → 都市高武

理由：核心消费已经是主角自身超常成长与装备战斗/生存，而不是都市生活或商业创业。

如果后台提供更贴切的“科幻都市 / 未来科技 / 科技进化”类目，则现场再比较，不为了沿用旧选择强锁都市高武。

## 标签优先级

有则优先：

> 爽文 / 快节奏 / 高武 / 科技 / 进化 / 都市异能 / 黑科技 / 热血

不建议为了流量误贴：

> 系统

因为V3明确没有任务面板、商城、积分和传统系统。如果后台没有“进化/异能”，宁可少贴一个弱相关标签，也不要把能力重新包装成系统。

## 封面方向

核心画面只表现一个瞬间：

- 年轻男主穿半损坏的近未来动力外骨骼；
- 巨大钢梁/机械结构压在肩背；
- 装备一侧仍有红色过载警报和火花；
- 男主却正在从跪姿一点点站起来；
- 身体与外骨骼之间出现局部结构自适应的蓝白科技纹路；
- 背景是坍塌救援现场，不堆满系统UI。

标题重点字：

> **第一次 / 杀死我**

封面必须首先卖“人越来越杀不死”，而不是卖工厂、订单或工程参数。

## 新建作品前最后检查

1. 标题能否在不知道设定时引发一个问题？
2. 简介第一屏有没有第一次/第二次的明确对比？
3. 封面是不是人在危险中进化，而不是一个人站着配科技HUD？
4. 标签有没有把它重新误导成商业系统文？
5. 第一章实际内容是否兑现了包装，而不是简介比正文更强？
