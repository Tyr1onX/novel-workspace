# 第二章 没有抱错

我爸盯着桌上那张纸，没有伸手。

“谁给你的？”

他声音不大。

但我知道他慌了。

沈建明真正生气的时候，从来不拍桌子。

他只会突然变得很安静。

我没回答。

“你先告诉她。”

我看了一眼林晚。

“上面的名字是不是你的？”

我爸脸色沉了下来。

“一张不知道从哪弄来的复印件，能说明什么？”

“那就是你的名字。”

“沈知微。”

我妈终于开口，“你先把电话挂了，有什么事我们一家人慢慢说。”

电话那头的接警员还在确认地址。

我重新报了一遍。

我妈站在原地，嘴唇动了一下。

没再劝。

林晚一直没有碰那张纸。

她只是低着头，看着最下面的日期。

十二年前。

那时候她十二岁。

姑姑从沙发边站起来，小声说：“建明，要不今天先到这儿吧，孩子刚回来，闹成这样不好看。”

我爸没理她。

“都坐着。”

几个已经准备拿包的亲戚又停住了。

我忽然明白，他为什么要他们留下。

只要这里还是一场家宴，只要还有一屋子亲戚坐着，他就能把接下来发生的一切解释成家务事。

二十多分钟后，门铃响了。

两名民警站在门外。

“谁报的警？”

“我。”

我爸几乎同时开口。

“不好意思，家庭矛盾。孩子今天情绪有点激动。”

年轻一点的民警看了我一眼。

“电话里说涉及多年前寻亲和故意隐瞒，是吗？”

“是。”

“材料呢？”

我把桌上的纸递过去。

我爸伸手想拦。

年长的民警抬了下手。

“先让我们看。”

客厅终于没人说话了。

民警把那张纸展开。

第一页是一份委托单。

委托时间，十二年前。

委托人，沈建明。

委托事项只有一行：

**查找二〇〇四年七月十八日出生于市妇幼保健院的一名女婴后续去向。**

年轻民警看完，抬头问我爸。

“这个签名是你的吗？”

我爸停了两秒。

“像。”

“像是什么意思？”

“时间太久了，我记不清。”

我差点笑出来。

他的签名二十年都没变过。

公司合同、家长会签到、我的留学材料，右下角永远是同一个潦草的“沈建明”。

民警翻到第二页。

我妈突然往前走了一步。

“别看了。”

所有人都看向她。

她自己也愣了一下。

“我是说……”

她抓紧手里的纸巾，“这都是很多年前的事情，里面有误会。”

“什么误会？”

林晚第一次开口。

我妈不说话了。

第二页不是委托。

是结项回执。

上面印着几个字：

**目标人员已找到。**

下面是当年的信息核验结果。

姓名：林晚。

年龄：十二岁。

监护人姓林。

就读学校也写得清清楚楚。

最下面还有一句：

**委托方确认信息无误，本次服务结束。**

确认人后面，是沈建明的签名。

这一次，我爸没有再说“记不清”。

年轻民警把两页纸并在一起。

“也就是说，至少在十二年前，你委托人查过这个孩子，而且收到过已经找到她的结果？”

我爸靠在沙发背上。

“我当时只是有怀疑。”

“怀疑什么？”

“医院那边以前出过问题。”

“什么问题？”

“时间太久，我要查资料。”

他说得很慢。

每一句都给自己留了退路。

我太熟悉这种说话方式了。

公司出事的时候，他也是这样。

不否认。

不承认。

只说需要核实。

林晚忽然问：

“你怀疑我是你女儿？”

我爸看向她。

这是她进门以后，两个人第一次真正对视。

过了几秒，他说：

“当年没有足够证据。”

“所以你就没找我？”

“不是没找。”

“这张纸上写着‘已找到’。”

我爸皱眉。

“找到一个人，和确认血缘，是两回事。”

“那后来呢？”

林晚问。

我爸没有马上回答。

我妈先说：“晚晚，当年真的很复杂。”

林晚转头看她。

“哪里复杂？”

“很多事情你现在不知道。”

“那你告诉我。”

我妈眼圈一下红了。

她最擅长这样。

一旦解释不了，就先哭。

以前我看到她这样，会立刻闭嘴。

林晚没有。

她就站在那里等。

等了十几秒。

我妈还是一句话都没说出来。

年长的民警合上材料。

“这两张我们先拍照登记。原件在哪里、材料怎么取得，之后都要核实。”

他看向我爸。

“另外，你们现在有没有做过亲子鉴定？”

我爸点头。

“有。”

“结果？”

客厅又静了一次。

我爸说：

“她是我们的亲生女儿。”

林晚的手指突然攥紧了。

这是今晚第一次，有人把这句话完整说出来。

没有‘可能’。

没有‘应该’。

没有‘当年情况复杂’。

她就是。

民警又问了几句现在的认亲经过，登记了联系方式。

涉及十二年前医院记录和当年的具体情况，他们没有当场下结论，只让我们把能够找到的资料都保留好，之后配合核查。

我爸始终很配合。

甚至送他们到了门口。

门一关，他脸上的客气就没了。

“你满意了？”

他看着我。

我没有说话。

“让警察到家里来，当着这么多长辈的面，把家里的事情闹成这样。”

他指了指桌上的纸。

“你以为你是在帮谁？”

我正要开口，林晚忽然说：

“十二年前是哪一天？”

我爸停住。

她走到桌边，把那张复印件拿起来。

这一次，她看得很仔细。

委托日期不是她看的地方。

她看的是结项日期。

二〇一六年九月十七日。

她盯了很久。

然后抬头看向我妈。

“那天是星期六。”

我妈的脸一下白了。

林晚继续问：

“你们当年是不是开了一辆黑色的车？”

没有人回答。

她看着我爸，又看了看我妈。

声音很轻。

“我见过你们。”
