# 《微信运动能提现吗？我一天走两万步》1–40 章重写审计

日期：2026-08-30

## 目标

针对读者明确反馈的“全是 AI 对话”“正常人不会说得这么生硬”，对第 1–40 章执行正文级重写，而不是同义词替换或局部润色。

本轮只调整语言、对白组织、叙述节奏、人物反应和重复场景表达。既定剧情结果、人物关系、收益规则和关键数值不得因去 AI 味被擅自改写。

## 审计轮次

### 第一轮：逐章正文重写

第 1–40 章逐章读取、逐章改写。重点处理：

- 完美接球式问答：A 问、B 答、A 追问、B 回答、A 抖包袱。
- 采访式对白：角色为了让读者知道信息而互相提问。
- 所有人都过分简洁、机灵、会接梗，导致角色声线同质化。
- 周航长期只承担“你怎么又走路”的吐槽器功能。
- 唐梨、胡凯围着沈川的步数与收益不断重复震惊。
- 每段对话都追求最后一句包袱或总结。
- 叙述已经表现出的信息，又由对白或旁白解释一遍。
- 手机 UI / 地图 / 步数 / 收益按固定流程重复展示。
- 相邻章节出现相同“出发—看距离—走路—看收益—回家”的骨架。

### 第二轮：自动全书 Gate + 高风险人工复查

执行：

`python shared/tools/novel_gate.py novels/walk-to-earn/chapters/chapter-*.md`

包含：

- `dialogue_guard.py`
- `humanizer_guard.py`
- `prose_guard.py`
- `meta_narrative_guard.py`

自动 Gate 不是最终批准，只负责暴露高风险结构。对其结果再次人工判断。

第二轮发现并人工修复的高风险位置：

- 第 16 章：母子通话存在连续问题链，容易形成“采访主角”的节奏；已重新组织为家常电话，信息穿插在母亲的担心、沈川的动作与主动补充中。
- 第 30 章：删除生成式二元翻案句式，长距离疲劳改为直接身体感受。
- 第 33 章：500 公里升级附近短问短答过密；重新组织周航反应，不让升级节点变成参数采访。
- 第 39 章：父子见面原版对白密度过高、问题链明显；大幅改写为边走边看学校、旧记忆和家庭琐事自然穿插。

修复后，上述章节级 `QUESTION_CHAIN`、`SHORT_PINGPONG`、`INTERVIEW_BLOCK`、`DIALOGUE_DENSITY` 风险已消失。

### 第三轮：模型口头禅与跨章重复复查

在第二轮通过后继续检查低等级警告，而不是看到 CI 绿色就结束。

进一步处理：

- 第 9 章：`终于` 在单章内重复过多，已逐处判断并删除非必要重复。
- 第 19 章：`第一次` 在回望旧路线时重复过多，已改成具体时间/事件指代，避免机械回环。
- 跨章 `你呢 / 多远 / 多少钱 / 几点了` 等短问题逐个检查；它们分布于不同人物、不同场景且承担不同即时功能，不按关键词机械删除。
- `UNIFORM_SENTENCE_LENGTH` 对粗体 UI 数字、里程块有较多误报；人工确认数字块是世界机制信息，不将其为了躲检测而故意写乱。

## 人物声线复核

- 沈川：话少，通常先行动，不负责给作者总结主题；对钱敏感但逐渐不再每笔都换算成步数。
- 周航：保留朋友间的吐槽，但必须拥有自己的实习、游戏、搬家、体测和生活状态，不能只作为沈川走路的反应器。
- 唐梨：工作场景里关注任务和自己的求职压力，偶尔接梗，不再持续盘问沈川的步数、价格和动机。
- 胡凯：更多负责自己的校招、活动路线和朋友同行，不重复承担“震惊主角”的功能。
- 父母：说话允许重复、担心、绕话和生活琐事，不把家庭电话写成财务情况问卷。

## 机制与数字连续性复核

既定收益规则保持：

- 0–99 km：0.04 元 / 有效步
- 100–499 km：0.05 元 / 有效步
- 500–1499 km：0.08 元 / 有效步
- 1500 km 起：0.12 元 / 有效步

关键节点复核：

- 第 30 章：38642 步，1932.10 元，累计 436.4 km。
- 第 31 章结尾：累计 455.6 km。
- 第 32 章：20836 步，1041.80 元，累计 473.8 km。
- 第 33 章：累计跨过 500.1 km，基础收益切换为 0.08 元 / 步；下一档明确为 1500 km、0.12 元 / 步。
- 第 34 章：升级后的首个完整日，12742 步 × 0.08 = 1019.36 元。
- 第 38 章：累计 603.6 km，仍处于 0.08 元 / 步档位。
- 第 40 章：17683 步 × 0.08 = 1414.64 元；累计 628.4 km；下一档仍为 1500 km。

没有新增身体强化、隐藏属性、额外系统、恋爱线或其他未授权设定。

## 最终判定规则

本次重写只有同时满足以下条件才允许合入和发布：

1. 1–40 章全部在同一重写分支完成。
2. `novel_gate` 全书运行完成，所有 HARD 项为 0。
3. `meta_narrative_guard` 全书 hard=0 / warn=0。
4. 高风险对白警告经人工二次改写后消失。
5. 再做一轮低等级口头禅、跨章重复与角色功能复查。
6. 数值、收益档位、时间线和人物关系人工复核通过。
7. 合入 `main` 后，Fanqie Sync 的 validate、probe、publish 全部成功。
8. 发布队列与同步状态确认没有本轮待发布、失败或重试项后，才可宣布“全部完成”。
