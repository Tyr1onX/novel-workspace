# 《微信运动能提现吗？我一天走两万步》

> 内部项目代号：Walk to Earn
> 状态：**DRAFTING / MAINLINE LOCKED**
> 首发平台：番茄小说
> 类型：都市脑洞 / 生活神豪 / 成长

## 一句话卖点

暑期实习一天两百块，沈川走了五千步。

晚上，他手机里多了一笔同样大小的钱：

> **有效步数 5031，收益 201.24 元。**

从那天起，他走的每一步，都真的值钱。

## 核心幻想

能力只做一件事：

> **有效步行可以换成真钱。**

开局基础收益：

> **0.04 元 / 有效步。**

5000步约200元；20000步约800元。

前期不追加随机职业、特殊任务、花钱返现、抽奖、技能商城、救人倍率等第二套系统。

长期成长只沿同一条轴扩张：

> 走得更多 → 累计里程更高 → 单步价值阶段性提高 → 主角能用时间和脚力换到更大的生活自由度 → 行走半径扩大 → 人物、地点和选择随之扩大。

## 当前正文事实

原始设计曾计划在前20章末完成100公里，但正文因为展会连续高步数，已经在**第10章**自然跨过100公里，并将基础收益提升为：

> **0.05 元 / 有效步。**

这是已经发生的正文事实，不回滚、不为了迁就旧章节卡篡改里程。

因此第11章起已经进入第二阶段：

> **100km → 500km。**

第二阶段不能写成单纯追数字。核心问题是：当沈川每天通过正常生活就能稳定获得几百到上千元，他会怎样重新安排自己的时间、工作、城市活动和出行半径。

## 主角

**沈川，22岁。**

大四前暑假，在虚构城市**临岚市**一家办公用品电商公司做运营实习。

日薪200元，住合租房，没背巨额债务，也没有全家等他救命。

他的第一欲望很普通：

> **手里有点自己的钱，不用每次想买东西、租房、出去玩都先算半天。**

他不是苦大仇深型主角，也不靠被羞辱启动。

人物吸引力来自：

- 会算账，但不会为了几十块把自己折腾得像疯子；
- 得到能力后第一反应是自己验证，不急着告诉别人；
- 钱变多以后先改善真实生活，再逐渐扩大选择；
- 有年轻人的懒、嘴贫和临时起意，也有做决定后真的去做的一面；
- 走路会让他持续进入城市、旅行和陌生人的生活，不长期困在一个出租屋刷步数。

## 长篇发动机

这本书不靠“今天2万步、明天3万步”重复推进。

每个阶段都必须改变至少一项：

- 主角今天为什么要走；
- 和谁一起走；
- 从哪里走到哪里；
- 这段路途中发生什么；
- 钱到账以后改变了什么现实选择；
- 累计里程距离下一档还有多少；
- 主角对工作、消费、旅行、关系和时间价值的判断发生什么变化。

钱是前期最直观计分板，生活自由度才是长期收益。

## 主线优先级

正文优先级固定为：

1. **走路赚钱与累计里程成长；**
2. **走路带来的生活选择和地理半径变化；**
3. 人物关系、工作、校招、消费等现实支线。

工作、校招、恋爱、家庭都可以写，但不能反客为主。

如果一个支线连续两章占据主要篇幅，而删掉“走路能力”后剧情仍几乎原样成立，说明已经偏离本书主线，必须压缩或重写。

## 开稿硬规则

1. 前300字必须出现“5000步 / 200元”的现实玩笑或对照。
2. 第一章必须完成真实提现，不把能力确认拖到第二章。
3. 第一章结束前必须让读者自己算出“两万步≈八百”。
4. 前三章不出现大型创业、豪车、豪宅、女神倒贴或全场震惊。
5. 前10章至少出现三种不同的行走理由和场景，禁止连续夜刷步数。
6. 系统前台只保留必要数字：有效步数、当日收益、累计里程/下一档，不写大段面板。
7. 钱必须具体落到真实生活：饭、鞋、房租、交通、设备、旅行、时间选择。
8. 人物关系不能只负责夸主角；室友、同事、朋友各自有自己的日程、利益和判断。
9. 轻松感来自人物和生活本身，不塞网络梗合集。
10. **故事地点统一使用虚构地名，不直接使用现实存在的城市、街区、商圈、景点和徒步线路名称。**
11. 每章必须执行 `shared/RULES.md`、`shared/PROSE_RULES.md`、本项目 `style/STYLE_DNA.md` 与 `design/06-current-stage-mainline.md`。
12. 用户只说“下一章”时，也不得只看上一章续写；必须先复核当前阶段目标、最近至少3章的功能、累计成长轴和支线占比。
