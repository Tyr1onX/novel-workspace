## 一句话卖点

暑期实习一天两百块，沈川走了五千步。

晚上，他手机里多了一笔同样大小的钱：

> **有效步数 5031，收益 201.24 元。**

从那天起，他走的每一步，都真的值钱。

## 核心幻想

能力只做一件事：

> **有效步行可以换成真钱。**

开局基础收益：

> **0.04元 / 有效步。**

长期成长只沿同一条轴扩张：

> 走得更多 → 累计里程更高 → 单步价值阶段性提高 → 时间和生活选择变多 → 活动半径扩大 → 新的真实行走事件。

禁止追加随机职业、特殊任务、花钱返现、抽奖、技能商城、救人倍率等第二套系统。

## 主角

**沈川，22岁，大四阶段。**

能力出现时正在虚构城市临岚市做运营实习，日薪200元。暑假实习已结束并返校。

家境普通，没有巨额债务，也没有必须立刻救命的家庭压力。

核心欲望一直很普通：

> **手里多一点余量，时间和选择能由自己决定。**

人物吸引力来自：

- 会算钱，也会算时间；
- 有一点懒，但对感兴趣的事会执行；
- 得到能力后自己验证，不急着告诉别人；
- 钱增加后先改善真实生活，再扩大旅行和城市半径；
- 会主动恢复，赶课会骑车，下雨会坐车；
- 长距离能力来自真实累计行走、经验和装备，不来自系统强化。

## 长篇发动机

这本书不靠“今天2万步、明天3万步”重复推进。

每个阶段至少改变一项：

- 今天为什么走；
- 和谁走；
- 从哪里到哪里；
- 路上发生什么；
- 钱到账后改变什么现实选择；
- 累计里程如何推进；
- 主角怎样重新判断工作、消费、旅行、关系和时间价值。

钱是直观计分板，生活自由度和活动半径才是长期收益。

## 主线优先级

1. **走路赚钱与累计成长；**
2. **走路带来的生活选择和地理半径变化；**
3. 人物关系、工作、校招、消费等现实支线。

工作、校招、恋爱、家庭都能写，但不能反客为主。

如果一个支线连续两章占据主要篇幅，而删掉“走路能力”后剧情仍几乎原样成立，必须压缩或重写。

## 开稿与续写硬规则

1. 系统前台只保留必要数字：有效步数、当日收益、累计里程/下一档。
2. 钱必须具体落到饭、鞋、房租、交通、设备、旅行、家庭和时间选择。
3. 配角都有自己的日程，不全天围着沈川。
4. 轻松感来自人物和生活，不塞网络梗合集。
5. **故事地点统一虚构，不直接使用现实存在的城市、街区、商圈、景点和徒步线路名称。**
6. 每章必须执行 `shared/RULES.md`、`shared/STORY_ARCHITECTURE_RULES.md`、`shared/NARRATIVE_PASS_RULES.md`、`shared/DIALOGUE_RULES.md`、`shared/DIALOGUE_APPRENTICESHIP.md`、`shared/HUMANIZER_RULES.md`、`shared/PROSE_RULES.md`、`shared/META_NARRATIVE_RULES.md`、本项目 `style/STYLE_DNA.md` 与 `design/06-current-stage-mainline.md`。
7. 用户只说“下一章”时，不得只看上一章续写；必须复核当前阶段、最近至少3章功能、累计成长轴和支线占比，并完成 Architecture Lite。
8. 正文后至少给一个主要场景写 QUD；关键对白必须能回答“这个人为什么现在必须说这句话？”。
9. 情绪优先采用“行为 + 直接情绪词 + 少量身体反应 + 必要留白”；普通情绪不连续堆胸口/呼吸/手心/喉咙等症状。
10. 1500km是长期背景，不写成新的每日倒数任务。
11. 0.08元/步只涨钱，不自动强化身体。
12. 收到“对白怪 / 像AI / 像排练”反馈时，按 `DIALOGUE_APPRENTICESHIP.md` 直接REBUILD，不能只逐句美容。
13. 不为去 AI 强行倒叙、答非所问、制造矛盾或塞无关支线；每章只处理最突出的 3–5 个叙事/语言问题。
