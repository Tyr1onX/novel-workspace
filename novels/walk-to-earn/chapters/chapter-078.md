# 第七十八章 下过雨以后，旧鞋先打了一下滑

周一晚上八点，图书馆闭馆广播刚响第一遍。

沈川合上电脑。

外面下过一场小雨。

雨已经停了，台阶还湿。

他从图书馆出来，走正常路线回寝室。

下第一级台阶时，右脚突然往前滑了半掌。

幅度不大。

沈川马上扶住旁边栏杆。

后面的人也停了一下。

“没事吧？”

“没事。”

他站稳，低头看鞋。

台阶本身有防滑条。

鞋底却已经磨得很平。

这双鞋是第2章以后买的那一双。

从最早的通勤、展会、青篁山，到后来栖湾、泊川，真正走过的距离已经远远超过普通大学生日常穿一双鞋的强度。

沈川以前检查的是脚。

最近脚没怎么出问题，他反而忽略了鞋底。

回寝室两公里，他把速度放慢。

湿地砖上每次转弯都不急。

走到路灯亮的地方，沈川又抬脚看了看。

前掌外侧的纹路几乎磨平，后跟也明显偏磨。

不是鞋突然坏了。

它只是用到了该换的时候。

寝室里，周航正在整理纸箱。

公司让他下个月去做一次提前体检，他顺便把用不到的旧资料扔掉。

沈川一进门先把鞋脱下来翻底。

周航看见。

“开胶了？”

“没有，磨平了。”

“你才发现？”

“刚滑了一下。”

周航把纸箱放旁边。

“那你还穿？”

“明天换。”

沈川还有一双日常运动鞋。

不是同款，但鞋底新很多。

他没有当晚立刻打开购物软件买最贵的跑鞋。

先把旧鞋擦干。

第二天早上换另一双去上课。

新换上的鞋前掌硬一点。

走到教学楼时没问题。

中午去食堂，脚趾位置开始觉得紧。

沈川坐下以后把鞋带松了一格。

胡凯看见。

“鞋又不行？”

“旧的磨平了，换这双。”

“这双不是你以前穿的吗？”

“嗯。”

“能走长路？”

“正常上课够。”

胡凯点头，继续吃饭。

下午沈川没有安排长距离。

学校里一万步以内，脚感可以接受。

晚上，他才去附近商场看鞋。

不是为了“升级装备”。

只需要替换已经磨损的那一双。

同款还有。

价格比上次便宜了一些，活动后五百多。

店员问：“跑步还是走路？”

“走路多。”

“每天多少？”

“有时候多。”

沈川没有报两万、三万。

店员让他试两个尺码。

旧鞋穿久以后已经撑开，新鞋同尺码反而显得紧。

他两只都穿，绕店走了几圈。

最后还是买原尺码，但换了更薄一点的袜子重新试。

前掌没有顶。

结账。

五百多块。

如果是能力刚出现时，这笔钱会是一个很明确的爽点。

现在只是一笔必要支出。

他能轻松承担，也不需要把它写成“今天走多少步就赚回来”。

新鞋装盒。

旧鞋没有扔在商场。

沈川拎回寝室。

周航看他一手鞋盒一手旧鞋。

“旧的还留？”

“下雨天不穿，平时下楼可以。”

“你都滑了。”

“干地没事。”

周航懒得管。

新鞋前两天只走校园。

沈川没有穿着刚拆盒的鞋就去拉二十公里。

第三天，鞋面弯折开始顺一些。

脚后跟没有磨点。

第四天晚上一场小雨。

沈川从实验楼出来，走到和周一相似的湿台阶。

他踩下去。

鞋底抓地正常。

没有什么系统提示。

他也没在台阶上故意多试几次。

走过去就算了。

旧鞋放在寝室鞋架最下面。

它陪他从很早的一段路走到八百多公里。

现在只是纹路磨平了。

人可以继续走，鞋得先换。
