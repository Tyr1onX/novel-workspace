# 核心机制：步数收益

## 1. 唯一基础规则

沈川完成的**有效步行**会形成现金收益。

开局：

> **0.04元 / 有效步。**

结算显示只需要：

- 今日有效步数；
- 今日收益；
- 累计有效里程；
- 距离下一收益档位。

收益进入独立余额，可随时提现至本人银行卡/支付账户，到账合法可用，不额外制造税务、黑钱、来源追查主线。

## 2. 什么算有效步数

作者后台需要稳定，正文不必逐条解释。

有效步行的基本边界：

- 主角本人双脚完成的自然行走/徒步；
- 日常通勤、逛街、旅行、工作中的步行都算；
- 跑步可计步，但系统按真实步态/位移识别，不允许原地抖腿刷数；
- 摇手机、机械震动、绑在动物/车轮上不算；
- 原地踏步只有极低或不计收益，避免长期在出租屋刷；
- 正常室内来回会算，但重复机械绕圈过久会逐步判低效。

核心不是惩罚主角，而是把他推向真正的“出去走”。

## 3. 长期升级只走一条轴

不追加第二套奖励树。

累计有效里程达到阶段节点，**基础单步价值上调**。

初步档位：

| 累计有效里程 | 单步收益 |
|---|---:|
| 0–99 km | 0.04元 |
| 100–499 km | 0.05元 |
| 500–1499 km | 0.08元 |
| 1500–4999 km | 0.12元 |
| 5000 km以后 | 后续根据正文经济尺度再锁，不提前无限膨胀 |

这些档位是作者侧节奏工具，不要求每次升级都弹出庆典。

第一阶段只需要让读者知道：

> **走够100公里以后，每一步会更值钱。**

这样“今天赚多少”和“累计走了多远”形成两个计分板。

## 4. 为什么不直接给倍率任务

暂时禁止：

- 救人×20；
- 夜间×2；
- 新路线首走×5；
- 连续签到；
- 随机宝箱；
- 走到指定地点领取资产；
- 运动技能自动强化。

原因：这些东西会迅速把一本很干净的生活幻想写成任务大厅。

真正的变化来自现实：

- 下雨天还走不走；
- 今天坐地铁还是提前两站下；
- 周末是躺一天还是去西湖绕一圈；
- 朋友叫他去徒步，他以前嫌累，现在会认真算；
- 加班三小时只多几十块，他会开始重新评估自己的时间；
- 有钱以后是否还愿意为了收益硬走；
- 当钱已经够花，“走路”还能给他什么。

## 5. 身体限制必须存在

收益强，但人体仍是普通人体。

前期真实限制：

- 脚底磨泡；
- 小腿酸；
- 鞋不合适；
- 天气；
- 时间；
- 第二天还要上班；
- 一天三四万步并不轻松。

这些限制不能写成苦难折磨，而是让主角有决策空间。

他会逐渐学习：

> 好鞋、补水、路线、配速、休息、饮食，比一晚上发疯多刷五千步更重要。

主角成长的一部分就是从“今天还能不能多走两千步”变成“我怎么让走路自然进入我的生活”。

## 6. 金钱尺度

0.04元/步时：

- 5000步 = 200元；
- 10000步 = 400元；
- 20000步 = 800元；
- 30000步 = 1200元。

这个阶段已经足够改变一个22岁实习生的生活，但还不足以让他几章内豪车豪宅。

这正是需要的尺度。

前期钱的使用顺序优先：

> 吃得不用太抠 → 换双真正适合走路的鞋 → 房租/生活费有余量 → 买以前会犹豫很久的中等价位物品 → 有底气拒绝低价值加班 → 周末开始主动去更远的地方。

消费的爽点来自“以前需要权衡的东西，现在能直接决定”，而不是每次用价格压人。

## 7. 长篇问题

随着收益提高，故事真正要回答的是：

> **一个普通年轻人如果真的可以靠自己的脚稳定获得越来越高的收入，他会怎样重新安排工作、城市、旅行、朋友和人生？**

能力提供钱和行动理由，人物选择负责把它变成故事。
