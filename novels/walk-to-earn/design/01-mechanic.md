# 核心机制：步数收益

## 1. 唯一基础规则

沈川完成的**有效步行**会形成现金收益。

系统前台只需要显示：

- 今日有效步数；
- 今日收益；
- 累计有效里程；
- 当前基础单步收益；
- 必要时显示下一档。

收益进入独立余额，可随时提现至本人银行卡/支付账户，到账合法可用，不额外制造税务、黑钱、来源追查主线。

## 2. 什么算有效步数

作者后台保持稳定，正文不必逐条解释。

有效步行基本边界：

- 主角本人双脚完成的自然行走/徒步；
- 日常通勤、逛街、旅行、工作中的步行都算；
- 跑步可以计步，但按真实步态/位移识别；
- 摇手机、机械震动、绑在动物/车轮上不算；
- 原地踏步只有极低或不计收益；
- 正常室内来回会算，重复机械绕圈过久会逐步判低效。

机制的作用是把沈川推向真实生活和真实路线，不把他困在屋里刷数。

## 3. 长期升级只走一条轴

不追加第二套奖励树。

| 累计有效里程 | 单步收益 |
|---|---:|
| 0–99 km | 0.04元 |
| 100–499 km | 0.05元 |
| 500–1499 km | 0.08元 |
| 1500–4999 km | 0.12元 |
| 5000 km以后 | 后续根据正文经济尺度再锁，不提前无限膨胀 |

正文已经发生：

- 第10章：100km，**0.04 → 0.05元/步**；
- 第33章：500km，**0.05 → 0.08元/步**。

第33章最后一次明确累计为：

> **500.1km**

当前生效：

> **0.08元 / 有效步。**

当前下一档：

> **1500km → 0.12元 / 有效步。**

1500km只提供长期方向，不写成每天机械倒数。

## 4. 禁止追加倍率任务

继续禁止：

- 救人×20；
- 夜间×2；
- 新路线首走×5；
- 连续签到；
- 随机宝箱；
- 走到指定地点领取资产；
- 运动技能自动强化；
- 任何第二套任务/技能树。

真正的变化来自现实：天气、交通、身体、时间、朋友、目的地和钱如何改变选择。

## 5. 身体限制必须存在

收益提高，人体仍是普通人体。

已经建立并持续有效：

- 脚底磨泡/磨热点；
- 小腿和大腿酸；
- 一天三四万步后的恢复；
- 鞋、袜子、补水、负重；
- 天气；
- 课程和返程时间；
- 第二天还有事；
- 走到一定距离后脚底发热；
- 该骑车、坐公交、坐地铁时会坐。

主角成长来自经验：路线、配速、休息、补给和判断越来越成熟，不来自自动身体强化。

## 6. 金钱尺度

### 0.04元/步阶段

- 5000步 = 200元；
- 10000步 = 400元；
- 20000步 = 800元。

### 0.05元/步阶段

- 10000步 = 500元；
- 20000步 = 1000元。

### 当前0.08元/步阶段

- 5000步 = 400元；
- 10000步 = 800元；
- 12000步 = 960元；
- 15000步 = 1200元；
- 20000步 = 1600元。

这个阶段已经能显著改变普通大学生对兼职、实习工资、交通费、住宿费和旅行预算的判断，但仍不足以几章内进入豪车豪宅尺度。

## 7. 钱的叙事作用

前期顺序已经从“吃饭/鞋/房租/电脑”逐步走到了“时间和活动半径”。

500km以后，收益优先改变：

- 普通有课日的时间价值；
- 是否接低价值兼职和加班；
- 是否因为几百元交通/住宿放弃机会；
- 能否临时提前一晚或多留一天；
- 是否开始认真安排更远城市和更多日路线。

爽点来自“以前需要权衡的东西，现在能直接决定”，不来自旁人围观余额。

## 8. 长篇问题

随着收益提高，故事持续回答：

> **一个普通年轻人如果真的可以靠自己的脚稳定获得越来越高的收入，他会怎样重新安排工作、城市、旅行、朋友和人生？**

能力提供钱和行动理由，人物选择负责把它变成故事。
