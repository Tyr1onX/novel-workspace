# 番茄平台包装

## 首选书名

> **《今天走了两万步，到账八百》**

先不加“神豪”“系统”“开局”等前缀。

标题的任务只有一个：

> 让读者下意识算一下——两万步八百，那我一天能赚多少？

## 备选书名

只在真实发布数据或平台审核说明首选明显有问题时再考虑：

1. 《一天两万步，我真赚了八百》
2. 《走一步四分钱，我开始天天暴走》
3. 《实习日薪两百，我走路一天八百》

当前不轮换测试，不在正文里频繁改定位。

## 推荐简介

沈川暑期实习，日薪两百。

某天下班，同事看了眼手机：今天走了五千多步，这两百块工资，算下来差不多一步四分钱。

沈川随口接了一句：

“那我要是走两万步，不就八百？”

当天晚上，他的手机里真的多了一个页面。

> 今日有效步数：5031
> 今日收益：201.24元

他点了提现。

银行卡到账。

从那以后，坐两站公交还是自己走，周末在家躺着还是出去逛，要不要为六十块加班三小时，沈川都有了另一种算法。

而当累计里程达到100公里后——

一步，开始不止四分钱。

## 简介原则

不提前讲：

- 后续所有里程档位；
- 全国旅行；
- 未来财富规模；
- 商业投资；
- 女主关系；
- 可能出现的后期地图。

简介只卖三个东西：

> 普通实习生 → 走路真到账 → 走得越久单步越值钱。

## 分类/标签方向

发布时根据番茄后台实际可选项确认。

内容定位优先靠近：

> 都市脑洞 / 都市生活 / 神豪 / 轻松 / 日常 / 成长

“系统”标签是否使用以后台实际语义和推荐效果再定。正文确有机制界面，但不是任务商城型系统。

## 封面方向

不要做豪车、金钱雨、银行卡、夸张神豪西装。

优先一个非常容易理解的现代场景：

- 年轻男生夜里走在城市街道/江边；
- 一手拿手机；
- 手机上只突出“20,000步 / ¥800”两个信息；
- 背景有城市灯光和延伸的人行道；
- 人在走，不站桩摆POSE；
- 整体偏轻松、年轻、现实都市。

封面应该让人先理解“走路赚钱”，再感受到都市爽文。

## 发布前检查

1. 标题看一眼能不能懂？
2. 简介前100字有没有5000步/200元的现实来源？
3. 第一章是否真的兑现提现，而不是简介更爽？
4. 是否把一件简单的事讲复杂了？
5. 是否让读者产生“如果是我，我也走”的念头？
