# 当前阶段主线闸门

> 用途：防止连续续写时只跟着上一章自然展开，导致支线逐渐吞掉《微信运动能提现吗？我一天走两万步》的核心幻想。

## 1. 当前正文阶段

已经完成两次明确升级：

- 第10章：累计100km，**0.04 → 0.05元/步**；
- 第33章：累计500km，**0.05 → 0.08元/步**。

当前长期计分板：

> **1500km → 0.12元/步。**

第33章正文最后一次明确显示：

> **累计有效里程：500.1km**
>
> **基础收益：0.08元 / 有效步**

500.1km出现在周航搬回学校的第二趟推车途中。之后沈川仍继续搬完行李、推回小车和整理旧纸箱，但正文没有再次展示累计数字，后续不要自行补算精确章末里程。

## 2. 500—1500km阶段要写什么

这一阶段的核心问题：

> 当一个普通学生正常走10000步就能得到800元、20000步能得到1600元，他会怎样重新安排普通日子、工作选择、城市出行和更远旅行？

不能把1500km写成新的“每日任务条”。这个目标距离足够远，应重新退回长期背景。

### A. 先兑现0.08档的日常尺度

第34章优先安排一个本身成立的普通日，让读者直接看到：

- 10000步 = 800元；
- 12000步 = 960元；
- 15000步 = 1200元；
- 20000步 = 1600元。

只需一次清楚兑现，不连续几章做收入报表。

### B. 钱开始更明显地购买时间和半径

0.08档应逐步改变：

- 是否接低价值兼职或低价加班；
- 一两百元交通费、住宿费是否还会阻止短途出行；
- 能否临时多留一天、提前一晚出发；
- 是否开始认真考虑更远城市、更多日行程；
- 普通学生消费是否从“买得起”变成“时间更值钱”。

仍然保持学生生活尺度，禁止几章内豪车豪宅。

### C. 行走继续产生新事件

每个较长步行段至少发生一个现场变化：

- 同行节奏；
- 找东西；
- 赶时间；
- 临时交通变化；
- 路线调整；
- 天气；
- 身体状态；
- 行李/目的地带来的现实阻力。

不能回到纯计步直播。

### D. 活动半径继续扩大，但地图要有呼吸

已经完成：

- 城市通勤；
- 山路徒步；
- 跨城办事；
- 小城一日游；
- 过夜短途；
- 连续20km验证；
- 正式28km活动。

500km以后可以逐步进入更多日路线、国内更远城市和更自由的旅行，但不能因为刚升级就立刻“30km → 40km → 50km”连续挑战。

校园、朋友和普通生活仍要与旅行交替出现。

## 3. 身体限制继续有效

0.08元/步只提高钱，不提高身体。

已经建立的事实继续有效：

- 28km后第二天会腿酸、脚底发胀；
- 沈川会骑车、坐地铁、坐公交；
- 背包重、下雨、赶课、脚磨、睡眠和恢复都会改变是否继续走；
- 长距离经验来自累计步行、装备和路线判断，不是系统强化。

升级后禁止突然写成运动员体质。

## 4. 人物线使用规则

### 周航

第33章实习正式结束，已经搬回学校。近期可以重新进入校园朋友生活，但搬家/退租事件已经闭环。

### 胡凯

仍在学校，可参与普通课程、朋友活动和中短路线。

### 唐梨

第32章刚重新出场并完成一次临岚同行。短期不要连续两章扩写她的校招或感情线。

### 陈姐

原实习带教，实习线已经结束，不频繁回收。

所有人物支线都必须依附“正在发生的真实生活与行走事件”。

## 5. 支线限额

允许工作、校招、家庭、消费、朋友和感情自然进入，但：

1. 同一现实支线连续两章成为最大篇幅时，下一章前必须重新审计；
2. 删掉“走路赚钱”后剧情仍能几乎原样成立，说明支线过重；
3. 校招不写成连续笔试/面试/谈薪；
4. 消费不写成购物清单；
5. 人物关系不能脱离行走主线独立长成另一部小说。

- 是否仍属于“走路赚钱 → 钱与体力改变现实选择 → 半径扩大 → 新行走事件”？
- 是否重复上一章功能？
- 是否把1500km写成机械冲刺？
- 是否有一个可复述的现实变化？
