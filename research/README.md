## 当前最重要的模型变化

### 1. “计分板”仍重要，但能力可以比当前目标大很多

《科技：为了上大学，上交可控核聚变》的第一现实目标不是“改变国家科技”，而是**300分如何获得龙科大的入场资格**。核聚变在第一阶段首先是一个能被机构验证的稀缺证明筹码。

因此新增候选：`scoreboard_reversal`、`power_to_goal_ratio`、`institutional_validation_ladder`。

### 2. 预先解决一个约束并非原罪

《黑科技：从一年造出光刻机开始》开局直接有500万启动资金，但市场、产品选择、量产、用户信任、人才、渠道等约束仍然存在。

所以比`constraint_preclearance`更准确的研究方式是看整个`constraint_portfolio`：到底还有多少真实摩擦继续活着。

### 3. 目前最接近SEED的强结构是“真实反馈本身成为成长燃料”

《重生1999：开启黑科技时代》里，主角解决现实问题、真正影响别人后获得影响力点；影响力再解锁更高技术，回到下一轮现实问题。

它形成：

> **现实问题 → 外部真实结果 → 成长资源 → 能力升级 → 更难现实问题。**

这比“系统升级后随机解锁新技能”更接近SEED应该验证的长线闭环。候选变量：`feedback_fuel_alignment`、`technology_context_fit`。

### 4. AI快速赚钱仍可能失败，主角的价值占比不能被AI吃空

《8号手机维修店》有明确经济困境、真实客户、收费和结果验证，但AI逐渐变成全能上游承包商：主角负责接单，AI负责几乎所有高价值解决。

因此新增`agency_share / protagonist_value_capture`：读者需要看见主角自己的判断、选择、承担和执行，而不只是“把问题转交给AI”。

### 5. 结构做对仍然不保证市场大成

《重生：我把魔法冠冕改成人工智能》前20章已经拥有三天房租期限、70→2800、能力成本、现场验货、硬件风险、现金流和产品化，几乎命中了当前结构模型的大多数正变量，但当前仍只是中低量级观察样本。

因此必须继续研究题材包装、核心承诺辨识度、人物吸引力、平台点击预期和推荐窗口，不能把结构模型当成万能解释。

### 6. 主角不必每章持续行动，已有成果的“验证/反应阶段”也可能承载爽点

《开局上交核聚变，能给份工作吗？》第一章之前主角已实际研发两个月、投入积蓄和借款；之后近20章本人昏迷，剧情主要由应急响应、机构逐级验证、家庭/地方反应承载。

这说明`agency_share`不能机械按“每章主角做多少事”评分。还要区分：

- `creation_agency`：成果最初是否是主角挣出来的；
- `reaction_phase`：成果完成后允许多长的现实验证/世界反应；
- `reaction_novelty_decay`：反应是否持续增加新信息，还是只重复震惊。

### 7. “核聚变开局 / 国家震惊 / 技术切得快”都不是自动失败条件

目前已经同时找到这类弱、中、强样本。后续不能再把表面标签当因果，必须继续比较验证阶梯、阶段目标、约束组合、主角选择、场景兑现密度和长线引擎。

## 对SEED当前最值得验证的闭环

如果最终保留“从真实反馈中学习/进化”，目前最值得测试的不是AI等级表，而是：

> **具体现实任务 → 主角做判断/选择 → 产生真实数据和外部反馈 → SEED从反馈学习 → 主角使用新能力回到同一现实任务 → 外界验证结果 → 新反馈成为下一轮燃料。**

必须同时保留：

- 主角明显的agency；
- 能力边界；
- 证明、部署、交易和组织成本；
- 技术对现实材料/工艺/市场的适配；
- 阶段结算；
- 重大成果的完整场景。
