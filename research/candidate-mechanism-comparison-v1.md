> 日期：2026-08-24

## 一、方法

本轮不再给每个候选一个“87/100”总分。原因是：

1. Click、Retention、Scale不是同一层；
2. 目前没有真实CTR/曝光数据；
3. 候选尚未有最终书名、简介、第一章，所以Click只能评“可压缩潜力”；
4. 权重稍改就可能改变总排名，提前做单一总分会制造伪精确。

统一比较：

- Click：`surface_causal_compression / surface_explanation_load / claim_grounding / surface_story_alignment`
- Activation：`human_stake_confirmation / first_real_world_proof / agency_signal`
- Retention：`progress_architecture / causal_ownership / friction_survival`
- SEED专属：`feedback_loop_fit`
- Scale：`long_tail_engine` + 当前证据置信度

0～3表示结构潜力；风险用R0～R3。它们不是市场成绩预测。

# 二、候选A：现代强现实困境 + SEED

## 核心外壳

主角先面对一个普通人立刻能理解、并且有期限/损失的现实问题；SEED第一次出现只帮助解决这个小问题的一部分，真实失败与反馈再推动它学习。

这里的“现实困境”不能直接照搬《首富从AI浪潮开始》的“裁员+补偿Bug”，否则会变成跟随样本。可以是工作交付、赔偿、事故责任、小生意危机、租金/债务、项目失败等，但第一利益必须具体。

## 结构潜力

| 层 | 判断 |
|---|---|
| Click C1 因果压缩 | **3**：最容易做到“问题→SEED第一次改善→现实利益” |
| Click C2 解释负担 | **R0～R1**：只要入口不先解释机器学习 |
| Click C3 事件落地 | **3** |
| Click C4 表层/正文对齐 | **3**，前20章可始终围绕同一问题升级 |
| Activation A1 | **3** |
| Activation A2 | **3** |
| Activation A3 | **3**，必须让主角先选择/部署/承担 |
| Retention R1 | **3** |
| Retention R2 | **3**，前提是SEED只提供增量能力，不承包全部价值 |
| Retention R3 | **3**，现实证明、客户/组织、钱、时间仍可存活 |
| feedback_loop_fit | **3** |
| long_tail_engine | **3** |
| 证据置信 | **高（结构）/中（最终Click）** |

## 当前最强支持

- 《首富从AI浪潮开始》证明：强能力不必消灭现实证明成本；第一利益可以极普通、极具体。
- 《重生1999》与《我靠打爆学霸》证明：现实反馈直接成为成长燃料时，能力线与剧情线可以天然咬合。
- 《AI客服》证明：真实反馈→纠正→再上线的SEED式闭环在现实商业问题中完全可执行。

## 最大风险

不是Retention，而是**表层同质化**：如果写成“程序员被裁后获得成长AI”，会同时撞上《首富AI》以及市场上已有“程序员+自制/进化AI”邻近设定。

因此A如果入围，下一步不是继续设计AI能力，而是寻找一个**不靠AI术语、也不复制裁员Bug的第一现实事件**。

# 三、候选B：现代小生意/创业 + SEED

## 核心外壳

从一个能直接接触真实客户反馈的小生意或产品开始。客户问题、退单、差评、人工纠正、复购、成本和转化率天然成为SEED训练数据与计分板。

## 结构潜力

| 层 | 判断 |
|---|---|
| Click C1 | **2**：如果只写“AI创业”会很泛；必须先有人物危机/第一客户 |
| Click C2 | **R2**：容易变成客服、SaaS、模型、ROI等行业方案说明 |
| Click C3 | **2～3** |
| Click C4 | **3** |
| Activation A1 | **2**，需主动补个人损失/期限 |
| Activation A2 | **3** |
| Activation A3 | **3** |
| Retention R1 | **3** |
| Retention R2 | **3** |
| Retention R3 | **3** |
| feedback_loop_fit | **3** |
| long_tail_engine | **3** |
| 证据置信 | **高（Retention）/中低（Click）** |

## 当前最强支持与反例

《AI客服》几乎是Retention正模板，但当前量级低，正说明“业务闭环漂亮”不能自动解决点击层。

《8号手机维修店》则从另一方向警告：真实客户+AI+快速赚钱仍可能弱，如果AI逐渐变成全能上游承包商，主角只剩接单转手。

## 最大风险

> **太像产品经理/创业案例，而不像小说幻想。**

B只有在第一客户/第一危机本身足够有戏时，才可能胜过A。否则A其实是更强的上位框架。

# 四、候选C：年代/重生现实产业 + SEED

## 核心外壳

回到技术、供应链和信息基础设施较弱的年代。SEED本身也受到当时网络、硬件、数据、资金、工艺限制，只能从现实问题中一点点学习和适配。

## 结构潜力

| 层 | 判断 |
|---|---|
| Click C1 | **2～3**：年代危机可以很具体，但“重生+AI”会增加一层机制 |
| Click C2 | **R2** |
| Click C3 | **3** |
| Click C4 | **3** |
| Activation A1 | **3**，家庭/工厂/生存问题天然可压实 |
| Activation A2 | **2～3** |
| Activation A3 | **3** |
| Retention R1 | **3** |
| Retention R2 | **2～3** |
| Retention R3 | **3**：年代条件天然保留工艺/渠道/网络/现金摩擦 |
| feedback_loop_fit | **2～3** |
| long_tail_engine | **3** |
| 证据置信 | **高** |

## 当前最强支持

- 《带着手机重生，目标科技教父》：未来AI受2008网络、现金、渠道、家庭信任约束，第一单可以到第25章，只要中间proof不断。
- 《重生1999》：未来知识必须适配1999工艺；现实影响还能反哺成长资源。

## 关键反例

《重生九零年代，人工智能带我飞》说明年代并不会自动变强。如果同时再塞：前世院士、空间、时间加速、量子计算机、灵泉、超级AI，SEED会失去第一现实兑现的因果所有权。

## 最大风险

> **重生本身已经是一套巨大外挂。**

如果主角还拥有精确未来商业/技术记忆，读者会问到底是重生知识赢了，还是SEED从反馈学习赢了。

所以C若入围，必须限制“未来记忆”的可直接变现程度；否则不如直接承认这是年代重生科技文，而不是SEED文。

# 五、候选D：全民都有AI，只有我的会从真实反馈进化

## 核心外壳

AI已经成为社会基础设施。别人使用的是固定/通用AI，主角的AI却会从现实失败、用户反应、对手行为中持续改变。

## 结构潜力

| 层 | 判断 |
|---|---|
| Click C1 | **3（有条件）**：对比句很强，但必须马上接具体利益，不能只写“我的会进化” |
| Click C2 | **R2**：需要解释社会AI规则与“为什么只有我的不同” |
| Click C3 | **3** |
| Click C4 | **3** |
| Activation A1 | **2**，世界观本身不能代替人物困境 |
| Activation A2 | **3** |
| Activation A3 | **2**，容易变成AI之间自动竞争 |
| Retention R1 | **3** |
| Retention R2 | **2** |
| Retention R3 | **2**：全社会都接受AI后，很多证明门槛可能天然下降 |
| feedback_loop_fit | **3** |
| long_tail_engine | **3** |
| 证据置信 | **低～中** |

## 市场邻近风险

当前公开样本已经能看到：

- “程序员自己写AI，AI逐步成为全能系统”；
- “人人都有AI管家”；
- “主角转生成AI，通过回答/任务进化”；
- “全国进入AI普及浪潮”的多个邻近设定。

因此“AI会进化”或“全民AI”本身已经不足以成为差异化。

真正可能有辨识度的是：

> **只有主角这一个AI的成长数据必须来自真实世界已经发生的失败/反馈，而且每次改变都能立刻回到同一现实问题复测。**

但这个差异如果无法在第一具体事件里演出来，就只是一句机制说明。

## 最大风险

- 世界观解释税；
- “只有我的特殊”容易游戏化/系统化；
- AI社会降低现实证明成本；
- 主角agency可能被AI竞争吞掉。

D暂不应进入第一名，只适合作为高概念候选继续定向补样本。

| feedback_loop_fit | **3** |

# 七、候选F：非SEED控制——现实验证/影响力驱动的科技树

## 为什么必须加入

如果研究只比较五种SEED外壳，无论最后谁赢，结论都默认了“SEED机制值得保留”。这会产生明显沉没成本偏差。

因此加入一个不需要AI学习设定的控制：

> **主角完成现实中真正被验证、真正改变他人的事情 → 获得影响/验证资源 → 解锁下一层科技/能力 → 返回现实解决更大问题。**

它可以是科技树、研究权限、资源池或单一异常规则，但不强调“AI自己在线学习”。

## 结构潜力

| 层 | 判断 |
|---|---|
| Click C1 | **3**，如果第一规则能压成具体事件 |
| Click C2 | **R0～R1** |
| Click C3 | **3** |
| Click C4 | **3** |
| Activation A1 | **3** |
| Activation A2 | **3** |
| Activation A3 | **3** |
| Retention R1 | **3** |
| Retention R2 | **3** |
| Retention R3 | **3** |
| feedback_loop_fit | **N/A**（但可有“现实验证→资源”闭环） |
| long_tail_engine | **3** |
| 证据置信 | **高** |

## 当前最强支持

《重生1999》已经证明“现实影响→系统资源→科技树→下一现实问题”可以支撑超长线；《打爆学霸》则从校园竞争证明“现实反应本身生产系统燃料”具有很强咬合度。

## 最大风险

它很容易退化成传统“影响力点/声望点/科技树系统”，失去SEED原本较现代、较独特的反馈学习质感。

但正因为F很强，它是一个必须认真面对的控制问题：

> **如果不用SEED也能得到几乎全部结构优势，那我们为什么一定要保留SEED？**

后续立项必须回答这个问题，而不能把“AI”当作既定前提。

# 八、V1分层结论

## 第一梯队：A 与 F

### A 现代强现实困境 + SEED

当前最均衡：Click容易压短、Retention与SEED反馈机制高度匹配、现实摩擦也容易保留。

但必须避开“裁员程序员+AI”的明显同质化表层。

### F 非SEED现实验证驱动科技树

是目前最强的沉没成本控制。它几乎拥有A的Retention优势，同时表层解释税更低。

它的存在意味着：**SEED必须证明自己的“真实反馈学习”能创造传统科技树做不到的剧情体验，否则应当放弃SEED。**

## 第二梯队：C 与 B

### C 年代 + SEED

现实约束与长线非常强，但重生/未来知识会和SEED争夺因果所有权。

### B 创业 + SEED

Retention几乎天然适配，但Click解释税是目前已有反例最明确的风险。

## 第三梯队：D 与 E

### D 全民AI + 独特进化

概念有对比性，但邻近市场已有多种“AI进化/全民AI”表达，且直接成功参照不足。需要定向补样本后再决定是否升档。

### E 原版大学生 + SEED

结构干净，但本身不是强Click外壳。只要补强现实危机，就会自然合并进A/B，因此不值得作为独立第一候选。

# 九、下一步只补前三类问题，不再无止境扩库

1. **A：**寻找“现代强现实困境 + 非裁员Bug + 技术/异常能力”的强弱对照，确认什么入口既具体又不跟《首富AI》同质化；
2. **F：**继续找“现实验证/影响→成长资源”但不是AI的强弱样本，确认优势是不是《重生1999》单一本书偶然；
3. **C/B择一进入第三名：**重点比较年代约束带来的长线优势，是否能抵消重生概念负担；以及创业型SEED的Click税是否可以被具体人物冲突修复；
4. D只做少量邻近题材核验，不优先扩样本；
5. 完成前三名定向补样本后，才做最终机制选择和平台落点。
