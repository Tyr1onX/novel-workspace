# 四、纵横站内强弱配对：等待多久不是关键，解锁后“打在哪”更关键

本轮先把两本结构高度相似、表现差距明显的纵横科技文做第一轮统一对照：

- 弱：《科技：复读四年，开局上交量子计算机》——59章/约13万字/441总点击；
- 强：《科技：打造巅峰华夏，从横推鹰酱开始》——约109.5万字/约16万级总点击/837推荐。

## 共同点：两本都让系统在“长期等待”后才真正启动

弱样本：主角为了系统任务连续复读四年，并长期故意维持低考试排名；第一章结束才正式获得至高科技系统、科技点和“唯一至高科研天赋”。

强样本：主角已经在611所实习两年半，第一章末才完成签到任务并开启科技之神系统/科技空间。

所以一个重要反修正是：

> **“系统不是第一天就来”“前置努力发生在过去”本身，并不能解释强弱。**

两本都采用了这种结构，但长期表现完全不同。

## 真正明显的差别1：解锁后的第一应用靶心

弱样本前20章目录很快跨越：

> 科研天赋 → 类人量子脑/AI → SCI → 中科院 → 国安/军方 → 军工蓝图 → 海陆空将军抢人。

核心能力更像“我拥有顶级全科研能力”，然后连续证明“我什么都会”。

强样本第一章给出的现实对象非常具体：

> **1997年611所正在改进的歼击7。**

系统第一次行动也不是给“全科技树”，而是：

> **解析眼前这架已经落后的歼击7。**

前20章目录几乎没有离开这个工程对象：

> 解析 → 矢量喷口 → 国产发动机 → 极限改进 → 机密会议 → 魔改完成 → RCS测试 → 气动布局 → 火控/感知。

直到21章以后才完成“世界最快最强战斗机”的阶段结算，29章才明确切到核潜艇。

这非常强地支持此前的 `application_target_coherence` 与 `stage_gate_closure`：

> **能力可以非常强，但前一阶段先把同一个现实对象拆成连续子问题，读者就能把每次技术升级理解为同一条进度，而不是功能演示巡回。**

## 真正明显的差别2：全能天赋 vs 对象分解

弱样本的第一块巨大收益是“唯一至高科研天赋”，它天然把未来所有技术赛道都提前纳入能力范围。

这会带来新的风险：

- 第一章就把“会不会科研”这一核心不确定性几乎清空；
- 后续每换一种技术，更像换一个展示模块；
- 权威认可从SCI、中科院、军方到多军种在很短窗口内连续叠加。

强样本也有很强外挂，但读者可见的使用方式是“对具体旧装备解析/改造”。能力上限很大，**读者一次只需要理解当前对象的一小段升级链**。

因此当前需要新增一个统一编码候选：

### `target_decomposition_depth`

> 一个阶段内，核心现实目标被拆成多少个连续、相互依赖、可观察的子问题后才完成结算。

它与`application_target_coherence`不同：后者问“能力是否都打在同一靶心”，前者进一步问“这个靶心内部有没有真正可追踪的分解过程”。

## 真正明显的差别3：过去努力是否能替代当前proof

弱样本把“四年复读+系统考核”作为巨大科研天赋的来源，逻辑上并非完全白送；但这些成本在第一章主要通过回顾一次性告诉读者。

这说明`earnedness`还需区分：

### `retrospective_effort_credit`

> 奖励是否主要靠故事开始前/第一章回顾中的努力来证明，而不是让读者在当前现实问题中看到“尝试→失败/成本→解决→结果”。

它不是天然负面：强样本同样有两年半实习/签到前史。

关键仍然是：**系统解锁后，当前剧情有没有立即进入新的、可见的proof链。**

强样本有“眼前歼击7→解析→逐项改造→测试”；弱样本更快进入“全科研天赋→多领域权威确认”。

因此不能简单打分“前史努力越多越好”，而应把它与当前proof分开编码。

# 五、对SEED的直接更新

本轮没有推翻“真实反馈学习”方向，反而进一步明确了它必须如何呈现：

> **SEED即使潜在能力无限，读者可见层也应一次只围绕一个现实对象/任务，把失败拆成连续子问题；每解决一格都回到同一对象复测，直到阶段结算后才换下一个应用靶。**

这比“系统一次只允许一个技能”更准确。

SEED应避免：

- 解锁后直接获得泛化“全能AI/全科研天赋”；
- 用过去的训练/等待一次性替代当前现实proof；
- 前20章把AI、黑客、金融、科研、商业分别演示一遍；
- 还没完成第一应用靶就不断叠加更高权威和新赛道。

新增候选字段：

- `target_decomposition_depth`
- `retrospective_effort_credit`

这两个先进入统一编码，不立即升为最终100分模型核心项。
