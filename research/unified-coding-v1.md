## 一、编码原则

### 1. 暂时不做总分

当前样本只有24本深读、8本极深读，而且部分字段高度相关。此时把所有变量直接加成100分会制造伪精确。

V1只做三件事：

1. 用8本极深读建立0～3量表锚点；
2. 看哪些变量在强/弱之间真的有初步区分力；
3. 找出不应作为“通用成功分”的条件变量。

### 2. 正向字段

统一：

- `0` = 很弱/几乎不存在；
- `1` = 偏弱；
- `2` = 中等；
- `3` = 很强。

### 3. 风险字段

为避免“3到底是好还是坏”混乱，风险字段单独加`R`：

- `R0` = 风险很低；
- `R1` = 轻；
- `R2` = 明显；
- `R3` = 很高。

### 4. 缺证据不猜

`?`表示当前极深报告没有足够证据，不为了填满表格猜分。

# 二、V1核心字段

## Activation

- `HSP` = `human_stake_preload`：能力出现前/同时是否有清楚的人类利益；
- `PSA` = `promise_surface_alignment`：标题/简介卖点是否很快进入正文现实因果；
- `CAC` = `causal_attribution_clarity`：核心胜利到底由谁/什么造成是否清楚；
- `PBS` = proof-burden survival：能力知道答案后，现实证明、部署、交易、验证是否仍存活；
- `AGS` = `agency_share`：主角在判断、选择、承担、执行中的价值占比。

## Retention

- `ATC` = `application_target_coherence`：多种能力是否先服务同一个现实靶；
- `TDD` = `target_decomposition_depth`：同一靶心是否拆成连续、相互依赖、可复测的子问题；
- `CPL` = `cumulative_progress_legibility`：连续胜利是否明显累加在同一条人生/项目进度线上；
- `IPD` = `intermediate_proof_density`：最终大兑现前，中间现实proof是否不断；
- `PH` = `progression_headroom`：第一次大胜后，同方向还剩多少可理解的成长空间；
- `RLR` = `resource_loop_visibility`：现实反馈→成长资源→能力→现实复测是否清楚可见；
- `SGC` = `stage_gate_closure`：一个阶段是否真的完成“目标→验证→结算”再换靶；
- `CS` = constraint survival：外挂出现后，钱/时间/市场/信任/组织/证明等约束组合是否仍能产生戏。

## 风险

- `MDR` = `module_demo_trap` risk：是否退化成逐项展示功能；
- `SSR` = `scoreboard_saturation_speed` risk：第一块计分板是否过快接近天花板。

## Scale

- `LTE` = `long_tail_engine`：当前真实长篇是否证明底层引擎可扩展。

`RLR`是**条件变量**：只有外挂设计本身依赖反馈燃料时才应该高权重。普通强作品不具备反馈燃料，不因此扣分。

### 关于几个刻意的分数

#### 《超级全能学生》HSP/PSA/CAC仍然给高分

这是故意保留反例，而不是为了让弱样本“看起来弱”而压分。

它：

- 有父亲跑出租攒学费、吊车尾想考大学的人类利益；
- 书名本来就承诺“全能”，正文也确实展示全能；
- 胜利来自超脑芯片，因果并不模糊；
- 前20章的即时兑现密度并不低。

它弱的地方主要落在另一组变量：

> `ATC 1 / TDD 1 / CPL 1 / PH 1 / SGC 1 / MDR R3 / SSR R3`

这说明研究模型已经不能再把“现实目标+快兑现+承诺一致”当作足够解释。

#### 《重生九零年代，人工智能带我飞》HSP仍然给3

它有非常清楚的父母悲剧和家庭改善目标。弱表现不能倒推出“没有human stake”。

真正问题更接近：AI、空间、前世院士、量子计算机、灵泉等同时争夺因果，空间养殖还抢走了最早的现金兑现，因此`CAC/ATC/CS/PH`都明显下降。

#### `RLR`不拿来惩罚普通强样本

《台式机》《首富AI浪潮》《带手机》并没有“反馈就是系统货币”的机制，所以标记`N/A`而不是0。

只有《重生1999》和《打爆学霸》能把它作为结构优势直接编码。

这避免把“SEED最喜欢的机制”偷偷变成所有成功作品都必须有的条件。

# 四、第一轮区分力检查

样本很小，下面只叫“初步区分”，不叫因果结论。

## A. 当前看起来区分力较弱的通用变量

### 1. `human_stake_preload`

8本极深读几乎全部能给出明确人类利益；两本弱样本也不缺。

结论：

> HSP更像**必要的开篇卫生项/下限项**，不适合单独承担高权重成功预测。

### 2. `promise_surface_alignment`

《超级全能学生》明确卖“全能”，正文也真的全能，但仍弱。

结论：

> 承诺一致能防止“点进来发现不是这本书”，但不能解释读者为什么长期追。

### 3. `intermediate_proof_density`

《超级全能学生》并不缺快速proof。

结论：

> proof数量本身不够，还要看proof是否**累加在同一条进度线上**。

因此`IPD`和`CPL/ATC/SGC`必须一起看。

# 五、当前更有区分力的候选簇

## 1. “进展拓扑簇”

当前最明显：

- `ATC application_target_coherence`
- `TDD target_decomposition_depth`
- `CPL cumulative_progress_legibility`
- `PH progression_headroom`
- `SGC stage_gate_closure`
- `MDR module_demo_risk`
- `SSR scoreboard_saturation_risk`

两本弱极深样本在这一簇中都出现明显问题，而强样本整体稳定。

这意味着未来可能不需要保留七个独立高权重变量，而是压缩成2～3个潜变量，例如：

### `progress_focus`

是否围绕同一现实靶心持续推进，而不是横向演示模块。

可能吸收：`ATC + TDD + MDR`。

### `progress_legibility`

胜利是否累加，阶段是否能清楚结算。

可能吸收：`CPL + SGC`。

### `progress_headroom`

第一块计分板是否既不断给proof，又不会过早打满。

可能吸收：`PH + SSR`。

暂时**不合并**，等24本编码后看它们是否真的高度共线。

## 2. “因果所有权/现实摩擦簇”

- `CAC causal_attribution_clarity`
- `AGS agency_share`
- `PBS proof-burden survival`
- `CS constraint survival`

《重生九零年代AI》尤其暴露出：human stake可以很强，但如果空间、前世知识、量子机、AI共同抢因果，核心卖点的因果所有权会变得模糊。

《首富AI浪潮》《重生1999》则说明：外挂很强不等于摩擦必须死亡，现实证明和组织执行可以继续成为剧情。

这组后续也可能压缩成：

### `causal_ownership`

核心卖点是否拥有核心成果的主要因果所有权，同时主角仍有明显价值占比。

### `friction_survival`

外挂出现后，现实验证/资源/组织/市场约束是否继续存活。

# 六、纵横新配对对V1量表的补充

虽然《科技：复读四年，开局上交量子计算机》和《科技：打造巅峰华夏，从横推鹰酱开始》不在24本深读权威名单里，本轮已完成原生元数据与前段结构配对，因此可用于**量表校准但不加入24本统计**。

共同点：两本系统都在长期等待/前置努力后才解锁。

差别：

- 弱样本：全科研天赋 → AI/SCI/科学院/军方/多军种快速扩散；
- 强样本：歼击7 → 发动机 → 矢量喷口 → 隐身 → 气动 → 火控 → 阶段完成后才切核潜艇。

这进一步支持`TDD`不是《台式机》单一本书推出来的偶然变量。

同时说明`retrospective_effort_credit`目前更适合作为**诊断字段**，不是直接正负分：两本都有过去努力，真正区分仍发生在系统解锁后的当前proof链。

# 七、Click layer暂不强行填满

当前8本极深报告对activation/retention证据最完整，但并非每本都完整记录了：

- 当时平台封面；
- 书名A/B历史；
- 原生简介完整版本；
- 推荐入口；
- 同期题材拥挤度。

因此V1没有为了表格完整而猜`surface_conflict_compression / fantasy_specificity / premise_explanation_tax / premise_concept_load`。

已知锚点：

- 《首富从AI浪潮开始》：表层冲突压缩强，“被裁→发现补偿Bug→多拿4.7万”无需技术背景即可理解；
- 《重生2005，AI客服称霸电商》：正文反馈闭环漂亮，但表层更像行业方案，需要读者先理解2005客服/知识库/ROI；
- 《魔法冠冕改AI》：正文第一阶段集中，但书名简介概念负载明显高。

Click layer将在24本第二遍编码时单独补，不与Retention先混成总分。

# 八、V1后的模型变化

当前不再假设：

> “强人类利益 + 前三章兑现 + 多次见证 = 大概率成功。”

更接近当前证据的结构是：

> **入口能理解 → 第一现实目标成立 → 核心能力拥有成果因果权 → 多个子能力围绕同一现实靶 → 连续proof累加在同一进度线上 → 第一阶段不提前打满 → 现实证明/约束继续存活 → 阶段结算后再打开更大靶。**

如果机制本身是反馈成长型，再额外要求：

> **现实反馈既是剧情结果，又成为下一轮成长燃料，而且循环对读者清楚可见。**

这比把所有书强行要求“必须feedback fuel”更不容易过拟合SEED。
