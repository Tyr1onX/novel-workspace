# Shared

这里存放所有小说项目共同复用的方法，不存任何单本小说的正文或专属设定。

## 当前内容

- `RULES.md`：从现有市场深读、强弱对照和结构编码中压缩出的通用创作规则。
- `PROSE_RULES.md`：所有小说正文共享的语言与叙述姿势硬闸门；写前读取，初稿后扫描并人工复核。
- `tools/prose_guard.py`：正文高风险模式定位工具，只报警，不自动改稿。
- `research/`：完整研究证据、样本账本、Click / Activation / Retention / Scale 模型、平台分层、反过拟合记录，以及 prose 规则的外部证据整理。

## 正文默认工作流

任何 `novels/*/` 下的新正文默认执行：

1. 读取当前小说自己的 README / design / style / continuity；
2. 读取 `RULES.md`；
3. 读取 `PROSE_RULES.md`；
4. 写第一稿，优先人物目标、动作、冲突和结果，不边写边机械躲关键词；
5. 运行 `python shared/tools/prose_guard.py <chapter.md>`；
6. 人工检查翻案腔、同构对举、动作后补解释、段尾升华、抽象情绪和生成式口头禅；
7. 通过后才把这一章当作后续续写基准。

扫描结果不能替代人工判断，也禁止为了降低命中数机械碎句、批量换同义词或清除作品本来成立的文学表达。

## 升级规则

只有满足以下任一条件，结论才允许进入 shared：

1. 有多个独立强样本与反例支持；
2. 在不同平台或不同题材中重复出现；
3. 在我们自己的多个小说项目中反复验证；
4. 能解释旧规则解释不了的反例，并且不会只是为单本书量身定制。

单本小说的局部技巧、角色设定、机制边界、风格例外和运营判断留在对应 `novels/<project>/` 内。
