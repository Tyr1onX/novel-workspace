# Shared

这里存放所有小说项目共同复用的方法，不存任何单本小说的正文或专属设定。

## 当前内容

- `RULES.md`：从现有市场深读、强弱对照和结构编码中压缩出的通用创作规则。
- `research/`：完整研究证据、样本账本、Click / Activation / Retention / Scale 模型、平台分层和反过拟合记录。

## 升级规则

只有满足以下任一条件，结论才允许进入 shared：

1. 有多个独立强样本与反例支持；
2. 在不同平台或不同题材中重复出现；
3. 在我们自己的多个小说项目中反复验证；
4. 能解释旧规则解释不了的反例，并且不会只是为单本书量身定制。

单本小说的局部技巧、角色设定、机制边界和运营判断留在对应 `novels/<project>/` 内。
