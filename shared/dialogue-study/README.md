# Dialogue Study：对白外部学习索引

本目录保存 `DIALOGUE_STUDY_CORPUS.md` 之外的增量阅读批次。

## 强制调用规则

凡 `DIALOGUE_APPRENTICESHIP.md` 判定为 `REBUILD` 的高风险对白，在开写前：

1. 先读 `../DIALOGUE_STUDY_CORPUS.md`；
2. 再读本目录**最近两个批次**；
3. 如果当前场景与更早批次明显同类，再按主题回读对应批次；
4. 只学习“人物为什么这样说 / 为什么不说 / 现实什么东西改变了下一句”，禁止复制原句、口癖或作者签名风格。

## 扩充规范

每批至少覆盖 3 个作品或 5 个有效场景。每条记录应包含：

- 场景类型；
- 人物各自目的；
- 共享背景；
- 没说出口的东西；
- 现实支点；
- 对话在哪里结束；
- AI 最容易学歪成什么；
- 对本仓库可迁移的决策；
- 明确不迁移的表面风格。

每累计两个新批次，必须回看 `DIALOGUE_APPRENTICESHIP.md`，只把跨作品、跨场景重复成立的结论升级成生产规则。
