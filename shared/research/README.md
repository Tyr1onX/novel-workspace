# 通用小说研究证据库

这里保存用于所有后续小说项目的市场研究原始证据与方法记录。

它不属于某一本小说，也不再承担“继续研究 SEED”或“决定某本书是否能写”的任务。

## 当前研究状态

市场深读阶段已经完成，当前证据规模包括：

- 高可信原生元数据：≥50本
- deep：24本
- extreme：8本
- deep弱/停更对照：8 / 24
- Click 表层诊断：19本
- 24本统一结构编码
- 平台分层与指标语义审计
- 非SEED控制与反过拟合样本
- 决策就绪/研究停止审计

完整样本账本：`sample-ledger-v2.md`。

## 当前用途

1. 为 `shared/RULES.md` 提供证据来源；
2. 新小说立项时查找强弱参照和反例；
3. 当新项目遇到旧模型解释不了的问题时，回到这里增补定向研究；
4. 不再为了“样本更多”而泛化扩库。

## 研究停止原则

当关键结论对删单个样本不敏感、已有多个正例和反例、最近定向样本不再产生新一级变量，而剩余问题只能靠真实曝光/点击/留存数据解决时，应停止继续深读，转入设计和发布测试。
