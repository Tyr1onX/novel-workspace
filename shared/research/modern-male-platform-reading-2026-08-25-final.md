# 现代男频爽文补课收口 — 2026-08-25

> 状态：ENOUGH TO DRAFT
> 目的：在正式重启 Third Pass 前，补足七猫 / 番茄 / 起点现代男频强样本的开篇、追读与文字经验。
> 本文件不是新的评分模型，只记录已经足够稳定、会直接改变正文写法的结论。

## 1. 本轮重点样本

### 七猫 / 七猫当前男频方向

重点查看并对照：

- 《她们眼中穷校草，竟是资本真大佬》：七猫当前 9.3 分、签约、连载；首章直接回到前世毁掉人生的陷害现场。
- 《步步登阶》：七猫当前 9.2 分、签约、超长连载；第一章用陌生城市、成人秘密、身份差和人际压力启动，不依赖系统。
- 《高武严父，永远比儿子高五个境界》：当前七猫男生新书榜前列；核心外挂与父子关系绑定，儿子成长同时改变父亲的能力、家庭关系和保护责任。
- 《二本没毕业，你怎么登上福布斯了》：当前七猫男生新书榜可见；重生后先处理学历羞辱、阶层焦虑和人生选择，不把“未来商业知识”单独当功能展示。
- 《厂长收手吧！国家真的压不住了！》：签约完结的现代黑科技 / 工业爽文；与 Second Pass 题材高度接近，可用于证明“小厂 + 黑科技”本身不是签约失败的根因。

### 番茄

重点对照：

- 《大学没毕业，你怎么登上福布斯了》：2026 年番茄都市种田高在读样本；开篇先把“高考 / 学历 / 阶层选择权”变成人物之间正在发生的争执。
- 《学霸的征途是星辰大海》：系统学霸 / 黑科技方向，高在读；目录可以看到早期不是直接从宏大科技起飞，而是试卷、老师、竞赛、同学等现实尺度逐层放大。
- 《商业帝国：黑科技有亿点多》以及多本黑科技创业样本：继续证明技术题材可行，但长期容易滑向产品清单和行业碾压，因此人物关系必须比产品升级更早进入主线。

### 起点

重点对照：

- 《学霸的黑科技系统》：经典科技爽文。第一章先让陆舟顶着高温穿布偶装打暑假工，用 60/70 元一小时这种生活尺度立住“为什么需要改变”，系统随后才进入。
- 《我真没想重生啊》：都市重生长青样本。强项不是重生知识本身，而是陈汉升的具体性格不断通过说话、撒谎、交往和选择制造事件。
- 《重生野性时代》：都市商业代表样本。主角回去面对的不是“未来商业知识等待使用”，而是父亲入狱、家庭和公司坠落，需要立刻救家。
- 2026 起点新晋万订 / 三江新书样本：继续显示成熟男频开篇越来越重视差异化场景、人物身份、明确欲望和即时矛盾，而不是只靠外挂说明。

## 2. 已经足够稳定的共识

### 2.1 第一章首先建立“今天必须解决的事”

强样本常常很快让读者知道：

1. 主角现在在哪；
2. 今天出了什么事；
3. 谁正在阻止他；
4. 他如果什么都不做会失去什么；
5. 他做了哪个能暴露性格的选择。

金手指可以晚几十段解释，但“人物今天为什么必须动”不能模糊。

### 2.2 爽点是情绪账的兑现，能力只是结算工具

产品性能翻倍、境界 +1、获得新技能都只是能力变化。

真正的爽点通常在结算一笔前文已经让读者记住的账：

- 被人轻视后改变双方地位；
- 旧方法曾让主角惨败，第二次对手信心十足地再用却失效；
- 主角过去保护不了的人，这次保住了；
- 对手以为抓住主角弱点，结果自己的判断成为败因；
- 主角终于拿回原本被剥夺的选择权。

因此写爽点前先问：读者现在到底在等哪笔账被还？

### 2.3 能力最好同时改变关系

高武严父的核心能力之所以比单纯“我永远高五境”更有故事性，是因为它通过儿子触发。

理想状态下，一次成长同时改变至少两项：

- 主角能做什么；
- 别人怎么看他；
- 谁开始害怕 / 依赖 / 怀疑他；
- 某段关系的上下位；
- 下一次冲突双方会怎么调整策略。

如果升级之后只有数值变了，故事很快会进入功能展示。

### 2.4 第一笔兑现要具体，但不需要把整本书一次证明完

Second Pass 的问题之一是首章同时塞入系统、失败采集、重构、参数翻倍、无人机测试和客户反馈。

强样本更常见的做法是：

> 先完成一个足够清楚的小兑现，让它自然打开第二个问题。

读者需要确认“这书会兑现”，不需要第一章就看到全部产品路线图。

### 2.5 主角不能只是正确，必须有辨识度

真正能撑长篇的人物，需要在普通场景里也能制造事件。

写前不能只记“冷静、聪明、果断”。要知道：

- 他被冒犯时具体怎么回；
- 他会不会撒谎；
- 他愿意为谁冒险；
- 他在害怕时会加快动作还是故意慢下来；
- 他如何保面子；
- 他发现别人说谎时，是当场拆穿、留下证据，还是反过来利用。

角色能让“没有外挂的一章”也成立，长篇才有生命。

### 2.6 反派 / 对手要会学习

对 Third Pass 尤其重要。

“同一种失败第二次无效”最强的用法不是测试中心不断换机器，而是：

> 有一个有脑子的人第一次找到主角弱点 → 几乎杀死他 → 认为方法已经验证 → 第二次更有把握地重复 → 方法失效 → 对方被迫学习、换手段。

此后形成双向军备竞赛：

- 林序通过失败改变；
- 对手通过观察林序改变。

这比“抗性图鉴”更能自然产生长期冲突。

### 2.7 章尾不是统一悬念句，而是让局面无法回到章首

有效章尾可以是：

- 新证据出现；
- 关系翻面；
- 一个决定已经做出；
- 对手改变策略；
- 主角刚赢，但暴露了更危险的信息；
- 已经无法撤销的行动启动。

章尾的核心是“下一章的问题已经被制造出来”。

## 3. 对 Third Pass 的最终诊断

当前核心能力和书名仍值得保留：

> 《你最好第一次就杀死我》
>
> 第一次真正差点毁掉林序的失败会被他与绑定装备记住，同一种方法第二次很难再拥有同样效果。

但旧开篇前四章仍有明显的“事故 → 复测 → 确认规则 → 留下装备”实验流程感。

最大缺口：

> **标题承诺的是“有人最好第一次就杀死我”，旧开篇却到第五章才让真正的人为敌意进入。**

因此正式开稿前最后一次调整：

1. 保留仓储坍塌与动力外骨骼；
2. 第一章第一次失效可以看似事故；
3. 林序为救被困队友 / 人员主动再次进入；
4. 同样的锁死指令第二次出现，但这次失效；
5. 救援结束后直接发现：两次失效都对应外部远程维护指令，第二次指令是在林序重新进入之后才下发；
6. 这意味着有人看见他第一次没死，又按了第二次；
7. 第一章同时完成能力首证、救人、人物选择、第一笔爽点，以及“有人在杀我”的长期冲突入口。

这样书名、能力、人物与敌人从第一章开始是同一件事。

## 4. 研究停止判断

此时继续泛读更多“好书”边际收益已经明显下降。

我们已有：

- 大量平台样本与强弱对照；
- 七猫签约失败的真实反馈；
- 七猫当前签约 / 榜单现代男频样本；
- 番茄高在读样本；
- 起点长期强样本与 2026 新晋强样本；
- 平台作家课堂；
- Writing DNA / prose guard 方法；
- 传统叙事工艺的必要补充。

现在最大不确定性不再是“我们知不知道理论”，而是：

> **我们能不能把这些经验写成一章真正让人想点下一章的正文。**

结论：停止泛研究，进入写作验证。
