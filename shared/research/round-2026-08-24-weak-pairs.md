# 2026-08-24：弱样本补读与反例校正

本轮目标不是继续找“好看的成功书”，而是补足会推翻我们已有假设的弱样本。正文继续冻结。

## 1. 《重生零九：我真没有黑科技啊！》

**表现**：番茄已完结，20.5 万字，当前作品页显示未满 1000 人在读。

**来源**：

- 作品页：https://fanqienovel.com/keyword/399220
- 第1章：https://fanqienovel.com/reader/7161272464583066125
- 第2章：https://fanqienovel.com/reader/7161272847690629667
- 第3章：https://fanqienovel.com/reader/7161273326994719268

### 前三章

第1章先给“09年重生 + 被前女友利用 + 没钱”的现实底色，但章末直接收到一万元。

第2章很快揭晓这笔钱来自未来科技球：科技球不仅直接弄来一万元，还一次性传入黑客技术。主角随后决定复制前世爆款小游戏，用最低成本起盘。

第3章进一步把能力推到近乎无门槛：几分钟进入网络世界，目标人物产业、监控、电脑、违法证据几乎全部暴露，随后直接把证据发给巡查组和QQ群。

### 前20章兑现路线

目录显示：

- 7章：招揽成功；
- 9章：第一个玩家；
- 14章：有钱啦；
- 15章：新游戏；
- 16章：买车；
- 20章：鹅厂来人；
- 21章：合同达成。

表面看，它其实不慢：钱、游戏、团队、车、鹅厂合作都在很早出现。

### 为什么仍然是高价值弱样本

它证明“快 + 钱 + 游戏 + 大厂”也不是充分条件。

主要结构问题不是事件少，而是：

1. **第一次收益缺乏 earnedness**：一万元不是通过主角解决问题获得，而是科技球直接“摸”来的。
2. **能力门槛迅速坍塌**：黑客技术几乎等于全城网络透明，信息阻力被消灭。
3. **目标分叉过早**：报复前女友/富二代、黑客揭黑、做游戏、招团队、赚钱同时展开。
4. **“赢”很快，但赢法没有形成可重复的核心承诺**：不是同一条主因果链逐步升级，而是不断换爽点。

番茄作品页相关公开评论还出现过“主角智商太差”“主动往别人枪口上撞”等负面反馈。它提醒我们：主角掌握超强技术不等于读者会自动认同主角的选择。

**本轮标签**：弱表现 / 年代重生 / 黑科技 / 快兑现 / 低阻力 / 多目标。

## 2. 《开局核聚变，打造大国之巅峰科技》

**表现**：番茄已完结，79.7 万字，当前作品页显示未满 1000 人在读。

**来源**：

- 作品页：https://fanqienovel.com/keyword/7626267
- 第1章：https://fanqienovel.com/reader/7224347702811853346
- 第2章：https://fanqienovel.com/reader/7224744910027489844
- 第3章：https://fanqienovel.com/reader/7224746552823120436

### 前三章

第1章一开始就把主角设成“死亡 → 魂穿500年后 → 活到98岁成为顶尖全能科学家 → 再回原时代”，等于把几十年的未来科研知识一次性装回大一新生身体。

同一章里，他看到本国核聚变落后消息，两小时就写出能把实验持续时间提高到24小时的方案，并把五分之一材料发给研究所。

第2章已经因为邮件触发国外情报力量，同时主角还有额外身体强化/反应能力。

第3章直接进入国外人员抓捕、特种部队、国安、国家级保护。外部世界不仅看见了结果，而且反应非常大。

### 前20章兑现路线

目录从第3章开始就持续大场面：

- 3：新型可控核聚变；
- 4：绝密邮件；
- 5：武装阻拦；
- 6：大一新生身份冲突；
- 7：打破记录；
- 10：商业大战；
- 14：企业高层求助；
- 17：一百万；
- 18：一千万；
- 19～20：保镖。

这本甚至比很多成功样本更快、更大、更“被世界看见”。

### 反例价值

它直接否定了一个潜在错误结论：

> “只要能力尽快转化成外部大结果，并让权威人物震惊，就能形成强留存。”

不够。

这里的主要问题是：

1. **能力来源太完整**：主角不是“能解决一个问题”，而是直接拥有500年后的全能科研人生。
2. **升级空间被预支**：开篇就能跨越几十年科技差，后面很难让读者感到“学会了什么”。
3. **阻力更像舞台布景**：邮件一发，国际间谍、特种部队、国安都自动围绕主角运转，主角自身解决现实约束的过程很少。
4. **规模膨胀快于可信度建立**：几章内从普通大一新生跨到国家级与国际级冲突，读者还没形成对人物能力边界的信任。

因此“外部见证”本身也要细分：

- **earned witness**：别人因为主角在真实约束下完成了一件事而改变判断；
- **author-declared witness**：作者安排世界立刻承认主角是天才。

二者不是同一种爽感。

**本轮标签**：弱表现 / 黑科技 / 极快兑现 / 超大规模 / 高见证 / 低阻力 / 低earnedness。

## 3. 《超级全能学生》（紫函）

**表现**：番茄已完结，91.4 万字，当前作品页显示未满 1000 人在读。

**来源**：

- 作品页：https://fanqienovel.com/keyword/7540438020344809472
- 第1章：https://fanqienovel.com/reader/7419913212067318808
- 第2章：https://fanqienovel.com/reader/7419913193226521624
- 第3章：https://fanqienovel.com/reader/7419913194270903320

### 为什么它尤其重要

它几乎把我们前面认为重要的元素都做了：

- 主角是高三学生；
- 家庭经济条件弱；
- 自己长期班级垫底；
- 学校内部有普通班/精英班与明确换班规则；
- 能力出现后第2章立即反击混混；
- 第3章马上在物理题上让成绩好的课代表发现异常；
- 第11章标题已经到“保送数学系博士”；
- 第18～20章进入买彩票、开奖。

它有现实计分板、有阶层、有老师/同学见证，也很快兑现，却仍然是弱表现。

### 前三章结构

第1章主角见义勇为被刺，随后绑定来自未来的超脑芯片。能力不仅治伤，还一次性拥有联网、运动神经复制、逻辑运算等多个模块。章末提出“考好大学、改变家庭”的目标，但很快又花大量篇幅罗列功能。

第2章直接调用“特种兵记忆”打败混混；随后又详细铺学校的富裕阶层、普通班/精英班、前女友、拆迁失败等关系。

第3章回到学习线：主角几分钟完成物理题，解法比课代表更简洁，形成第一次校内见证。

### 前20章的问题

如果只看单点爽感，它并不缺：学习、打架、篮球、保送、恋爱、彩票都有。

但这恰恰暴露了新的变量：**Promise coherence（承诺一致性）**。

它的核心幻想很快从“学渣靠超脑逆袭”扩散成：

- 学习；
- 格斗；
- 体育；
- 恋爱；
- 权势冲突；
- 彩票财富。

每条线都能爽，但读者无法稳定预期“下一次进度条到底是什么”。能力越全能，原本最清楚的校园计分板反而越快失去价值。

因此我们要进一步区分：

> **有计分板** ≠ **整本开篇围绕同一块计分板持续升级**。

成功的校园样本往往会把成绩、竞赛名额、老师评价、学校层级持续串成同一条因果链；这本则更快变成“超脑什么都能做”。

**本轮标签**：弱表现 / 校园 / 未来计算能力 / 强计分板 / 强见证 / 超全能 / 承诺分散。

## 4. 候选弱样本：《零〖ZERO〗》——暂不计入深读数量

它和未来可能的 SEED 商业外壳异常接近：28岁高级工程师背锅被裁，电脑中的自主AI觉醒，把主角视为父亲，随后报复项目经理/原公司、注册一人公司、解决客户问题、拿订单、建立商业帝国。

但目录显示前30章大量篇幅依次停留在：

- 背锅（1～3）；
- 零（1～3）；
- 求救（1～3）；
- 林婉如（1～3）；
- 起诉（1～3）；
- 墓地（18～20）；
- 证据（21～23）；
- 开庭（24～27）；

# 本轮对模型的修正

上一轮的规律：

> 市场未必排斥AI，更排斥“AI能力本身就是剧情”。

仍然成立，但需要加上更严格的后半句：

> **外部结果必须绑定一个清楚、稀缺、持续的计分板；结果要在仍然存在的现实阻力中挣出来，并被外部人物真实见证；同时整段开篇必须维持同一核心承诺。**

所以现在至少有六种常见假快：

1. **事件快**：很多事情连续发生，但每件事都没有选择和代价。
2. **数字快**：营收、估值、成绩暴涨，但只是作者报数字。
3. **权威快**：院士、领导、投资人立即震惊，却没有可信的验证过程。
4. **能力快**：第一章一次性给全套技能，后续没有成长感。
5. **换爽点快**：学习爽完去打架，打架爽完中彩票，再去商战，核心承诺不断漂移。
6. **规模快**：几章从普通人跳到国家/国际舞台，但人物与读者的信任尚未建立。

# 对后续立项评分的新增字段

除原来的“0.5秒幻想、前三章兑现、2万字兑现、50万字长线能力、差异度、平台适配度”外，正式评分前增加：

- 计分板延迟；
- 能力→现实兑换延迟；
- 外部见证密度；
- 阻力存活度；
- 目标集中度；
- 承诺一致性；
- 获得感/可信度；
- 稀缺性；
- “场景挣到的结果”与“作者宣布的结果”比例。

这批变量要继续用成功/失败成对样本验证，不能因为本轮三个反例就直接写进最终创作公式。
