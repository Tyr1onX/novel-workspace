## 一、沿用 V1 量表

正向字段 0～3：0 很弱，3 很强。

风险字段：`R0` 风险低，`R3` 风险高。

- `HSP` human stake preload
- `PSA` promise surface alignment
- `CAC` causal attribution clarity
- `PBS` proof-burden survival
- `AGS` agency share
- `ATC` application target coherence
- `TDD` target decomposition depth
- `CPL` cumulative progress legibility
- `IPD` intermediate proof density
- `PH` progression headroom
- `RLR` resource loop visibility；仅对反馈成长型机制高权重
- `SGC` stage gate closure
- `CS` constraint survival
- `MDR` module demo trap risk
- `SSR` scoreboard saturation risk
- `LTE` long-tail engine

V2 仍然**不直接把所有字段相加成 100 分**。

## 三、剩余16本编码时最重要的校正

### 1. 《重生零九》与《开局核聚变》再次证明 `IPD` 不能单独使用

两本都不缺“事情发生”：前者很快有钱、游戏、团队、车、大厂；后者很快有核聚变、间谍、国安、商业战、百万/千万。

所以都给了较高 `IPD`。

但它们的 `ATC/TDD/CPL/SGC/CS` 同时很低：proof 很多，却不是在一条有阻力、能累计、能结算的现实进度线上连续挣出来。

因此以后不要把“爽点密度”直接写成成功变量。更准确的是：

> **有效 proof 密度 = proof 数量 × proof 的累计性 × proof 的阶段相关性。**

### 2. 《黑科技神豪从制造芯片开始》故意保留高 `CAC`

三台 5nm EUV 到底从哪里来非常清楚：系统直接送。

所以它的 `CAC` 不是低，而是主角 `AGS=0`、`PBS=1`、`SGC=0`。

这再次说明 `causal attribution clarity` 只回答“是谁造成的”，不回答“是否挣得”。

因此 `CAC` 不能吸收 `agency / earnedness`。

### 3. 《8号手机维修店》是 AI 外包陷阱的干净样本

它的标题承诺很快兑现，客户也真实付钱，所以 `PSA/IPD` 不低。

真正下滑的是：AI 从辅助主角修手机逐步变成全能上游承包商，主角越来越像接单/转手前台。因此：

- `AGS=1`
- `ATC/TDD/CPL/SGC` 都低
- `MDR=R3`

这比简单说“AI太强”更准确。

### 4. 《开局上交核聚变，能给份工作吗？》修正“主角每章必须高 agency”

第一章前，刘阳已经用两个月、个人积蓄和借款完成主要研发；第2～9章主角行动很少，但国家机构对既有成果逐级验证，第9章才正式确认可控核聚变。

因此 `AGS=2` 而不是因为“主角昏迷”打成0；creation agency 与 reaction phase 必须分开。

### 5. 《裁员后，我成了科技教父》提示 RLR 不只存在于两本极深样本

现有资料显示，小沙的成长并非纯签到：郝成提供关键知识/影响现实科技方向后会触发能量/学习资源，再反过来推动 AI 能力升级。

因此暂记 `RLR=2`，但证据强度低于《重生1999》和《打爆学霸》的 `RLR=3`。后续若进入极深读可再校准。

## 四、performance-hidden 计算：先不看表现标签，只算结构潜变量

为了避免继续把 16 个字段当 16 个独立真理，V2 先构造五个**诊断潜变量**。它们不是最终评分，只用于检查是否存在明显结构簇。

### `progress_focus`

`mean(ATC, TDD, 3-MDR)`

回答：是不是围绕同一个应用靶持续拆问题，而不是功能巡演。

### `progress_legibility`

`mean(CPL, SGC)`

回答：连续胜利是不是能累加、阶段是不是能真正结算。

### `progress_headroom`

`mean(PH, 3-SSR)`

回答：第一阶段既能不断兑现，又是否给同一方向留下继续追的空间。

### `causal_ownership`

`mean(CAC, AGS)`

回答：核心卖点是否拥有成果的主要因果权，同时主角本人有没有价值占比。

### `friction_survival`

`mean(PBS, CS)`

回答：外挂知道/能做之后，现实证明与资源/市场/组织约束是否还活着。

再取五项均值，得到一个**Retention Core diagnostic**。这里只用于检查样本排列，不作为立项总分。

## 五、隐藏标签后的结果

编码完成后才把稳定表现标签重新放回来，出现了非常明显但不能过度解读的分层：

- 稳定强样本 Retention Core：**2.60～2.90，均值约2.78**；
- 稳定弱/长期停更样本：**0.93～2.30，均值约1.22**；
- 如果暂时拿掉《重生手搓ChatGPT》这个重要离群点，其余稳定弱/停更样本最高只有约 **1.13**。

这说明“进展拓扑 + 因果所有权 + 现实摩擦”这一簇当前确实有明显区分力。

但这不是可以庆祝模型已经完成，恰恰相反：**《重生手搓ChatGPT》就是必须保留的反例。**

## 六、三个最重要的反过拟合离群点

### A. 《重生手搓ChatGPT》：Retention Core 约2.30，但长期停在12万字级

它保留真实技术约束、主角 agency 也高，结构分并不差。

问题更可能落在：

- 标题承诺兑现的 reader-facing latency；
- 技术解释预算；
- 产品 proof 前先拿500万资本；
- 用户增长以 dashboard 数字呈现；
- Click Layer 明确写“缺少计算机和AI基础谨慎观看”，主动提高进入门槛；
- 作者停止更新这一供给侧因素。

因此它证明：Retention 结构不能解释“作者为什么停更”，也不能完全解释点击与首批读者规模。

### B. 《重生2005，AI客服称霸电商》：Retention Core 约2.90，但当前低量级

它在 feedback loop、现实约束、主角 agency、stage gate 上几乎都符合当前 SEED 正解。

如果以后它仍没有明显放量，不能倒推“这些变量没有用”，而要继续检查：

- 表层幻想是否过于像行业方案；
- 解释税；
- 人物/情绪吸引力；
- 推荐窗口；
- 后段时间压缩与阻力质量。

### C. 《重生：我把魔法冠冕改成人工智能》：Retention Core 约2.90，当前中低量级

前20章在结构上几乎挑不出大缺口；最明显的疑点反而在点击前：

> 重生 + 魔法冠冕 + AI + 废品硬件 + 网吧创业 + 光刻机/数字霸权

正文其实很集中，但表层概念负载很高。

这进一步要求 Click Layer 必须成为独立子模型。

## 七、24本字段共线检查

24本第一轮手工编码出现非常高的相关：

- `CPL ↔ SGC` ≈ **0.98**
- `ATC ↔ CPL` ≈ **0.97**
- `ATC ↔ SGC` ≈ **0.95**
- `ATC ↔ MDR` ≈ **-0.94**
- `CPL ↔ MDR` ≈ **-0.93**
- `PH ↔ MDR` ≈ **-0.93**
- `CPL ↔ SSR` ≈ **-0.92**
- `SGC ↔ SSR` ≈ **-0.92**
- `ATC ↔ TDD` ≈ **0.88**

这些数字不能当市场统计学结论——样本小，而且编码本身来自同一研究者，天然会制造相关。

但至少足以说明：

> **最终模型绝对不应该把这些字段当成七个独立加分项。**

否则等于对同一个“进展集中且可累计”现象重复加七次分。

## 八、V2建议压缩方向

暂时保留五个 Retention 潜变量：

1. `progress_focus`
2. `progress_legibility`
3. `progress_headroom`
4. `causal_ownership`
5. `friction_survival`

`HSP/PSA/IPD`降为 Activation/卫生项，不再和上述五项等权。

`RLR`保留为**SEED类反馈成长机制的专属增强项**，而非全品类通用成功变量。

`LTE`只用于 Scale layer 的事后验证，不拿长篇成功反过来给开篇结构加分。

## 九、当前最重要的新判断

24本编码后，研究模型从“什么元素要有”进一步变成：

> **一本书不是因为有多少爽点而强，而是因为读者能否把这些爽点组织成一条不断前进、仍有余量、现实会反抗、成果有明确因果所有权的进展结构。**

这也解释了为什么《超级全能学生》会成为非常重要的弱反例：它什么都有，但“都有”本身正是问题。

同时必须保留另一半：

> **结构正确也不是充分条件。**《AI客服》《魔法冠冕AI》《重生手搓ChatGPT》要求下一阶段把 Click / narration / distribution / author supply 分开研究。

5. 完成 Click + Retention 后才开始比较 SEED 立项候选。
